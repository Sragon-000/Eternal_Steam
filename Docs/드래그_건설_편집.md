# 드래그 건설·범위 회수 편집

적용일: 2026-09-17. 원본 프로젝트의 OpenWorld 공통 입력에 적용하며 StartRegionSandbox에서 검증했다. 게임 빌드는 수행하지 않았다.

## 조작

- 수정 상태에서 방벽을 선택하고 **첫 좌클릭으로 시작점, 다음 좌클릭으로 끝점**을 지정한다. 첫 클릭 후에는 선 미리보기만 표시하며 두 번째 클릭으로 일직선 방벽을 임시 배치한다. **확정**하면 설치한다. 누른 채 이동해도 경로를 따라 설치하지 않는다.
- 같은 방벽 인벤토리 항목을 다시 클릭하면 건설 도구 선택이 해제된다. 수정 상태의 빈 공간에서 **좌클릭 사각 드래그**하면 범위 내 설치된 포탑·방벽·다른 회수 가능한 건물을 회수 예정으로 선택한다.
- 방벽 도구를 유지한 채 **Shift + 좌클릭 드래그**해도 사각형 선택을 사용할 수 있다.
- 사각형 선택은 기존 회수 목록에 추가한다. 같은 범위를 다시 선택해도 기존 선택을 해제하지 않는다. 개별 클릭은 기존처럼 회수 선택을 켜고 끈다.
- 회수는 **확정** 시 실행한다. 수정 버튼 재클릭 또는 취소하면 임시 배치를 없애고 회수 예정 건물을 유지한다.
- 토대 위 건물도 범위 선택에 포함하지만 토대 자체는 자동 회수하지 않는다. 토대 회수는 기존 개별 클릭 흐름을 사용한다.

## 판정과 예외

- 방벽 외 입력은 화면에서 6픽셀 이상 움직이면 사각 드래그다. 방벽은 클릭을 놓을 때 누른 지점을 시작점/끝점으로 사용한다.
- 45도 월드 격자 기준 2m·1셀 방벽을 연속 배치한다. 끝점은 시작점과의 차이가 큰 격자 축으로 맞춘다(동률이면 X축). 따라서 항상 한 행 또는 한 열의 직선이며, 시작·끝 칸을 모두 포함한다. 동일 칸을 두 번 찍으면 1개를 예약한다.
- 이미 예약한 칸은 중복 배치하거나 예약을 제거하지 않는다. 설치 불가·점유 칸은 건너뛰고 건너뛴 수와 실패 이유를 표시한다.
- 전체 확정 시 기존 배치 세션의 재검증을 거친다. 드래그 자체가 건물을 즉시 설치하지 않는다.
- 사각형의 경계 안에 **건물 중심점**이 들어오면 선택한다. 역방향 드래그도 동일하다. 임시 건물은 회수 대상이 아니다.
- 드래그 중 카메라 이동과 휠 줌을 막는다. UI로 이동하거나 창 포커스를 잃으면 현재 제스처만 취소하며 이전에 완료한 임시 작업은 유지한다.
- 기존 계약대로 임시 설치와 회수를 한 작업에서 혼합하지 않는다. 임시 설치가 남아 있으면 먼저 확정하거나 취소해야 회수 선택이 가능하다.

## 책임 분리

| 구성 | 책임 |
|---|---|
| WallPlacementStroke | 격자 경로 채우기, 중복 방지, 현재 제스처 예약의 취소 |
| BuildingRectangleSelection | 화면 사각형과 건물 중심점 판정, 여러 토대 월드 수집 |
| ConstructionDragEditor | 클릭·드래그 구분, 사각형 표시, 제스처 수명 |
| OpenWorldInput | 실제 InputSystem 입력 전달, 기존 단일 클릭 연결 |
| WorldEditSession.SelectRecovery | 월드와 개체 기준의 중복 없는 회수 선택 |
| 기존 PlacementSession / RecoverySession | 최종 설치·회수의 검증·확정·취소 |

방벽 판별은 콘텐츠 ID나 UI 분류가 아니라 명시적인 건물 전투 모듈의 Wall 역할과 1셀 점유를 사용한다. 서로 다른 토대의 로컬 건물 ID가 같아도 개체를 구분한다.

## 검증 결과

원본 Editor Play 모드에서 다음 스크립트 통과:

- `Tools/VerifyDragConstruction.cs`: 두 클릭 직선·역방향·한 칸 예약·시작점 취소, 확정·취소, 점유 칸 건너뛰기, UI/포커스 취소 시 이전 예약 보존, Shift 선택, 역방향/반복 선택, 서로 다른 토대의 동일 로컬 ID, 회수 후 토대 유지.
- `Tools/VerifyDragMouseInput.cs`: InputSystem 가상 마우스의 첫 클릭 후 길게 눌러 이동해도 예약하지 않으며 두 번째 클릭이 실제 Update를 통해 6칸 직선 배치 및 사각형 회수 선택으로 연결됨. 드래그 중 카메라 차단과 취소 보존 확인.
- `Tools/VerifyOpenWorldCameraInput.cs`: WASD, 입력창 포커스, 휠 줌 및 UI 위 줌 차단.
- `Tools/VerifyNexusGroundInput.cs`: 기존 넥서스·신규/기존 포탑 단일 배치와 지연 회수.
- `Tools/VerifySelectedTowerRange.cs`: 수정 상태 사거리 숨김, 일반 상태 선택 사거리 및 선택 해제.

추가 성능 개선 후보는 [추가 개선 백로그](추가_개선_백로그.md)에 문서로만 남겼다. 이번 변경의 성능 향상 수치를 주장하지 않는다.
