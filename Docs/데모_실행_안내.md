# 도형 기반 물량 처리 데모

## 실행

복제한 저장소의 루트가 Unity 프로젝트입니다. Unity 6000.3.14f1에서 `Assets/HordeDemo/Scenes/HordeDemo.unity`를 열고 Play를 누르세요. 기본 포탑 4개가 배치됩니다.

## 조작

- 파란색 설치 구역을 마우스 왼쪽 버튼으로 클릭하면 포탑을 설치합니다. 가까운 포탑과 겹치는 위치에는 설치할 수 없습니다.
- `50/s`, `100/s`, `300/s`: 초당 적 생성 수를 변경합니다.
- `Pause spawns`: 새 적 생성을 일시 정지합니다. 기존 적과 포탑은 계속 움직입니다.
- `Reset enemies`: 적과 처치·통과 카운터를 초기화합니다. 설치한 포탑은 유지합니다.
- `Clear turrets`: 설치한 포탑을 모두 제거합니다.

## 구현 범위

캡슐 적이 왼쪽에서 오른쪽으로 이동하고, 큐브 포탑이 사거리 내 적을 자동 조준해 한 발로 처치합니다. 노란 사격선으로 공격을 표시합니다. 출구를 통과한 적은 제거되고 통과 수에 합산됩니다.

동시 적 상한은 4,000마리, 포탑 상한은 64개입니다. 적은 고정 배열과 재사용 슬롯으로 관리하며, 공간 격자로 표적을 찾고 인스턴싱으로 렌더링합니다. 적끼리 충돌하거나 길을 찾지는 않습니다. 경제·강화·승패 시스템은 이번 데모에 포함하지 않습니다.

HUD에서 현재 적 수, 처치 수, 통과 수, 포탑 수, 생성 속도, FPS를 확인할 수 있습니다. FPS는 에디터 창의 활성 상태와 장비에 영향을 받으므로 빌드 성능 측정값으로 해석하지 않습니다.

## 검증

Unity CLI를 통해 스크립트 컴파일과 Play 실행을 확인했습니다. `Tools/VerifyHordeDemo.cs`는 설치 제한, 적·포탑 상한, 자동 공격, 슬롯 재사용, 출구 제거, 카운터 일관성과 초기화를 검증합니다. `Tools/VerifyHordeHud.cs`는 UI 버튼의 생성 속도 변경, 생성 일시 정지·재개와 적 초기화를 검증합니다. 두 검증 모두 통과했으며, 마우스 입력을 통한 실제 포탑 설치도 확인했습니다.

두 검증 스크립트는 Play 중 Unity CLI `run_script` 명령으로 실행합니다. 실행하면 현재 데모 상태가 변경됩니다.

```sh
unity command run_script --file Tools/VerifyHordeDemo.cs --entry VerifyHordeDemo.Main --project-path . --format json
unity command run_script --file Tools/VerifyHordeHud.cs --entry VerifyHordeHud.Main --project-path . --format json
```

`Tools/CreateHordeDemo.cs`는 최초 씬 생성용입니다. 기존 데모 씬이 있으면 덮어쓰지 않고 중단합니다.
