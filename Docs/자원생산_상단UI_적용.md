# 자원 생산과 최상단 UI (일정 2~2.1)

2026-09-18. 사용자 지정 범위는 기존 생산 기능 연결과 최상단 재고 표시다. 2.2 이후 지역 제한·실제 기지 레벨 해금·저장 건물·설치 개수 제한은 이번 작업에서 추가하지 않는다.

- 시작 맵 카탈로그에 빠져 있던 기존 자원 생산 정의 7종을 등록했다. 자원 탭에서 선택 가능하다.
- 생산·변환 레시피와 재고 모듈을 재사용한다. 기존 배치 확정/가동 범위/회수 계약, 검증 레벨·용량·수치는 변경하지 않았다. 최종 경제 수치가 아니다.
- 자원 UI는 OpenWorldHud.uxml의 resource-panel에 미리 배치했다. 최상단 중앙이며 시계/우측 테스트 패널과 분리된다. 향후 이동은 USS 레이아웃으로 처리한다.
- ResourceStockView는 카탈로그에서 자원 ID별 목록을 초기 구성하고 재고 변경 시에만 표시 문자열을 갱신한다. 같은 자원을 생산하는 정의가 추가되어도 표시는 중복하지 않는다. UI가 생산이나 재고를 직접 변경하지 않는다.
- 준비/전투 중 기존 생산 갱신 경로를 유지한다. 수정 중 자동 생산은 기존대로 정지한다. 개발자 시계 정지는 생산과 별개다.

검증: 원본 새 맵 Play 모드에서 VerifyResourceStockUI 통과. 생산 갱신을 정해진 간격으로 직접 호출하여 임시 상태 생산 없음 → 넥서스/자원 건물 확정 → 실제 레시피 재고 증가 → 상단 표시 반영 → 회수 확정 후 생산 중단을 확인했다. 자연 경과 시간을 기다리는 자동 생산 검증을 이번에 통과했다고 주장하지 않는다. 카탈로그 구성 검사 및 컴파일 통과. 빌드는 수행하지 않았다.
