# 정상 플레이 내부 테스트 — 실행 전 점검

상태: 선행 작업과 정상 기준 회차 완료. 열차 대기 전력 개선의 296개 회귀를 통과했으며 개선 후 장기 생존 비교를 실행 중이다. 제품 내부 플레이이며 학술 연구 실험은 아니다.

## 현재 확인한 제약

- `OpenWorldSandbox`는 기지별 재고·캠페인 저장이 없는 호환 씬이다. 정상 플레이 요청에 따라 기존 캠페인 `StartRegionSandbox`를 최초 한 번 선택하고 이번 회차의 테스트 씬으로 고정했다. 실행기는 다른 씬을 열거나 자동 순회하지 않는다.
- 기존 캠페인 `StartRegionSandbox`는 시작 기지, BasePlanningRules, StartRegionAssault를 참조한다. ConstructionCosts/UpgradeCosts 참조는 비어 있어 현행 일반 건설·강화 무료 정책을 사용한다. 이를 유료 비용이 균형 잡힌 게임으로 평가하면 안 된다.
- StartRegionAssault 정적 설정: 목표 1,000,000 내부 단위, 셀 에너지 10,000, 추출 10/초, 일반 적 처치 보상 1,000, 첫날 일반 적 예산 100, 이후 일차당 25 추가, 소환 간격 0.2초, 보스 체력 1,000. 실제 적용 구성은 회차 시작 시 다시 기록한다.
- MapEnergyState는 90%에 도달한 뒤 밤 조건에서 보스 단계로 진행하고 보스 처치가 나머지 10%를 준다. 오브 제작 시 Cleared가 되며 공세를 멈추고 남은 적을 무보상 정리한다. 클리어 후 적 없는 시간을 오래 보내는 것을 생존 난이도 성과로 계산하지 않는다.
- 과거 첫 회차 자료는 정상 시뮬레이션 Tick과 HUD 명령으로 자연 생산·철 30 운송·보스·제작을 확인했지만 이번 버전의 장기 생존 기록을 대신하지 않는다.

## 실행 순서

1. 한 씬에 고정하고 초기화/생산/전력/건설·강화/자원 소유권/적 도달·피해/기지 손실/운송/보스/오브/저장·실패 복구의 전체 경로를 코드와 데이터로 감사한다. 진행 불가·중복 결제·자원 소실·무한 생성·소프트락은 수집 전에 수정한다.
2. 고정 버전·설정의 회차 ID와 격리 저장 루트를 만든다. 실행 중 규칙을 고치면 해당 회차를 중단·보존하고 새 회차로 다시 시작한다. 임의 재고/에너지/체력/낮밤 주입을 금지한다.
3. 실제로 제공되는 콘텐츠 목록을 카탈로그에서 추출한다. 건설/강화·기지 확장·철도 운송·기차 화물/방어·방어 건물 역할·보스·오브를 사용한다. 미구현 기획 콘텐츠는 완료 목록에서 제외하고 누락 사유를 기록한다.
4. 이벤트와 주기 표본을 함께 남긴다. `runId, utc, realtime, gameSeconds, day, phase, action, baseId, buildingId, routeId, resource, before, delta, after, reason, screenshot` 키로 비용·생산·소비·손실을 연결한다. 재고·전력·적 생성/처치/잔존·피해·연료·적재/하역·배송량·대기 사유를 수집한다.
5. 낮밤 전환/해금/추가 기지/첫 배송/위험 상황/보스/실패/완료에 화면을 보존한다. 긴 구간도 일정 간격으로 캡처하여 상태를 복원할 수 있게 한다. 자동 행동이나 시간 가속을 사용하면 배율·행동 규칙·사용 구간을 명시하고 수동 입력과 구분한다.
6. 모든 현재 콘텐츠를 경험한 후에도 제작 전에는 웨이브가 지속되므로 방어·보급을 유지해 생존을 시도한다. 회차 종료는 패배, 목표 콘텐츠 완료 후 오브 제작, 또는 명시적 운영 중단이다. 관찰한 최대 일차와 중단 이유를 보고하며 무한히 가능한 이론적 생존 상한을 주장하지 않는다.
7. 경제 수지, 기지별 물류, 일차별 압력/피해, 해금 소요시간, 중단 원인을 표로 정리한다. 밸런스 제안과 재현되는 논리 결함을 분리하고 변경 전후 별도 회차로 비교한다. 개발일지와 GitHub 문서를 갱신한다.

진행 중 수집: `20261003-survival-improved-01`, 10번째 밤까지 우선 관찰하고 다음 안전한 낮에 평가한다. [개선 회차의 실제 상태와 고정 체크포인트](../Validation/2026-10-03-survival-improved-live.md). 정상 기준 회차는 3일차 오브 제작·동일 씬 저장 복원까지 완료했다. [기준 회차 결과와 개선](../Validation/2026-10-03-survival-baseline.md). 수집기 QA 두 회차는 정상 생존 데이터와 계속 구분한다.

## 콘텐츠 참여 검증 보완

전체 정의의 설치와 실제 공격 작동을 별도 집계한다. 3일차 개선 회차에서 모든 정의 설치는 확인했으나 테슬라·EMP·대공 2종·기존 포탑 4종의 작동 신호는 아직 없다. 오류로 단정하거나 전체 전투 검증 완료로 처리하지 않는다. 고정 장기 회차의 방어 구성을 유지하며 추가 참여를 관찰한다.

종료 시에도 참여가 없으면 같은 캠페인 씬의 별도 정상 회차에서 해당 방어를 먼저 배치해 자연 공세/보스와의 작동을 확인한다. 일반 공세는 지상 적이고 현재 유일한 자연 공중 적은 최초 보스이므로, 대공 검증에는 보스 전 배치가 필요하다. 해당 회차를 장기 생존 회차의 일수에 합치지 않으며 적 종류·체력·시간을 주입하지 않는다. 현재 배치와 사거리의 영향을 먼저 확인하고, 미정 경제 정책이나 적 구성 변경은 수치 확정 없이 관찰과 개선 제안으로 구분한다.
