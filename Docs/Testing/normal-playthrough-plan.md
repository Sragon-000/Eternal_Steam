# 정상 플레이 내부 테스트 — 실행 전 점검

상태: 정상 기준·10공세 장기·콘텐츠 보완 회차의 수집과 최종 감사를 완료했다. 무기13종 참여, 같은 씬 저장 복원, 관측 부하 비교와 밸런스 우선순위를 정리했다. 열차 대기 방전 및 숨은 독 입력 잠금 수정 후 현재 씬297/297·실제 Play14/14 통과. [종합 결과](../Validation/2026-10-03-normal-playthrough-results.md). 아래 단계별 서술은 실행 당시 계획/경과이며 현재 상태는 이 요약과 최종 결과를 따른다. 제품 내부 플레이이며 학술 연구 실험은 아니다.

## 현재 확인한 제약

- `OpenWorldSandbox`는 기지별 재고·캠페인 저장이 없는 호환 씬이다. 정상 플레이 요청에 따라 기존 캠페인 `StartRegionSandbox`를 최초 한 번 선택하고 이번 회차의 테스트 씬으로 고정했다. 실행기는 다른 씬을 열거나 자동 순회하지 않는다.
- 기존 캠페인 `StartRegionSandbox`는 시작 기지, BasePlanningRules, StartRegionAssault를 참조한다. ConstructionCosts/UpgradeCosts 참조는 비어 있어 현행 일반 건설·강화 무료 정책을 사용한다. 이를 유료 비용이 균형 잡힌 게임으로 평가하면 안 된다.
- StartRegionAssault 정적 설정: 목표 1,000,000 내부 단위, 셀 에너지 10,000, 추출 10/초, 일반 적 처치 보상 1,000, 첫날 일반 적 예산 100, 이후 일차당 25 추가, 소환 간격 0.2초, 보스 체력 1,000. 실제 적용 구성은 회차 시작 시 다시 기록한다.
- MapEnergyState는 90%에 도달한 뒤 밤 조건에서 보스 단계로 진행하고 보스 처치가 나머지 10%를 준다. 오브 제작 시 Cleared가 되며 공세를 멈추고 남은 적을 무보상 정리한다. 클리어 후 적 없는 시간을 오래 보내는 것을 생존 난이도 성과로 계산하지 않는다.
- 과거 첫 회차 자료는 정상 시뮬레이션 Tick과 HUD 명령으로 자연 생산·철 30 운송·보스·제작을 확인했지만 이번 버전의 장기 생존 기록을 대신하지 않는다.

## 실행 순서

1. 한 씬에 고정하고 초기화/생산/전력/건설·강화/자원 소유권/적 도달·피해/기지 손실/운송/보스/오브/저장·실패 복구의 전체 경로를 코드와 데이터로 감사한다. 진행 불가·중복 결제·자원 소실·무한 생성·소프트락은 수집 전에 수정한다.
2. 고정 버전·설정의 회차 ID와 격리 저장 루트를 만든다. 실행 중 규칙을 고치면 해당 회차를 중단·보존하고 새 회차로 다시 시작한다. 임의 재고/에너지/체력/낮밤 주입을 금지한다.
3. 실제로 제공되는 콘텐츠 목록을 카탈로그에서 추출한다. 건설/강화·기지 확장·철도 운송·기차 화물/방어·방어 건물 역할·보스·오브를 사용한다. 미구현 기획 콘텐츠는 완료 목록에서 제외하고 누락 사유를 기록한다.
4. 이벤트와 주기 표본을 함께 남긴다. `runId, utc, realtime, gameSeconds, day, phase, action, baseId, buildingId, routeId, resource, before, delta, after, reason, screenshot` 키로 비용·생산·소비·손실을 연결한다. 재고·전력·적 생성/처치/잔존·피해·연료·적재/하역·배송량·대기 사유를 수집한다.
5. 낮밤 전환/해금/추가 기지/첫 배송/위험 상황/보스/실패/완료에 화면을 보존한다. 긴 구간도 일정 간격으로 캡처하여 상태를 복원할 수 있게 한다. 자동 행동이나 시간 가속을 사용하면 배율·행동 규칙·사용 구간을 명시하고 수동 입력과 구분한다.
6. 모든 현재 콘텐츠를 경험한 후에도 제작 전에는 웨이브가 지속되므로 방어·보급을 유지해 생존을 시도한다. 회차 종료는 패배, 목표 콘텐츠 완료 후 오브 제작, 또는 명시적 운영 중단이다. 관찰한 최대 일차와 중단 이유를 보고하며 무한히 가능한 이론적 생존 상한을 주장하지 않는다.
7. 경제 수지, 기지별 물류, 일차별 압력/피해, 해금 소요시간, 중단 원인을 표로 정리한다. 밸런스 제안과 재현되는 논리 결함을 분리하고 변경 전후 별도 회차로 비교한다. 개발일지와 GitHub 문서를 갱신한다.

완료된 장기 수집: `20261003-survival-improved-01`, 10번째 밤까지 관찰하고 다음 안전한 낮에 정상 종료·복원·감사했다. [개선 회차의 실제 상태와 고정 체크포인트](../Validation/2026-10-03-survival-improved-live.md). 정상 기준 회차는 3일차 오브 제작·동일 씬 저장 복원까지 완료했다. [기준 회차 결과와 개선](../Validation/2026-10-03-survival-baseline.md). 수집기 QA 두 회차는 정상 생존 데이터와 계속 구분한다.

## 콘텐츠 참여 검증 보완

전체 정의의 설치와 실제 공격 작동을 별도 집계한다. 3일차 개선 회차에서 모든 정의 설치는 확인했으나 테슬라·EMP·대공 2종·기존 포탑 4종의 작동 신호는 아직 없다. 오류로 단정하거나 전체 전투 검증 완료로 처리하지 않는다. 고정 장기 회차의 방어 구성을 유지하며 추가 참여를 관찰한다.

관측 보정: 기존 포탑 4종은 공통 Shot 이벤트를 발생시키지 않으므로 별도 `HordeTower.shot`을 읽는다. 5일차 시작의 실제 카운터는 모두 0이었다. 이후 사거리/표적 종류별 기회와 카운터를 함께 기록하며, 오브 제작에 따른 카운터 초기화 전에 최종 값을 보존한다. 이전 공통 이벤트 0을 비활동 증거로 소급 사용하지 않는다.

종료 시에도 참여가 없으면 같은 캠페인 씬의 별도 정상 회차에서 해당 방어를 먼저 배치해 자연 공세/보스와의 작동을 확인한다. 일반 공세는 지상 적이고 현재 유일한 자연 공중 적은 최초 보스이므로, 대공 검증에는 보스 전 배치가 필요하다. 해당 회차를 장기 생존 회차의 일수에 합치지 않으며 적 종류·체력·시간을 주입하지 않는다. 현재 배치와 사거리의 영향을 먼저 확인하고, 미정 경제 정책이나 적 구성 변경은 수치 확정 없이 관찰과 개선 제안으로 구분한다.

초기 준비 시점의 기록: 후속 명령은 `Tools/Testing/Balance/FocusedContentActions.cs`에 준비했다. `content-coverage`라는 별도 정상 회차 경로에서만 동작한다. `PrepareCore`는 정상 비용/강화/배치 검사를 사용해 메인 테슬라·EMP, 보스 접근 방향의 추가 기지·발전기·벌컨/하늘 플라즈마를 설치한다. 초기 단거리 참여를 관찰한 뒤 `AddLegacyRing`으로 기존 포탑 4종을 정상 지면 배치한다. 실제 배치 위치·운영 상태·전력과 자연 적 접근은 실행 때 확인한다. 현재는 컴파일과 장기 회차 경로 거부까지만 검증했으며 설치/전투 인수가 아니다.

장기 회차 종료 명령도 일반화했다. 살아 있는 적/미소환 예산이 없을 때만 오브 제작하며, 기존 포탑 카운터를 먼저 보존해 보조 기록기를 종료한다. 실제 일차·처치 수를 기록하고 필요한 경우 정상 계속 진행 명령으로 정차를 마친 뒤 저장한다. 철도가 없거나 여러 노선인 경우도 처리한다. 현재 회차에서는 아직 제작/종료하지 않았다.

## 콘텐츠 보완 1차 종료 후 조정

별도 정상 회차에서 테슬라/EMP 신호는 확인했으나 첫 공세에 메인 기지가 파괴됐다. [실패 근거와 다음 배치 조건](../Validation/2026-10-03-content-coverage-01.md). 건설 영역 중심이 실제 메인 기지 방어 사거리 안인지 확인해야 하며, 다음 회차는 기존 포탑 4종도 첫 공세 전에 배치한다. 대공 2종/기존 포탑 4종은 아직 미확인이다. 기존 회차와 원본을 수정하거나 실패를 생략하지 않는다.

## 콘텐츠 보완 2차 실제 적용

`20261003-content-coverage-02`는 두 기록기를 건설 전에 연결한 정상 회차다. 기존 포탑 4종을 실제 메인 기지로부터 7.07~11.40m에 공세 전에 배치했다. 테슬라 4개 Lv5는 10.30~13.93m, EMP Lv3는 21.21m다. 모두 정상 운영/전력 공급을 실제 표본에서 확인했다. 테슬라/기존 포탑은 후보 거리 16m 제한을 적용한다. EMP의 첫 16m 제한은 정상 겹침 거부로 실패해 남은 건설만 별도 명령으로 이어가고 24m까지 허용했다(강화 사거리 30m). [실제 위치 표](../Measurements/Balance/20261003-content-coverage-02/initial-defense-placement.json), [개입 기록](../Measurements/Balance/20261003-content-coverage-02/placement-adjustment.json).

제품 소스와 공세·자원 수치를 변경하지 않았고 기존 회차를 다시 열지 않았다. 전투 참여와 생존 결과는 아직 진행 중이며 성공으로 선기록하지 않는다. [회차 프로토콜](../Measurements/Balance/20261003-content-coverage-02/protocol.json).

## 최종 실행 대조

콘텐츠 2차도 두 자연 공세·정상 제작·실제 같은 씬 복원·전체 감사를 완료했다. 기존 포23회 등 남은 참여 공백이 해소됐다. 방향 성분의 미세 오차는 엄격 실패/허용 기준 검토로 분리했고 완료 상태 ABBA도 종료했다. [콘텐츠 최종 검증](../Validation/2026-10-03-content-coverage-02.md), [입력 잠금 수정](../Validation/2026-10-03-hidden-dock-input-fix.md). 기록/제안/적용/제한은 종합 보고서에서 구분하며 최종 main 게시 확인은 개발일지에 남긴다.
