# 정상 생존 기준 회차 — 관찰 메모

회차 종료·집계·수정 검증은 [최종 기준 회차 기록](../Validation/2026-10-03-survival-baseline.md)을 따른다. 아래는 실행 중 관찰 메모이며 장기 개선 회차는 아직 미실행이다.

회차: `20261003-survival-baseline-01`. 기준 코드 `941c7da`, StartRegionSandbox 고정, 실제 시간 배율 1, 무한 자원 OFF. 명령 기반 플레이 자동화로 정상 구매·건설·HUD 동작을 호출한다. 사람의 마우스 조작 속도나 일반 초보 플레이를 모사한 결과는 아니다. 학술 비교 실험이 아니다.

## 확인한 진행

- 초기 메인 Lv3·철 2기/석탄 1기·발전/방어 → 추가 기지 Lv3 → 무료 메인 Lv10 해금과 전체 카탈로그 → 철도 건설·방어 장착/강화·철 30씩 배송 → 토대/기존 포탑 4종 → 후방 기지 Lv10으로 포탑 운영 범위·전력 연결.
- 자연 보스 진입 385.00초, 보스 처치/제작 대기 495.35초. 첫날 일반 적 100명, 보스 1명. 2일차 일반 적 125명 추가. 오브는 제작하지 않아 후속 공세가 유지된다.
- 일차·자원 수지는 회차 종료 후 원본 JSONL로 다시 계산한다. 진행 중 수치는 최종 수치로 확정하지 않는다.

## 재현한 문제와 개선 후보

1. **열차 방어의 비전투 방전**: 축전지 200, 소모율 5/s여서 적 없는 낮에도 약 40초 만에 0이 된다. 첫 충전 후 149.33초, 두 번째 충전 후 771.11초의 표본에서 0; 모두 낮·활성 적 0. 첫 야간 전에 방어 능력을 잃는다. 원인은 MobileDefenseRuntime.Tick가 공격 가능한 표적 유무와 무관하게 배터리를 차감하는 것이다.
   - 다음 개선 회차 후보: 유효 표적이 없는 대기에는 소모하지 않고 냉각/기존 발사체 시간은 정상 진행. 표적 접근 시 기존 5/s·200용량·배터리 부족 시 공격 제한은 유지. 충전은 기존 정차·수동 기지 전력 이체 규칙을 유지한다.
   - 현재 기준 회차에는 아직 적용하지 않는다. 적용 시 별도 회차·구성으로 구분하고 빈 탐색, 표적 종류/사거리, 진입 후 차감, 고갈 후 신규 공격 금지, 발사체 마무리, 저장 복원을 검증한다.
2. **무료 해금·수요 부족**: 첫 낮 약 69초에 메인 Lv10까지 도달했다. 7종 일반 광물 대부분의 소비처가 현 구성에 연결되지 않아 잔고 증가만으로 경제가 균형 잡혔다고 할 수 없다. 제품 비용표·정책 미정 상태와 분리해서 제안한다.
3. **후방 토대 비가동**: 외부 건설은 허용되지만 운영 범위 밖 포탑은 정지한다. 이번 플레이에서 후방 기지를 추가해 실제 가동을 확인했다. 지형/토대 겹침으로 거절된 명령도 원본 파일·행동 기록에 유지한다. 게임 결함으로 오인하지 않는다.

## 해석 제한

- `maximumFrameMs`에는 Editor 일시정지 해제·동적 명령 컴파일·한 번에 여러 건설을 확정한 시간이 포함된다. 게임 렌더 성능의 p95/최대값으로 사용하지 않는다.
- ‘전력 미공급’은 운영 영역 밖 소비자와 영역 안 전력 부족으로 분리했다. 초기 토대 포탑의 OutsideArea를 발전량 부족으로 합산하지 않는다.
- 전체 정의 설치는 현재 콘텐츠 존재/사용 경로 확인이다. 모든 개별 무기의 전투 기여도나 미구현 콘텐츠 완료를 의미하지 않는다.
