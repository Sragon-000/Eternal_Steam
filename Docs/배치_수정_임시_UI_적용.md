# 배치 수정 임시 UI 적용

2026-09-16. Downloads의 `배치 수정 임시 UI.md`와 `IMG_0516.png`를 참고해 OpenWorldSandbox의 하단 인벤토리를 변경했다. 원본 첨부 파일은 수정하지 않았다.

## 적용 규칙

- 화면 하단에 가로 건물 인벤토리, 상단 왼쪽에 분류 탭, 오른쪽에 수정·확정을 배치한다.
- **방어 → 자원 → 기타 → 설치** 순서다. 스케치에는 설치/기타 순서가 다르지만 문서의 명시된 순서를 따랐다.
- 처음 열 때와 닫았다 다시 열 때 **방어**로 초기화한다.
- 평소에는 수정 활성 / 확정 비활성(불투명도 0.38). 수정 중에도 수정 버튼을 활성화하고 선택 색상으로 표시하며 확정을 활성화한다. 수정 버튼을 다시 누르면 모든 임시 배치·격자 예약·회수 선택·방향 미리보기를 취소하고 일반 상태로 돌아간다. 이미 설치한 건물은 유지한다. 최신 사용자 요청이 원본 문서의 수정 버튼 비활성 규칙을 대체한다. 확정 성공 후 초기 상태로 돌아간다.
- 새 UI 문서에 따라 빈 수정 작업도 확정으로 종료할 수 있다. 실패한 배치·회수와 미완료 방향 선택은 종료하지 않고 이유를 표시한다.
- 한 줄에 최대 8개, 9번째부터 다음 줄. 넘친 세로 목록은 스크롤한다.
- 등록된 포탑 프리팹이 방어 목록, 토대가 설치 목록에 표시된다. 자원·기타는 현재 오픈월드 등록 항목이 없으므로 빈 상태를 표시한다. 가상의 건물을 추가하지 않는다.
- 수정을 시작한 뒤 인벤토리에서 배치 종류를 고른다. 수정 진입은 회수를 바로 선택할 수 있는 중립 상태이며 이전 배치 종류를 자동 적용하지 않는다. 설치는 임시 배치 후 확정한다.
- 수정 중 기존 토대·포탑 클릭으로 회수 예정 선택/해제하며 확정할 때 회수한다. 토대를 선택하면 위 포탑도 포함한다. 확정 전 실제 점유와 기능은 유지한다. 임시 건물은 다시 클릭하여 개별 제거한다. 하단 회수·방향·이동·제거·선택 해제·취소 버튼은 제거했다.
- 인벤토리 닫기와 Esc/우클릭은 진행 중인 편집을 취소한다. 이미 확정된 배치는 유지한다.
- 적 수량·소환·전투 제어는 오른쪽 위 테스트 패널로 분리했다. 두 패널과 돌출된 분류 탭 모두 카메라/배치 클릭 차단 영역이다.

## 개발 구조

`BuildingInventoryView`는 주입된 건물 항목의 분류·목록·선택 표시를 담당한다. `OpenWorldHud`가 등록 프리팹을 항목으로 변환하고 명령을 전달한다. 실제 배치·회수는 기존 `WorldEditSession`, 입력 상태는 `OpenWorldInput`에 유지한다. 45° XZ 격자와 공통 모듈은 바꾸지 않았다.

## 검증

- 수정 버튼 토글 변경 후 `VerifyBuildingInventoryUI` 재실행 통과: 두 번째 클릭으로 토대·포탑 임시 오브젝트 제거, 포탑 예약 해제 및 같은 셀 재배치, 기존 토대 보존, 방향 미리보기 취소를 확인했다.
- `VerifyBuildingInventoryUI`: 분류 순서, 기본 방어, 빈 분류, 재열기 초기화, 수정/확정 활성 상태, 빈 작업 확정, 토대/포탑 임시 설치·확정, 포탑 회수, 방향 미리보기·취소·확정, 9개 항목의 8+1 줄바꿈 통과.
- `VerifyQuantityFocus`: WASD 수량 충돌 방지, 숫자 입력·포커스 복원, 정확한 소환 통과.
- `VerifyOpenWorldCameraInput`: WASD·휠과 오른쪽 위 UI 입력 차단 통과.
- 캡처로 하단 탭/목록과 오른쪽 수정/확정 배치 확인. 확정 비활성 상태의 resolved opacity 0.38 확인.
- 검증용 Unity Editor에서 수행했으며 게임 빌드는 하지 않았다.

이전 `VerifyDocumentConstruction`의 구형 버튼 이름은 이전 UI 검증 기록이다. 현재 화면의 수용 검증은 `VerifyBuildingInventoryUI`를 사용한다.

## 클릭 회수 변경 검증 (2026-09-16)

`VerifyBuildingInventoryUI` 재실행 통과. 포탑 클릭 선택/해제, 수정 취소 시 점유 유지, 확정 시 포탑만 회수, 토대와 위 포탑 일괄 회수 선택/해제/취소/확정, 빈 토대 회수, 보조 버튼 제거, 새 배치와 임시 취소를 확인했다. 위의 방향 버튼 관련 검증과 기존 캡처는 이전 UI 기록이다. 현재 UI에는 해당 버튼이 없다.

토대 회수는 토대 존재와 위 포탑 전체를 다시 검증한 뒤 실행한다. 회수 불가 포탑이 있거나 선택 후 구성이 바뀌면 전체 확정을 보류한다. 회수와 새 배치는 같은 작업에 섞지 않으며 빈 회수 세션은 설치 확정을 가로막지 않는다.

## 콘텐츠 등록 후 갱신 (2026-09-17)

자원 분류에는 7종, 방어 분류에는 새 9종과 기존 4종이 표시된다. 빈 분류 검증은 기타 탭을 사용한다. 오른쪽 테스트 패널은 하단 인벤토리와 겹치지 않는 스크롤 영역이다. [콘텐츠 적용 결과](자원_방어_건물_적용_결과.md).
