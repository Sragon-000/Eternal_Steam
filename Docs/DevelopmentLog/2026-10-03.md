## 검증과 문제 해결

- 최적화 단계 기존 EditMode 303/303·PlayMode 4/4 통과 후, 개편한 현재 씬 실행기로 **285/285**, 반복 UI **35/35** 통과.
- 적 3,000회 무작위 연산의 기존 구현 일치, 9개 격자 메시 완전 일치, 현재 씬 적 1,000개 성능 QA 통과.
- 최초 밀집 QA는 수동 정리가 늦어 기지 패배가 발생함. 자동 정리 도구로 교체하고 재검증했으며 실패 기록 보존. 정상 생존 데이터로 사용하지 않음.
- NUnit 일반 실행기/컨텍스트 초기화와 UI 비직렬화 상태 누출 문제를 보완. 최종 씬 핸들·파일 바이트·dirty 상태 보존을 확인함.
- 최적화·테스트 개편 종료 당시 에디터 상태: OpenWorldSandbox, Play 꺼짐, dirty=false, 저장 격리 해제, 원래 백그라운드 설정 복구, 테스트 버튼 활성.

- 호환 씬 OpenWorldSandbox에는 캠페인 저장/시작 기지가 없어 정상 플레이를 시작하지 않았다. 후속 회차 준비에서는 기존 캠페인 StartRegionSandbox를 한 번 선택하고 테스트 대상으로 고정했다. 검사 도구의 자동 씬 전환은 계속 금지한다. 실제 최대 관측 일차와 실패/완료 조건을 기록하며 수집 전 밸런스 개선 완료를 주장하지 않는다.

### 후속 로직 사전 확인

캠페인 씬의 일반 건설·강화 비용 참조가 비어 있는 현행 무료 정책과 오브 제작 후 공세 종료를 확인했다. 무료 정책을 유료 경제 밸런스 검증으로, 클리어 후 경과 시간을 생존 성과로 혼동하지 않도록 [정상 플레이 실행 전 계획](../Testing/normal-playthrough-plan.md)에 조건과 기록 스키마를 남겼다. 실제 회차는 아직 실행하지 않았다.

### 정상 생존 회차 준비 후속

캠페인 카탈로그 24개 정의·모듈·설치 조건을 다른 씬을 열지 않고 감사했다(정의 오류 0). 재고 순변화만으로는 총생산/소비를 놓치는 문제를 해결하기 위해 자원 은행과 기지/건물 생명주기에 선택적 관측 이벤트를 추가했다. 오류가 난 관측자는 경제·등록 동작에서 격리한다. 기존 규칙·비용 수치는 유지했다.

관측 회귀 7개를 추가해 전체 **292/292** 통과, 현재 씬/파일/dirty 상태 보존을 확인했다. 검사 결과 경로를 선택할 수 있도록 하고 반복 실행 결과를 덮어쓰지 않도록 보완했다. 초기화 설정·JSONL 이벤트/1초 표본·상황별 스크린샷을 담당하는 수집 도구는 컴파일까지 확인했다. 상세 근거와 실제 통합 검증 잔여 항목은 [회차 사전 감사](../Validation/2026-10-03-playthrough-preflight.md)에 있다. 실제 생존 회차나 연구 실험은 아직 시작하지 않았다.

- 두 번째 회차: 정상 강화/건설 명령과 전체 면적 포함 검사로 생산기를 설치. 34 표본·2장 캡처, 자연 철 생산 15건·15개를 기록하고 최종 재고와 대조했다.
- 두 데이터셋의 연속 이벤트, 모든 화면 요청과 파일·해시, 재고 일치, 관측 오류 0, 종료 시 대기 캡처 0을 검사했다. 대표 화면도 직접 확인했다. [검증 상세와 제한](../Validation/2026-10-03-playthrough-preflight.md), [원본 기록](../Measurements/Balance).
- 최종 상태: StartRegionSandbox 한 씬, Edit 모드, dirty=false, 저장 경로·일시정지·백그라운드 설정 복구. 실제 장기 생존, 전투·물류 데이터 수집, 관측 부하 A/B는 남아 있다. 학술 연구 실험은 시작하지 않았다.
