2. **전체 구조 평가**: 실제 게임 조립/모듈/레거시/렌더링/UI/저장/패키지·텍스처 경로 검토. 이름만 바꾸는 이동이나 근거 없는 패키지·Collider 삭제는 하지 않음. [구조 평가와 최적화](../Validation/2026-10-03-project-performance.md).
3. **측정 기반 최적화**: Play 중 TWC 페인트 Gizmo 차단, 생존 적 비트셋·사용 버킷만 초기화, 건설 격자 프레임 분할, 숨은 UI 갱신 제한·설명 높이 캐시. 동일 Editor 전투 프레임 중앙값 82.96→7.77ms, 건설 85.29→8.03ms. 배포 성능 보장과 구분.
4. **테스트 전면 재구성**: 현재 씬 고정, 다른/Preview/임시 씬 전환 제거, 중복 씬 사례 통합, 과거 자동 씬 이동 도구 25개 원문·해시 보관. T0~T5 검사 체계·285개 인벤토리 작성. [변경·검증 기록](../Validation/2026-10-03-test-restructure.md), [운영 기준](../Testing/README.md).
5. **검증 기록 보존**: 변경 전 소스·해시, Profiler 원시 수치, 회귀 XML, 실패 시도, 저장 fixture, 해상도/입력/화면 캡처를 모두 프로젝트 안에 유지. 사용자 테스트 UI는 남겼고 정상 자원 규칙을 바꾸지 않음.

## 검증과 문제 해결

- 최적화 단계 기존 EditMode 303/303·PlayMode 4/4 통과 후, 개편한 현재 씬 실행기로 **285/285**, 반복 UI **35/35** 통과.
- 적 3,000회 무작위 연산의 기존 구현 일치, 9개 격자 메시 완전 일치, 현재 씬 적 1,000개 성능 QA 통과.
- 최초 밀집 QA는 수동 정리가 늦어 기지 패배가 발생함. 자동 정리 도구로 교체하고 재검증했으며 실패 기록 보존. 정상 생존 데이터로 사용하지 않음.
- NUnit 일반 실행기/컨텍스트 초기화와 UI 비직렬화 상태 누출 문제를 보완. 최종 씬 핸들·파일 바이트·dirty 상태 보존을 확인함.
- 에디터 종료 상태: OpenWorldSandbox, Play 꺼짐, dirty=false, 저장 격리 해제, 원래 백그라운드 설정 복구, 테스트 버튼 활성.
