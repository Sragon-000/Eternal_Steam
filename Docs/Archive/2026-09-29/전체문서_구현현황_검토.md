## 범위와 판정 기준

보관 원본 Markdown 12개·참고 이미지 1개를 inventory로 확인하고 원본 해시 13개를 검증했다. 기차 이외 Markdown 10개의 요구, 기존 적용결과/후속 결정, 주요 코드·정의 자산을 대조했다. [범위 기록](../../Validation/2026-09-29-all-documents-review.json). 이미지의 픽셀 단위 시각 대조와 모든 원문 요구의 개별 실기 인수는 이번에 하지 않았다. 문서가 존재하거나 과거 테스트가 통과한 사실만으로 전체 구현 완료를 선언하지 않는다.

- **핵심 구현:** 해당 모델/기능 경로가 실제 소스에 존재. 전 항목 실기 완료와 다르다.

- **미구현:** 현재 실행 구조에 필요한 상태·명령·연결이 없다.
- **변경/기획 대기:** 후속 결정이 원문을 대체했거나 정책·수치를 정해야 한다.

## 원문과 후속 결정의 충돌

- 4. 기지 MAIN-004의 ‘맵별 독립 Lv.1’은 4.1의 ‘모든 맵 공유 레벨’로 대체됐다. 공유 모델은 있고 실제 캠페인 이동은 없다.
- 방어 원문의 부채꼴 수동 방향은 후속 원형 자동 공격 요청으로 변경됐다. 일부 원문 무기 표의 각도와 설명도 서로 다르므로 수치를 무조건 원복하지 않는다.
- 방어 종류 문서의 정수 강화 예시는 ‘3.9→4’지만 설명은 정수 증가량 누적이다. 현재 PerformanceUpgrade.Count는 내림을 사용한다. 이 부분은 원문 해석 충돌로 명시하고 기준을 확정해야 한다.
- 날짜별 적 능력치 증가는 일정에서 검토/미적용으로 남겼고, 현재 MapAssaultSettings도 DAY와 무관한 검증 능력치를 쓴다. 물량 증가와 능력치 증가는 구분한다.
- 단일 맵 저장은 구현됐다. 9월20일 문서의 ‘저장 없음’ 문구를 최신 상태로 인용하지 않는다. 반대로 단일 맵 저장을 다중 맵 저장 완료로 확대하지 않는다.
- Editor Play 자동 새 게임은 최신 사용자 요청에 따른 시작 정책이며, 현재 게임 빌드의 이어하기 정책과 별개다.

## 권장 후속 순서

1. 현재 단일 맵의 안정화 인수: 저장·재시작·기지 파괴/회수·기차 복구. 기존 기차 UI A2~A4를 포함해 실제 플레이 흐름 완성.
