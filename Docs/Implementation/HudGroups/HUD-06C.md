# HUD-06C · 연결·노선 편집

상태: 완료

## 적용

- 연결 화면: 출발/도착 역·연결구 선택, 경로·신규/재사용 선로·비용·지불 기지 요약, 경로 확인/연결 확정/취소.
- 편집 화면: ‘역 순서’와 ‘구간·오류’ 페이지. 정차역 직접 선택/이전·다음 페이지/추가/삭제/이동/첫 역, 기존 순환 노선의 연결구·지도 포트 선택과 순환 열기·닫기, 오류 선택을 유지한다.
- 검증 후 확정, 편집으로 복귀, 미저장 변경 유지/폐기를 독립 화면으로 보여준다. 주요 행동은 스크롤 밖에 고정한다.
- 편집 패널은 화면 오른쪽 최대 560px/너비 60%로 제한해 왼쪽 지도 입력 영역을 남긴다. 본문 스크롤, 18px 실효 글자, 기존 스프라이트/스타일을 사용한다.
- 두 씬에 37개 명령 표시 버튼과 영구 콜백을 저장한다. 원래 RailwayHud 명령/초안/경로/결제/예약 상태를 그대로 사용한다. 코어 규칙과 연구 실험은 변경하지 않는다.

## 검증 기준

- [x] 두 씬 정적 계층·명령·원본 참조 확인
- [x] 실제 연결 미리보기/취소 무변경, 신규 선로만 결제, 중복 확정 방지
- [x] 지불 기지 변경·자원 부족 거부
- [x] 새 노선 검증/계속 편집/확정, 중복 기차 방지
- [x] 역 순서·물리 정차 위치 유지, 점유 역 삭제 제한, 초안 폐기
- [x] 그룹 전환 초안 유지, 운행 중 첫 역 고정, 예약 취소·스냅샷 복원·적용
- [x] 실제 복귀 선로로 구성한 기존 순환 노선의 포트 오류 선택·수정
- [x] 4해상도 × 5화면의 실제 글자·버튼·지도 입력 확인
- [x] 최종 회귀·편집 환경 복구·증거 기록
