# HUD-06 · 철도 관리 재구성

상태: 완료 (06A/06B/06C 적용 및 단계 검증 완료)

내부 순서: **06A 목록·운행 → 06B 화물·방어 → 06C 연결·노선 편집**. 한 번에 전체 RailwayHud를 갈아엎지 않고 표시 단위별로 교체한다.

- 06A: 목록+선택 노선, 좁은 화면 목록→상세, 현재/다음 역·연료·화물 요약, 상태별 주요 행동과 비활성 이유.
- 06B: 단일 화물 자원 표시/최초 지정, 선택 역의 적재/하역 입력·적용, 정차 제한, 방어 상세 진입·복귀. 이동 중 화물 예약이나 여러 역 원자적 일괄 저장을 새로 약속하지 않음.
- 06C: 역 연결의 경로/비용/지불 기지 확인과 선로 건설 확정, 운행 노선 설정, 정차역 편집, 오류 위치, 예약 적용/취소. 기존 왕복 기본·레거시 기능 접근 유지.

완료 기준: 기능 대응표의 모든 기존 행동에 접근 가능. 제목/버튼/입력/안내의 동일 글자 기준과 실효 배율 확인. 정차/이동/정지 요청/연료 부족/역 진입 대기/오류/예약 상태에서 코어와 버튼 판단 일치. 초안·입력 유지, 취소 의미, 중복 결제 방지, 저장 재로드를 검증한다.

산출물: 새 철도 표시 계층과 상태 바인딩, 상태별 화면/집중 회귀 결과. 코어의 결제/운행/저장 규칙은 바꾸지 않는다.
