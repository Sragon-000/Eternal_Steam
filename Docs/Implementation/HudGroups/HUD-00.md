# HUD-00 · 현재 기능과 최종 배치를 고정

상태: 완료

작업: 최신 두 씬의 실제 계층/콜백/활성 상태를 읽고 모든 HUD 명령을 새 위치에 대응시킨다. 기존 철도 76개 버튼은 과거 기준 수량이므로 실제 수와 비교한다. 현재 CanvasWorldHud/CanvasHudLayout/GameplayHudWorkspace 및 RailwayHud, 입력·미니맵의 책임을 매핑한다. 1920×1080과 800×600의 전투/건설/철도 화면 배치를 작성한다. 기존 테스트 UI 및 미완료 기능의 접근 경로도 포함한다.

완료 기준: 기존 명령의 누락 없는 대응표, 그룹별 소속/출입 방향, 공통 영역, 좁은 화면 전환 규칙이 문서와 시안에서 일치한다. Tab과 IME/입력 필드 처리, 미니맵 지면 교차 실패의 대체 처리까지 정한다. 미정 항목은 후속 단계로 무심코 넘기지 않는다.

산출물: 범위별 작업 전 사본/해시, 기능 대응표, 두 크기 배치 시안, 새 인수 목록. 필요한 단순 와이어프레임으로 시작하며 새 아트 제작을 선행 조건으로 삼지 않는다.
