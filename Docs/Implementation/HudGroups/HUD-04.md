# HUD-04 · 기지 목록과 재고 아코디언 적용

상태: 완료 (단계 범위; 전체 UI 최종 인수는 HUD-07)

작업: 활성 기지 목록을 stable ID로 연결하고 선택 행 바로 아래에 해당 재고를 펼친다. 자원 아이콘·이름·수량·스크롤을 공통 스타일로 표시한다. 조회 기지와 결제 기지의 상태를 분리하고 목록 갱신/기지 소실/빈 상태/그룹 복귀를 처리한다. 정적 행 템플릿과 재사용할 목록 슬롯은 씬/프리팹에 작성하며 기존 계층 원칙을 지킨다.

완료 기준: 서로 다른 재고의 두 기지를 전환했을 때 정확한 재고 표시. 조회 클릭으로 지불 기지와 예약이 바뀌지 않음. 한 행 펼침/접힘과 스크롤 정상. 기지 파괴 후 오래된 참조로 재고가 표시되지 않음. 실시간 생산 갱신 중 선택/스크롤 유지.

산출물: 저장 계층/조회 바인딩, 두 기지 재고 비교와 생명주기 검증 기록.
