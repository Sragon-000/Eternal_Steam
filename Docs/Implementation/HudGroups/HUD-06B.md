# HUD-06B · 화물·방어 화면

상태: 완료

## 적용 범위

- 기존 운행 화면의 화물·방어 행동에서 같은 외곽 패널의 전용 상세 화면으로 이동한다.
- 화물 자원 최초 지정 및 고정 상태, 선택 역, 적재·하역 수량, 선택 역 적용을 분리한다. 원래 TMP 입력 필드를 이동해 입력과 명령의 권한을 RailwayHud에 유지한다.
- 운행 화면 복귀와 전투/건설 그룹 전환은 작성 중인 입력을 유지한다. 다른 역 선택은 기존 동작대로 그 역의 저장 값을 표시하며 미적용 입력 초기화를 화면에 명시한다. 여러 역 초안이나 이동 중 예약 저장은 추가하지 않는다.
- 방어칸 크기·후보·장착·해제·강화·충전, 비용·환급·축전지 상태와 비활성 이유를 모은다. 실행 가능 여부와 결제는 기존 코어를 따른다.
- 고정 복귀 버튼과 스크롤 본문을 분리한다. 글자는 실효 18px, 작은 화면은 스크롤 안내를 제공한다.
- 두 실제 씬에 정적 계층·입력 참조·영구 콜백을 저장한다. Play 중 UI 생성은 하지 않는다.

## 검증 기준

- [x] 두 씬의 입력 참조와 8개 서비스 명령, 복귀 콜백 저장
- [x] 최초 화물 지정·잘못된 수량·역별 적용·입력 보존 Play 검증
- [x] 방어 설치 중복 결제 방지·강화 비용·전력 보존·환급 없음 검증
- [x] 실제 이동 중 변경 제한 및 화물·방어 스냅샷 복원
- [x] 4해상도 클릭 영역·스크롤 접근·18px 확인
- [x] 최종 회귀와 편집 환경 복구
