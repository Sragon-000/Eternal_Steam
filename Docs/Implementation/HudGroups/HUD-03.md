# HUD-03 · 근거리 미니맵 적용

상태: 검증 중

작업: 화면 중앙 시선과 지면의 교차점을 표시 중심으로 계산한다. 기존 투영의 중심/범위 입력을 통일해 지형·기지·적·카메라 영역·클릭 변환이 같은 150×150을 사용하게 한다. 맵 밖은 빈 배경, 바깥 마커는 표시 영역에서 제외한다. 이동마다 전체 지형 텍스처를 재생성하는 비용이 발생하는지 확인하고 기존 지형 데이터 재사용/UV 갱신 등 적합한 방법을 선택한다.

완료 기준: 카메라 이동/회전/줌에서 시야 중심 일치, 폭·높이 각 150 유지, 맵 끝에서 중심 강제 이동 없음. UI→월드→UI 좌표 왕복 오차를 검증하고 맵 밖 클릭은 유효한 이동으로 처리하지 않음. 지면 교차 실패에도 잘못된 좌표/NaN/점프 없음. 기존 방향 표현은 불필요하게 바꾸지 않는다.

산출물: 투영/표시 수정, 중심·경계 좌표 검사, 이동 전후 화면 증거. 제품 기능 검증이며 연구 성능 실험은 아니다.

## 결과 기록

시야 중앙 광선의 지면 교차를 중심으로 150×150 월드 투영을 적용했다. 전체 지형 텍스처는 초기 1회 만들고 현재 표시 영역을 UV로 잘라 그린다. 마커와 클릭 좌표도 같은 투영을 사용하며 맵 밖 클릭은 거부한다. 이동 추종 및 투영 왕복 검사는 통과했다. HUD-07에서 줌별 중심과 텍스처 재사용, 맵 밖 클릭/드래그 거부, 지면 교차 실패 fallback을 검증했다. 맵 끝의 유효 클릭/연속 드래그와 적 밀집 상태 비용은 최종 인수에 남긴다.
