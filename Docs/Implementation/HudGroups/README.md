# HUD 그룹 개편 실제 작업 문서

기준: [프로젝트 통합기준 §7.3.16](../../프로젝트_통합기준.md). 단계별 적용·증거는 이 문서 묶음에서 관리한다. 연구 실험은 실행하지 않는다. 기존 테스트 UI는 ON 유지.

| 작업 | 범위 | 상태 |
|---|---|---|
| [HUD-00](HUD-00.md) | 현재 기능과 최종 배치를 고정 | 완료 |
| [HUD-01](HUD-01.md) | 실제 씬의 그룹 구조와 공통 스타일 적용 | 검증 중 |
| [HUD-02](HUD-02.md) | Tab 전환·이징·입력 보호를 완성 | 검증 중 |
| [HUD-03](HUD-03.md) | 근거리 미니맵 적용 | 검증 중 |
| [HUD-04](HUD-04.md) | 기지 목록과 재고 아코디언 적용 | 완료 |
| [HUD-05](HUD-05.md) | 건설 메뉴와 편집 흐름 통합 | 완료 |
| [HUD-06](HUD-06.md) | 철도 관리 재구성 | 완료 · 06A/06B/06C |
| [HUD-07](HUD-07.md) | 통합 인수와 적용 완료 기록 | 진행 중 |
| [HUD-08](HUD-08.md) | 원형 미니맵·Esc 메뉴·건설 화면 축소 | 완료 · 08A~E 로컬 인수 |

실행 순서: HUD-00 → 01 → 02 → 03 → 04 → 05 → 06 → 07. 각 단계의 체크리스트와 실제 결과를 구분한다. GitHub 이슈 생성 여부는 사용자 답변 대기.

첫 적용 묶음: 그룹/입력/근거리 미니맵. 이후 작업은 HUD-04 기지 자원, HUD-05 건설, HUD-06 철도, HUD-07 최종 인수 순서다. 미인수 항목은 각 문서에 명시한다.

HUD-04 적용·단계 검증 완료: [기지 자원 검증 기록](../../Validation/2026-10-02-hud-04-base-resources.md). HUD-05도 완료했다.

HUD-05 적용·검증 완료: [건설 흐름 검증 기록](../../Validation/2026-10-02-hud-05-construction-workflow.md). 다음 작업은 HUD-06A 목록·운행이다.

HUD-06A 완료: [목록·운행 검증](../../Validation/2026-10-02-hud-06a-railway-overview.md). 후속 HUD-06B도 완료했다.

HUD-06B 완료: [화물·방어 검증](../../Validation/2026-10-02-hud-06b-railway-services.md). 후속 HUD-06C도 완료했다.

HUD-06C 완료: [연결·노선 편집 검증](../../Validation/2026-10-02-hud-06c-railway-editor.md). 다음 작업은 HUD-07 통합 인수다.

HUD-07 진행 중: [통합 검증 및 미인수 항목](../../Validation/2026-10-02-hud-07-integration.md). 전체 283개 회귀와 실제 저장 재로드 검증을 완료하고 화면 인수를 진행했다.

새 요청의 상세 적용계획: [HUD-08](HUD-08.md). HUD-08A 입력/정지 → 08B Esc 메뉴 → 08C 원형 미니맵 → 08D 건설 dock → 08E 통합 인수 순서로 제안한다. 기존 HUD-07 결과는 이력으로 유지한다.

HUD-08A/B 적용: [Esc 메뉴·입력 정지 상태와 검증](../../Validation/2026-10-03-hud-08ab-escape-menu.md). 다음은 HUD-08C 원형 미니맵, HUD-08D 건설 dock 축소이며 HUD-08 전체는 진행 중이다.

HUD-08C 적용·단계 검증 완료: [원형 미니맵 검증](../../Validation/2026-10-03-hud-08c-circular-minimap.md). 295개 회귀와 두 씬 × 7해상도 검사 통과. 다음은 HUD-08D 건설 하단 UI 축소다.

HUD-08D 적용·단계 검증 완료: [건설 하단 UI 축소 검증](../../Validation/2026-10-03-hud-08d-compact-construction.md). 목록/배치 높이는 여백 포함 172/96px로 제한했다. 297개 회귀, 두 씬 × 7해상도, 결제·취소·상세 스크롤 검사가 통과했다. 다음은 HUD-08E 복합 입력·저장·철도 통합 인수 및 실제 OS IME 확인이다.

HUD-08E 로컬 통합 인수 완료: [통합 검증과 Esc 입력 수정](../../Validation/2026-10-03-hud-08e-integration.md). 최종 297개 회귀, 두 씬 × 7해상도, 실제 저장 복원, 순환 노선 편집 35상태, macOS 한글/Tab/Esc 입력을 검증했다. 플랫폼·배포 빌드 확장은 별도 검증 범위다.
