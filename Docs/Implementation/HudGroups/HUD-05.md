# HUD-05 · 건설 메뉴와 편집 흐름 통합

상태: 완료 (건설 단계 범위; 전체 UI 인수는 HUD-07)

작업: 건설 그룹 안의 건설/철도 작업 선택을 적용한다. 건설 분류·건물 카드·선택 정보·비용/지불 기지·확정/취소를 정돈한다. 철도 건설 카드를 공통 건설 분류에서 사용하고 중복 바로가기를 정리한다. 전투 그룹 복귀와 기존 WorldEditSession의 편집 상태를 연결한다.

완료 기준: 단순히 건설 그룹을 여는 것만으로 배치/비용 변화 없음. 카드 선택→미리보기→확정/취소 동작. 철도 탭/전투 그룹 전환 시 미확정 편집 보호. 일반 재고와 자원 무한 ON/OFF에서 기존 비용 검사 유지. 선택 정보/팝업이 필수 조작을 가리지 않음.

산출물: 저장된 건설 작업 UI, 실제 카드/확정/취소/그룹 복귀 기록.
