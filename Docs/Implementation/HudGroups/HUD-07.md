# HUD-07 · 통합 인수와 적용 완료 기록

상태: 진행 중 · 반응형 배치와 통합 회귀 적용

작업: 두 씬에서 저장 참조를 확인하고 전체 EditMode 회귀를 실행한다. 실제 Play에서 전투/건설/철도/테스트 도구와 전환을 검증한다. 800×600, 1024×768, 1280×720, 1920×1080, 2560×1080, 3840×1080, 3840×2160의 7개 해상도를 두 씬에서 확인한다. BaseRules 등 씬 자체의 기능 제한은 명시하고 정상 기능인 것처럼 판정하지 않는다.

완료 기준: 필수 UI 잘림/겹침/의도하지 않은 글자 축소 0, 비표시 UI 입력/월드 관통 0, 초안 유실/중복 결제 0. 긴 역명·최대/잘못된 수량·기지 소실·창 크기 변경·Tab 연타·IME 입력·테스트 조작·저장 재로드를 포함한다. 결과 수/실패/미검증 범위를 기록한다. 이전 ‘개발 UI 숨김’ 검사는 새 테스트 UI 유지 요구에 맞게 교체한다. 전체 통과 수는 실행 결과로만 쓴다.

산출물: `Docs/Measurements/<실행일>-hud-groups/` 아래 단계별 JSON/XML/스크린샷/격리 저장/작업 전 사본, `Docs/Validation/<실행일>-hud-groups.md` 최종 결과. 사용자 일반 저장은 사용하지 않는다. 연구 실험은 실행하지 않는다.

## 결과 기록

Canvas 기준 1280×720와 세로 배율, 전투 미니맵 공간, 목표문 줄바꿈/높이, 자원 패널의 상단 여백, 작은 화면의 테스트 버튼 두 줄 배치, 팝업의 고정 실효 글자 크기와 스크롤 앵커를 두 씬에 적용했다. Tab 왕복 후 수량 입력 포커스를 복원한다.

이번 단계에서 전체 EditMode 283개 통과, Input System Tab/IME 조합 이벤트/드래그 보호 통과, 화물·방어 실제 비용과 운행 제한 통과, 실제 씬 재로드 후 전체 저장 스냅샷 일치를 확인했다. 세부 화면 인수와 남은 범위는 [통합 검증 기록](../../Validation/2026-10-02-hud-07-integration.md)에 기록한다.

OS 한글 입력기의 실제 조합과 적 밀집 상태의 미니맵 갱신 비용은 아직 검증하지 않았다. 자동 IME 이벤트 테스트를 OS 입력기 실증으로 간주하지 않는다. HUD-01~03 및 HUD-07 전체 완료 판정은 남은 인수 이후에 한다. 연구 실험은 시작하지 않았다.
