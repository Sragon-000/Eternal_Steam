# HUD-02 · Tab 전환·이징·입력 보호를 완성

상태: 검증 중

작업: 그룹 상태와 전환 목표를 단일 소유자가 관리한다. 기본 전투, Tab 건설↔전투를 연결한다. 앵커의 화면 안 위치와 가장자리 밖 위치 사이에서 이징한다. 미표시/전환 중 입력 차단, 카메라/월드 입력 관통 방지, 초안·포커스·스크롤 복원, 재입력/일시정지/창 크기 변경을 처리한다. 건설 그룹 진입과 실제 배치 시작을 분리한다.

완료 기준: Tab 1회당 목표 그룹 1회 변경. 연타 시 겹친 애니메이션이나 유실된 상태 없음. 일시정지에서도 완료. 편집 중 전환으로 비용/설치/노선이 자동 확정·삭제되지 않음. 테스트 도구는 열고 닫아도 편집 상태를 유지. 최초 진입과 양방향 전환 모두 검증한다.

산출물: 전환/편집 상태 코드와 집중 회귀, 실제 양방향 전환 기록. 이후 패널은 같은 전환 규칙을 사용한다.

## 결과 기록

Tab/버튼 그룹 전환, 0.24초 이징, 일시정지 중 갱신, 전환 중 월드 입력 차단, 편집 상태 유지, 빠른 방향 반전을 구현했다. 실제 Play에서 그룹 버튼 raycast/PointerClick과 상태 보존을 확인했다. HUD-07에서 실제 OS Tab 왕복, Input System 연타/IME 조합 이벤트, 수량·포커스 복원, 활성 드래그 차단을 확인했다. OS 한글 입력기의 실제 조합 인수는 남는다.
