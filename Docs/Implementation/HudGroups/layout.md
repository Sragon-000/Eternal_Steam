# HUD-00 배치 기준

## 전투

1920×1080: 좌상단 체력/통합 시계, 우상단 미니맵. 상단 중앙 그룹 전환, 우상단 저장/일시정지. 테스트 빠른 조작과 알림은 공통 영역.
800×600: 동일 모서리 배치, 두 전투 열 사이에 게임 시야 유지. 긴 통합 시간 문구는 두 줄 허용. 건설 그룹은 숨김.

## 건설

1920×1080: 좌측 기지/재고, 하단 건설 카탈로그, 우측 선택 상세. 철도 관리로 전환하면 가운데 작업 화면에서 목록/상세를 표시.
800×600: 작업 본문 중심 한 열, 자원/선택 상세 접힘 전환. 필수 뒤로/확정은 고정. HUD-05/06에서 실제 배치 적용.

## 입력·좌표

Tab은 그룹 전환 한 번만 처리, IME 조합 종료까지 요청 보류. 진행 중 드래그는 끝낸 뒤 전환하도록 원인 표시. 숨긴 편집은 초안을 남기고 월드 입력 차단. 그룹 표시만으로 건설 모드를 시작하지 않음.
미니맵 시야 중심은 TerrainCollider와 화면 중앙 광선의 교차점. 지형 밖에서는 카메라 Focus 높이의 수평면 교차점을 사용하며 실패하면 Focus를 사용. 중심을 맵 경계로 강제 이동하지 않음. 기존 north-up 유지.

## 단계 구분

현재 구현 대상은 저장 그룹/Tab/미니맵 기반이며, 이 문서의 좁은 건설 배치·기지 아코디언·철도 화면 분리는 HUD-04~06에서 수행한다. 계획 그림을 실제 인수 증거로 사용하지 않는다.
