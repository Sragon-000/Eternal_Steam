# HUD-01 · 실제 씬의 그룹 구조와 공통 스타일 적용

상태: 검증 중

작업: 기존 Canvas 아래에 전투 그룹/건설 그룹/공통 보조 영역을 저장 계층으로 구성한다. 기존 오브젝트와 참조를 최대한 재사용해 체력·시간·미니맵/건설·철도·자원을 배치한다. 낮밤 시계와 일차·현재 단계·남은 시간을 하나로 통합한다. 공통 글자/여백/앵커와 넓은/좁은 배치를 적용한다. 기존 위치 계산과 새 레이아웃이 같은 RectTransform을 동시에 제어하지 않도록 소유권을 분리한다.

완료 기준: Play 전에도 모든 정적 UI와 참조가 계층에 존재한다. 두 씬에서 영속 콜백/폰트/스프라이트 참조 누락 0. 테스트 UI는 계속 접근 가능하다. 시간 표시 중복이 없고 철도 글자 규칙을 적용할 공통 스타일이 마련된다. 기존 저장 계층을 런타임 생성으로 대체하지 않는다.

산출물: 저장된 두 씬 및 필요한 공통 컴포넌트/참조, 저장 계층 검증. 이 단계의 배치만으로 실제 그룹 전환 인수 완료라고 하지 않는다.

## 결과 기록

두 씬에 CombatGroup/ConstructionGroup과 방향별 슬라이드 호스트를 저장했다. 시간 정보를 ClockPanel로 통합하고 테스트 UI/저장/전환 버튼을 공통 영역에 유지했다. 정적 계층과 콜백, 기본 전투 상태는 EditMode 및 Play에서 확인했다. 작은 창의 최종 글자 가독성과 건설/철도 세부 배치는 HUD-05/06/07과 함께 인수하므로 전체 완료로 표시하지 않는다.
