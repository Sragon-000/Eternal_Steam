# 화물칸 / 포탑 토대칸 v3

2026-10-02 KST · Blender 5.2.1 LTS / Blender MCP

기존 청회색 철판, 검은 프레임, 밝은 보강대, 황동 피팅, 황토색 식별판에 맞춰 C01 개방형 화물칸과 T01 포탑 토대칸을 추가했다. 원본 v1, 바퀴 애니메이션 v1, 연동 애니메이션 v2는 덮어쓰지 않았다. 현재 편성은 기관차 → 화물칸 → 포탑 토대칸이다.

## 파일
- train-a-v3-consist.blend: 기관차와 신규 차량 2개, 기존 연동 애니메이션, 검토 카메라.
- cargo-wagon.blend: CARGO_ROOT가 (0,0,0)에 있는 독립 화물칸. Optional removable steel cargo 컬렉션은 숨기거나 분리 가능.
- turret-foundation-wagon.blend: FOUNDATION_ROOT가 (0,0,0)에 있는 독립 토대칸. 포탑 본체 없음.
- consist.png / wagons.png / wagon-top.png / coupler-detail.png: 전체 편성, 신규 차량, 상면 및 연결부 검토 렌더.
- interface-spec.json: 기계 판독용 연결부 규격. validation.json: 저장 및 애니메이션 검사.

## 차량 연결부 ES_COUPLER_V1

모든 값은 현재 모델 단위이며 실제 제작 규격 또는 Unity 확정 치수가 아니다.

| 항목 | 값 |
|---|---|
| 전방 / 위 | -X / +Z |
| 새 차량 길이 / 폭 | 5.2 / 2.72 |
| 앞 소켓 (차량 로컬) | (-3.2, 0, 1.05) |
| 뒤 소켓 (차량 로컬) | (3.2, 0, 1.05) |
| 연결 피치 | 6.4 |
| 수직 핀 지름 | 0.10 |
| 앞 혀 폭 / 뒤 포크 내폭 | 0.18 / 0.23 |

앞은 tongue, 뒤는 fork이며 소켓 위치를 일치시키고 소켓 로컬 +X 축은 서로 반대로 맞춘다. 차량 전체는 ROOT로 이동한다. 기관차는 기존 후방 커플링을 보존하고 x=6.0, y=0, z=1.05에 어댑터 소켓을 추가했다. 화물칸 중심 x=9.2, 토대칸 중심 x=15.6. 후방에도 동일 소켓이 있어 같은 규격의 차량을 더 붙일 수 있다. 현재는 직선 조립 및 시각 모델이다. 곡선 선로 관절/물리 조인트/충돌체는 아직 구현하지 않았다.

## 포탑 장착 ES_TURRET_V1

포탑은 별도 오브젝트/자산으로 올린다. 포탑 루트 원점을 하단 장착면 중앙으로 만들고, TURRET_MOUNT에 parent한 뒤 local position/rotation=0, scale=1로 맞춘다. 토대칸 로컬 기준점은 (0,0,2.17), +Z 위, -X 전방이다. 8개 TURRET_BOLT_01..08 Empty도 제공한다.

장착판 지름 2.06, 볼트 원 지름 1.70, 볼트 8개/45도 간격/명목 지름 .09. 중앙 황동 위치결정 링의 중심 반지름 .67, 튜브 반지름 .035. 별도 포탑 밑면에는 이 링을 수용하는 최소 .06 깊이의 홈과 .055 높이의 볼트머리 여유/구멍을 둔다. 장착면 위를 무조건 평평하게 막으면 링·볼트머리와 겹칠 수 있으므로 이 인터페이스 형상을 따라야 한다. 권장 포탑 기부 반지름은 최대 1.05이며, 포신/회전 외곽과 상자·난간의 간섭은 실제 포탑 설계 시 확인한다.

## 애니메이션과 검증

기존 기관차의 휠/피스톤/연결봉 드라이버를 새 씬 내부 대상으로 복제했다. 새 차량 4개 차축에도 24fps/1–48프레임의 같은 시각 회전 루프를 추가했다. 바퀴 반지름별 주행 속도 동기화나 실제 차량 이동은 포함하지 않는다.

저장 파일을 Blender에 다시 로드하여 940개 오브젝트 확인. 두 쌍 연결 소켓 좌표 오차 0, 방향 내적 -1 확인. 0.25프레임 간격 193회 검사에서 기존 연결봉 연결점 오차 4.92e-7 이하, 새 바퀴 중심 이동 오차 3.85e-6 이하, 루프 오차 2.39e-7 이하. 외부 씬을 참조하는 드라이버 0. 독립 파일 라이브러리 읽기 및 원점 기준 소켓/포탑 기준점 좌표 확인.

전체 파일 저장 뒤 최초 독립 파일 복제 중 MCP 연결이 끊겨 Blender를 다시 실행했다. 저장된 전체 편성을 다시 로드해 검증한 뒤, 활성 씬에서 차량별 저장을 완료했다. 이 과정에서 기존 프로젝트 파일은 덮어쓰지 않았다. 원본 v2 SHA-256 불변 확인.

Unity Assets, 씬, 프리팹, 철도 코드 수정 없음. Unity 임포트/Play, 포탑 실물 자산 부착, 게임용 최적화, 실제 제조/충돌 검증은 미실시.
