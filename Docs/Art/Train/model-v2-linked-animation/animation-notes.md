# Train A 연동 애니메이션 v2

2026-10-02 KST · Blender 5.2.1 LTS · Blender MCP

원본 모델 v1 및 바퀴 회전 v1 파일은 그대로 보존. 별도 TRAIN_A_LINKED_MOTION_V2 씬과 train-a-v2-linked-animation.blend에 저장.

양측 4개 구동축 크랭크 핀, 커플링 로드, 연결봉, 크로스헤드와 피스톤봉을 연동했다. 24fps, 1–48 프레임의 2초 루프; 49 프레임이 1 프레임과 일치한다. 8축 16개 바퀴를 유지하며 차체는 이동하지 않는다.

구동축의 회전각 a를 단일 기준으로 사용. 크랭크 반경 .13, 연결봉 길이 2.1, 피스톤 높이 1.14. 크랭크 좌표 x=-2.15-.13*sin(a), z=.7-.13*cos(a). 슬라이더 x=크랭크 x-sqrt(2.1²-(1.14-크랭크 z)²). 이 식으로 길이가 늘어나지 않는 연결봉의 중점과 각도를 계산한다. 바퀴 키프레임은 Linear+Cycles이며 봉은 Blender 기본 수식 드라이버를 사용하므로 외부 스크립트 없이 프레임 사이에서도 연속적으로 계산된다.

기존 Piston rod 메시를 길이 2.1의 연결봉으로 사용했다. 실제 직선 왕복을 위해 피스톤 샤프트/가이드/글랜드, 크로스헤드 및 연장 크랭크 저널을 추가했다. 연결봉은 y=±1.57, 커플링 로드는 y=±1.38로 분리하여 회전 부품이 같은 평면에서 겹치지 않도록 했다. 원래 보일러/운전실/석탄부와 바퀴 메시·머티리얼은 변경하지 않았다.

검증: 한 주기를 0.25프레임 간격으로 193회 검사. 봉 양 끝 연결점, 커플링 로드와 4개 핀, 피스톤-크로스헤드, 고정 연결봉 길이의 오차가 6e-7 모델 단위 미만. 바퀴 중심 고정 오차 1e-6 미만. 루프와 유효 드라이버 확인. 상세 수치는 linkage-validation.json.

렌더 검토에서 복제 parent-inverse 누락에 따른 바퀴 중심 이동을 발견해 수정하고 전체 프레임을 다시 렌더했다. 수정 후 1/13/25 프레임의 바퀴와 연결부를 실제 픽셀로 확인했다. linked-motion-preview.mp4는 수정된 48프레임/24fps의 기구부 확대 영상이다.

게임용 애니메이션 베이크/익스포트 및 Unity 임포트·Play는 수행하지 않았다. 서로 다른 바퀴 반지름의 주행 속도 동기화, 좌우 90도 위상차, 밸브 기어는 포함하지 않는다. 모든 고형 메시의 충돌이나 실제 증기기관 제작 가능성은 검증 대상이 아니다.
