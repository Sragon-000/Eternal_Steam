# 추가 개선 백로그 — 문서화만

사용자 결정: 아래 최적화는 이번 작업에서 구현하지 않는다. 방벽 두 클릭 직선 배치와 사각형 선택은 이후 구현했다. 아래 남은 최적화의 승인 범위는 별도다. 최신 상태: 2026-09-25.

1. UI의 변경된 값만 갱신하고 요소 참조를 캐시한다. 전체 Editor 프레임에서 관측된 약 39KB 할당의 실제 발생 위치를 먼저 추적한다.
2. 활성 적 목록을 이동·전투·렌더링에 공유하여 빈 슬롯 순회를 줄인다.
3. 일반/둔화 적을 한 번에 분류하고 화면 밖 구역의 행렬 생성과 렌더링 요청을 생략한다. 화면 밖 전투는 유지한다.
4. 공간 인덱스의 전체 재구축과 셀 변경분 갱신 비용을 동일 조건에서 비교한 후 선택한다.
5. 건물 변경 시 월드 전체 대신 영향을 받는 구역의 캐시만 무효화한다.
6. **기반 적용 완료:** 시작 루프는 0.1초 이하 분할과 프레임당 처리 상한·미처리 시간 누적을 사용한다. 원래의 시간 버림 개선은 반영됐으며, 장시간 부하에서 누적 지연 정책의 추가 튜닝은 별도 측정 후 판단한다.

권장 순서: 할당 출처 측정 및 UI 갱신 → 활성 적 목록 → 렌더링 순회 → 공간 인덱스/지역 무효화 → 누적 시간의 부하 측정. 게임 빌드나 병렬화·DOTS 이전은 별도 요청 범위다.

미니맵의 슬롯 집계는 최대 5Hz로 제한했다. 향후 활성 적 목록을 공유할 때 집계도 함께 연결하되, 현재 전체 게임 무할당/성능 목표 달성으로 간주하지 않는다.
