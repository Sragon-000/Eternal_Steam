# 맵 에너지·야간 소환·오브 적용 결과

2026-09-20. 원본 `StartRegionSandbox`에 적용. 게임 빌드·새 프로젝트·GitHub 업로드 없음.

## 이번에 연결한 범위

계획 B~D의 **저장 전 단일 맵 흐름**이다. A의 메인/서브 기지 기반을 사용한다.

- 에너지: 2m·45도 논리 격자, 기지 추출 영역 합집합, 칸별 유한 잔량. 기지 제거/재설치로 같은 실행 세션의 잔량이 복구되지 않는다.
- 추출/일반 처치/보스 누적과 잔고를 분리한다. 정수 1/1000 단위이며 일반 지급은 합계 90%까지만 지급한다. 45%씩 강제 제한하지 않는다.
- 정상 기지 설치 범위에서 각 방향 5칸 확장한 안전 영역은 일반 소환에서 제외한다.
- 매 밤 정상 기지 수+1 위치를 무복원 균등 추첨한다. 같은 밤 유효 위치 유지, 기지 변경 시 보충, 위치 감소/부재 시 미소환 예산 보존. 개발자 낮/밤 반복으로 같은 DAY 예산을 재발급하지 않는다.
- 보스전 일반 소환은 에셋에 저작한 8개 위치를 우선한다. 안전 영역에 막힌 위치는 임시 위치로 대체하며 다시 유효해지면 원래 위치로 복원한다. 유효 셀이 부족하면 가능한 수만 사용한다.
- 낮 90%는 밤까지 대기, 밤 90%는 자동 보스 생성. 슬롯+세대로 실제 보스 사망을 구분한다. 보스 보상 10%+불완전 오브는 한 번만 지급한다.
- 해당 맵 잔고 100%와 불완전 오브를 소비하여 완벽 오브를 제작한다. 제작 후 클리어하고 신규 일반 소환/대기 예산을 중단한다. 잔존 적과 건물은 삭제하지 않으며 생산은 유지한다.
- 상단 UXML에 확보율·추출 기여율·재고·보스 단계·소환 지점/대기량·제작 버튼을 저작했다. 수정 중에는 제작을 막는다.
- 수정/시간 정지 중 전투와 추출도 정지한다. 공략 중 개발자 적 초기화는 보스 상태를 손상시키므로 안내하고 차단한다.

## 모듈 경계

- `MapEnergyState`: Unity와 독립적인 에너지 원장·진행 상태·보상/제작 트랜잭션.
- `NightSpawnPlanner`: Unity와 독립적인 위치 추첨·유지·예산.
- `MapCoverage`: 현재 지면·기지·장애물에서 논리 셀과 영역 캐시 구성. 변경 시 갱신.
- `MapAssaultController`: 위 로직과 기존 배열 적 월드 연결. 적별 GameObject 추가 없음. 종료 시 사망 구독 해제.
- `MapAssaultSettings`: 에셋 검증 설정. 실행 시 복사하여 에셋 변경과 실행 상태 분리.
- `MapProgressView`: 기존 UXML의 표시·제작 명령 연결.
- 기존 데모는 설정을 연결하지 않아 자동 야간 소환/에너지 진행을 사용하지 않는다. 적 사망 이벤트와 선택적 보스 확대 표시는 기본 동작을 바꾸지 않는다.

## 명시적인 검증 설정과 한계

`Content/Buildings/BasePlanning/StartRegionAssault.asset`:

- 에너지 목표 1,000, 칸 초기 10, 칸당 초당 0.01, 일반 처치 1, 보스 100.
- 첫 밤 100마리, DAY당 +25. 체력·공격력 날짜 강화 없음. 일반 적 체력은 기존 검증 설정, 건물 공격력은 기존 1 유지.
- 소환 간격 0.2초, 각 지점 1마리씩 시도, 최소 간격/동시 최대 10만 적용. 개발자 1억 요청과 야간 예산은 별개.
- 보스 체력 1,000, 이동속도 1, 공중 검증 개체. 별도 안전 예외 위치에서 생성하며 기존 모델을 3배 표시한다. 최종 보스 디자인/종류가 아니다.
- 낮에는 새로운 일반 적 생성을 보류하고 미소환 예산을 다음 밤으로 넘긴다. 낮 잔존 적/보스는 계속 싸운다. 보스 처치 후에도 제작 전까지 일반 밤 공세는 유지한다.
- 유효 소환 셀은 **지면·안전 영역 밖·장애물 없음·기지까지 기존 직선 지형 경로가 있는 셀**이다. 이 집합 내에서 균등하다. 지형 우회 길찾기를 구현한 것은 아니다.
- 에너지/안전 영역은 셀 중심의 반개구간 포함으로 판정한다. 건물 가동은 기존 전체 점유 포함 판정을 유지한다. 맵 경계의 추출 영역은 유효 지면으로 잘린다.
- 가져온 50×50 프리팹을 보존했다. 최소 150×150 최종 맵 요건을 충족한 것으로 처리하지 않는다.

## 검증 기록

- Editor C# 컴파일 성공.
- `VerifyMapAssault`: 90% 잔여 지급/칸 차감, 낮 보스 대기, 중복 보상·제작 방지, 다른 맵 재료 거부, 실패, 위치 유지·안전 대체·복원·예산 보존, 적 사망 이벤트/초기화 구분 통과.
- `VerifyMapAssaultIntegration`: 원본 씬에서 실제 메인 설치, 102개 유효 셀 추출, 야간 2개 지점, 실제 보스 슬롯 생성/사망, 정확한 보상과 제작, 저작 UXML 확인 통과. 이는 결정적 직접 Tick 통합검증이다.
- 별도 `VerifyMapAssaultFrames`: 실제 PlayerLoop 395프레임 관찰에서 시계 2.0468초 진행, 이후 정지 변화 0초. 직접 Tick 결과와 구분한다.
- 게임 화면 캡처로 상단 새 UI 표시 확인.
- `VerifyBasePlanning`: 메인 1개, 서브 5/10개 한도, 레벨/체력/범위, 중첩 가동, 회수와 메인 파괴 회귀 통과.

## 아직 남아 있는 항목

- **E 미구현:** 디스크 저장/로드, 다른 맵 전환과 재방문, 공유 캠페인 재고, 비활성 맵 생산, 영구 오브 해금. 현재 에너지/오브/고갈은 Play 세션 상태이며 Play 종료 시 초기화된다. 다음 맵 에셋 연결 및 저장 복구 검증이 필요하다.
- **F 기획 대기:** 재활성화 발동 조건·물량·보상·종료 조건, 3 DAY 준비와 외곽 균열, 9종 오브 효과/특수 건물. 임의의 제품 규칙으로 만들지 않았다.
- 최종 맵 규모, 지형 우회, 최종 보스 외형·밸런스, 전투/렌더링 전체 성능 비교도 별도다.

완료 판정은 **단일 세션에서 기지 설치 → 에너지 → 밤 공세 → 보스 → 오브 제작**까지다. 전체 B~F/영구 캠페인 완료가 아니다.
