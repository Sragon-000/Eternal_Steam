# 문서 대조 및 45도 격자 검증

2026-09-15, Unity 6000.3.14f1의 검증용 프로젝트 복사본에서 실행. 사용자 Editor와 수정된 지형·재질·씬·발표 자료는 수정하지 않았다. 게임 빌드는 실행하지 않았다.

## 자동 검증

- EditMode: **35/35 통과** (`document-contract-editmode.json`). 기존 건물/공격/강화/자원/이동 모듈 테스트와 이번 DocumentContractTests 포함.
- 공통 PlayMode: **4/4 통과** (`document-contract-playmode.json`). 배치·회수·생명주기 및 확장 조합 회귀.
- `VerifyDocumentConstruction`: **통과**. 회전된 토대 프리팹/격자 좌표, 복수 토대 임시 배치·이동 실패·이동 성공·개별 제거·취소·확정, 여러 토대의 포탑 예약/이동/선택 해제, 전체 재검사 실패 시 미반영, 확정, 회수 취소·확정, 방향 미리보기와 기존 방향 유지, 취소/확정, 개별 제거, 편집 중 소환 차단, 정리 후 상태 복원.
- `VerifyQuantityFocus`: **통과**. W 이동/수량 유지, 직접 클릭 시 숫자 편집, 영문·잘못된 붙여넣기 거부, Enter·지형 클릭·소환 후 입력 복원, 25마리 소환.
- `VerifyOpenWorldCameraInput`: **통과**. 가상 W 이동, 수량 편집 중 카메라 차단, 휠 확대·축소, UI 위 줌 차단.
- 컴파일 오류 없음. 이번 수정한 소스·문서는 공백 검사 통과. 작업 시작 전부터 수정돼 있던 씬의 Unity 생성 빈 필드 공백은 변경하지 않음.

새 단위 테스트는 45도 좌표 왕복 변환(음수 좌표·다중 셀 포함), 여러 월드 생성/활성화 실패 롤백과 재확정, 회수 대상 소실 시 전체 보류, 유효한 타겟을 포함하는 필터 변경 시 타겟 유지 등을 검사한다.

최초 통합 테스트는 같은 프레임 안에서 확정 버튼을 눌러 UI 활성화 갱신 전에 실패했다. UI 상태 갱신 프레임을 기다린 후 버튼 이벤트를 보내도록 테스트를 수정했고 통과했다.

## 표시 확인

검증용 Play에서 카메라와 UI를 별도 렌더링해 확인했다. 토대·4×4 칸이 마름모로 보이고, 실제 설치 포탑과 반투명 임시 포탑이 각 칸에 놓인다. 설치 모드에 종류 선택과 공용 확정/취소가 표시되며 `3D XZ 격자 / Y축 45°`를 명시한다. 패널은 스크롤되며 수량·전투 버튼은 아래에 있다. 외곽선 재질을 개별 복사해 공유 재질 색상에 영향을 받지 않게 했다.

## 적용 범위

전체 항목별 코드 연결은 `../문서_세부항목_적용_대조.md` 참조. 공통 모듈 구현과 오픈월드 연결 여부를 구분한다. 기존 오픈월드 4종 포탑 공격은 레거시 호환 경로다. 넥서스·강화·새 타겟 규칙 등의 전체 조합은 FoundationSandbox/ModuleSandbox에서 검증하며, 기차·낮밤 규칙은 이번에 추가하지 않았다.

UI 버튼 이벤트와 월드 클릭 처리 함수, 가상 입력을 검사했다. OS 마우스로 전체 동선을 수동 실행한 검증이나 새 성능 측정은 아니다. Play 중 설치 상태는 영구 저장하지 않는다.
