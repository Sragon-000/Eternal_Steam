# 대규모 적 소환 검증

2026-09-16 · Unity 6000.3.14f1 · 검증용 복제 프로젝트 Editor Play · 게임 빌드 없음.

## 결과

`Tools/VerifyEnemySpawnStream.cs` 통과:

- 1억 요청 후 실제 동시 생존 100,000마리, 대기 99,900,000마리 확인.
- 생성된 10만 마리 전체의 XZ 최소 간격 0.75m 확인. 생성 검사에는 이미 살아 있는 적도 포함.
- 모든 대상의 이동 목표가 생성 위치에서 가장 가까운 토대인지 확인, 이동 후 목표까지 거리 감소 확인.
- 최초 생성 최대 2,048마리, 활성 한도 도달 시 추가 생성 중단, 빈자리 보충, 초기화 시 대기와 활성 모두 제거 확인.
- 잘못된 입력·1억 초과·토대 없는 소환 거부. 입력창 9자리 유지, 소량 25마리 정확히 생성.
- 4,000번 이후 슬롯에도 범위 공격 적용. 기존 적 월드 기본 용량 4,000 유지.

## 측정 범위

10만 마리를 채우는 동안 이동을 일시정지한 스크립트 검증: 최초 배치 이후 48회 Pump, 약 204.4ms. 이는 일반 플레이의 채움 시간 또는 프레임 시간이 아니다.

10만 적 `MoveAndIndex(1/60)`을 5회 워밍업 후 90회 측정: CPU 중앙값 **15.27ms**, 상위 95% **15.47ms**. Terrain 높이 조회·이동·공간 인덱스만 포함하며 포탑 전투, 소환, UI, 렌더링/GPU는 제외한다. 전체 게임 FPS나 60fps를 보장하는 수치는 아니다. 1억 전체 소진까지 실행하지는 않았다.

## 회귀

- `VerifyQuantityFocus`: WASD/입력 포커스 분리, 숫자 입력, 정확한 25마리 소환 통과.
- `VerifyBuildingInventoryUI`: 수정 토글 취소·예약 해제, 설치/회수/방향, 분류와 줄바꿈 통과.
- `VerifyLegacyCombatPresentation`: 기존 3개 맵, 4종 포탑, 공격 간격, 연출과 초기화 통과.

목표 도착 시 적 제거는 기존 테스트 규칙이며 토대 공격·피해는 이번 범위에 추가하지 않았다. 최소 간격은 생성 시 보장하고 이동 중 충돌 회피는 포함하지 않는다.
