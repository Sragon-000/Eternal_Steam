# HUD-06C 연결·노선 편집 UI 검증

작업일: 2026-10-02. Unity 6000.3.14f1. 대상: StartRegionSandbox / OpenWorldSandbox.

## 변경 내용

RailwayOverview 안에 저장된 RailwayEditorPanel을 추가했다. 연결, 역 순서, 구간·오류, 확정, 폐기의 5개 상태를 기존 RailwayHud에서 읽는다. 정적 UI는 두 씬에 저장된 Canvas/uGUI 객체이며, 37개 새 버튼의 영구 콜백은 원래 명령을 호출한다. 런타임 UI 생성이나 철도 코어 규칙 변경은 없다.

연결 화면은 역/연결구와 경로 요약, 신규·재사용 칸, 비용·지불 기지를 표시한다. 노선 편집은 ‘역 순서’와 ‘구간·오류’로 나누고 기존 순환 노선의 포트 편집도 유지한다. 검증·확정·취소는 고정 영역에 배치한다. 오른쪽 패널 너비는 최대 560px이며 화면의 60% 이하로 제한해 지도 선택 영역을 확보한다. 공통 글자 크기는 실효 18px이다.

## 증거

측정 폴더: `Docs/Measurements/2026-10-02-hud-06c/`.

- `author.json`: 두 씬에 37개 명령과 2개 페이지 참조 저장 성공.
- `product-tests.xml`: 최종 283/283 통과, 실패·건너뜀 0. 13:46:06–13:46:40 UTC. 기존 코어 회귀와 두 씬의 편집 UI 참조·고정 버튼·18px 검사 포함.
- `play-result.json`: 실제 기지/역/선로와 저장된 UI 콜백을 사용. 미리보기·취소 무변경, 자원 부족 및 지불 기지 변경 거부, 신규 선로만 결제, 중복 확정 시 추가 비용/기차 없음 확인.
- 같은 Play 검증: 새 노선의 검증→취소 확인→계속 편집→확정, 그룹 전환 초안 보존, 역 순서 이동/첫 역 변경 시 기차·물리 정차 역 유지, 점유 역 삭제 제한, 초안 폐기 확인.
- 운행 중 첫 역 고정, 예약 취소 시 지불한 구간과 연료 유지, `pending-snapshot.json`의 실제 직렬화/복원, 기존 첫 역 복귀 시 예약 적용과 연료 재차감 없음 확인.
- `legacy-result.json`: 실제 별도 복귀 선로를 설치한 뒤 기존 순환 노선 형식으로 변환한 격리 fixture. 순환 열기/닫기, 지도 포트 선택, 잘못된 포트의 오류 표시/역 선택/수정과 확정까지 확인. 기존 사용자 세이브를 수정한 검사가 아니다.
- `resolutions.json`: 800×600, 1280×720, 1920×1080, 3840×1080 × 역 순서/오류/확정/폐기/연결 5화면. 스크롤로 각 버튼에 접근해 경계와 최상위 GraphicRaycaster 대상, 실제 버튼 글자 생성, 18px 실효 크기, 왼쪽 지도 입력 영역을 검사한다.

## 발견한 문제와 수정

첫 해상도 검사는 클릭 영역 기준으로 통과했지만 스크린샷을 직접 확인하니 28px 하단 버튼에서 한글이 비어 보이고 안내문이 가로로 잘렸다. 하단 버튼을 기존 40px 높이로 수정하고 TMP 안내문 줄바꿈을 저장했다. 이후 해상도 검사에 버튼의 실제 표시 글자 검사도 추가했다. 클릭 가능한 사각형만으로 가독성을 통과 처리하지 않았다.

## 범위와 후속 인수

결제·경로 탐색·노선 저장·예약 규칙은 변경하지 않았다. 오류/운행 상태의 코어 판단과 버튼 판단은 같은 CanExecute를 사용한다. 테스트 UI는 켜 둔다. 검증은 프로젝트 내부 격리 저장 경로에서 자동 저장을 끄고 수행하며 연구 실험은 실행하지 않는다.

이번 저장 검사는 철도 스냅샷 복원이다. 전체 게임 종료·재시작, 복합 입력/IME, 전체 HUD 최종 가독성 및 기능 대응표의 최종 인수는 HUD-07에서 마무리한다. 기지/철도 건설은 기존 건설 메뉴, 선택 역 진입은 기존 지도 선택 정보 UI를 함께 사용한다.

## 최종 확인 및 종료 상태

최종 Play/순환 노선 호환/20개 해상도·화면 조합 모두 PASS. 연결 비용 화면과 800×600 역 순서·폐기 화면의 스크린샷을 직접 확인했다. 최초 렌더 문제의 화면은 `first-render/`에 보존했다. GameView를 2560×1440으로 복구하고 StartRegionSandbox Edit 모드, 씬 변경 없음, 격리 저장 환경변수 해제, runInBackground=false, 테스트 컨트롤 ON 상태를 `final-editor-state.json`에 기록했다. 커밋·푸시는 수행하지 않았다.
