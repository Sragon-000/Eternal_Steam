# 레거시 전투 분리 검증

2026-09-14 · Unity 6000.3.14f1 · Apple M4 Pro · 임시 복제 프로젝트에서 실행. 사용자 Editor와 실제 진행 기록은 변경하지 않았다.

## 테스트

- LegacyCombat EditMode: 12/12 통과 (`legacy-combat-editmode.json`).
- 공통 기반 EditMode: 30/30 통과 (`legacy-combat-foundation-editmode.json`).
- 공통 기반 PlayMode: 4/4 통과 (`legacy-combat-playmode.json`).
- `VerifyFoundationRegression`: 3맵 출격·통과 포함 클리어·보상 중복 방지·저장 복원·다음 단계·패배·재도전·설치 한도 저장 통과.
- `VerifyLegacyBuildingWorld`: 3맵 건물 생성·ID·점유·제거·재도전·전투 중 배치 차단 통과.
- `VerifyLegacyCombatPresentation`: 3맵 × 4종, 준비 중 정지·적 없는 연사·사거리/부채꼴·포탄/냉각 연출·쿨다운·리셋 통과.
- `VerifyPrototypeLoop`: HUD 출격·화살 선택·관통·보상·저장·로비 복귀 통과.

검사 도중 표현 도구가 기존 설치별 초기 지연을 무시했고, UI 도구가 HUD 갱신 전에 버튼을 눌렀다. 두 도구를 실제 동작에 맞게 고친 후 통과했다. 제품 발사 지연이나 HUD 동작은 변경하지 않았다.

## 통제된 CPU/GC 비교

`Tools/BenchmarkLegacyCombat.cs`: Lane, 고정 위치의 4종 포탑, 시드 731, dt 1/60초. 매 100스텝 블록을 4,000 동시 적으로 시작하고 공격이 닿는 영역에 동일 분포로 배치한다. 각 회차 워밍업 120스텝 후 600스텝을 측정한다. 처치로 수가 감소하므로 4,000마리를 매 프레임 유지하는 부하는 아니다. 스테이지 수량 제한은 변경하지 않았다.

측정은 `MoveAndIndex + UpdateTowers + DrawEnemies`의 메인 스레드 실행 시간이다. 초기화·적 생성·분포 설정·reflection·체크섬 계산은 측정 밖이다. 전체 Editor 프레임, 입력·UI, GPU 완료 시간, 생성 비용은 포함하지 않는다.

| 회차 | 중앙값 전→후 ms | p95 전→후 ms | 중앙값 변화 | p95 변화 | GC 전/후 |
|---|---|---|---|---|---|
| 1 | 0.4354 → 0.4615 | 0.5324 → 0.5572 | +6.0% | +4.7% | 0/0 B |
| 2 | 0.4342 → 0.4616 | 0.5268 → 0.5646 | +6.3% | +7.2% | 0/0 B |
| 3 | 0.4345 → 0.4619 | 0.5228 → 0.5505 | +6.3% | +5.3% | 0/0 B |

세 회차 모두 최종 3,211 생존·789 처치와 적 상태 체크섬 `0C112205DFD935D9`가 분리 전후 일치했다. 이 체크섬은 같은 Unity/장비 환경의 비교용이며 플랫폼 간 영구 규격이 아니다. 측정 구간에서 반복되는 10% 초과 악화나 새 GC 할당은 관측하지 않았다. 성능 향상이나 전체 프레임 동등성을 의미하지 않는다.

원시 기록: `legacy-combat-before.json`, `legacy-combat-after.json`. 분리 직전 HordeSimulation SHA-256: `4f0422c39efe9f829116aa4f22bc59079b32864b107f34ffbb057d57379276af`.

## 재현

원본과 분리 후 버전을 각각 같은 Unity 버전의 검증 복제 프로젝트에서 연다. Play 모드로 HordeDemo 씬을 시작하고 아래 도구를 실행한다. 도구는 임시 전투·포탑 배치를 초기화하므로 작업 중인 사용자 씬에서 실행하지 않는다.

```sh
unity command run_script --file Tools/BenchmarkLegacyCombat.cs --entry BenchmarkLegacyCombat.Main --timeout_ms 60000 --project-path <검증프로젝트> --format json
unity command run_script --file Tools/VerifyLegacyCombatPresentation.cs --entry VerifyLegacyCombatPresentation.Main --timeout_ms 60000 --project-path <검증프로젝트> --format json
```

전체 프레임 CPU 중앙값·p95, GPU 및 Standalone 빌드 측정은 미실시다. 이 항목은 후속으로 남기며 전체 이전 성능 완료 판정을 유보한다.

## 후속: 빌드 없는 Editor 프레임 측정

[Editor 실제 프레임 측정](Editor_프레임_측정.md)을 추가 완료했다. 위 미실시 설명은 최초 전투 분리 시점의 기록이다. Editor CPU·GC 3회 전후 비교에서 10% 초과 악화는 없었고 GC 중앙값·p95는 전후 모두 352 B/frame이다. GPU 유효 표본 부족은 남아 있으며 빌드는 사용자 요청으로 제외했다.
