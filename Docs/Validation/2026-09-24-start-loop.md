## 발견 및 수정

전력 검증 도구는 기기 설치 전에 Editor가 이미 진행한 부분 초를 고려하지 않아 첫 저장량 15와 바로 비교하고 실패했다. 실제 저장량 11.8835253에 미정산 순생산 3.1164747을 더하면 15로 일치했다. `VerifyBasePowerIntegration.cs`가 빈 공급 상태에서 다음 정산 경계까지 먼저 진행하도록 수정한 뒤 초기 씬에서 재실행하여 통과했다. 게임 전력 로직은 변경하지 않았다.

`VerifyHudFolds.cs`는 빈 작업 목록 대신 실제 건물 예약을 만든 상태로 검사하도록 강화했다. UI 버튼에 연결된 콜백을 호출한 검사이며, 마우스 좌표 클릭 재현을 의미하지 않는다.
