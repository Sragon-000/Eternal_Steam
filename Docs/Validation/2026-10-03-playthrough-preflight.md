# 정상 회차 로직 사전 감사·관측 기능

상태: 코드/정적 데이터 사전 점검과 관측 단위 검증 완료. **실제 생존 회차는 미실행**, 수집기 초기화·기록·캡처·종료·복구 Play 검증은 후속 완료했다. 정적 감사 당시 OpenWorldSandbox를 유지했으며 대상 씬을 열지 않았다. 후속 정상 플레이 준비에서 기존 캠페인 StartRegionSandbox를 최초 한 번 선택하고 이번 회차의 고정 테스트 씬으로 지정했다. 자동 검사 중 씬 전환은 금지한다.

## 현재 판단과 남은 실제 확인

| 경로 | 코드·데이터 확인 | 실제 회차에서 확인할 것 |
| --- | --- | --- |
| 초기 기지/진행 | 저장된 StartRegion 씬은 시작 기지·BasePlanningRules·Assault를 참조한다. 메인 레벨 상한 10, 서브 기지 상한 min(레벨×5,10) | 신규 회차 초기 자원/시계·건설 가능 영역 |
| 일반 건설/강화 | 비용 테이블 참조가 없어 현행 무료 정책. 구매/건설 실패 복구는 회귀 통과 | 무료 정책을 분리 표시하고 철도·기차 실제 소비를 측정 |
| 생산·재고 | 24개 카탈로그 정의 모두 Validate 오류 없음. 철/석탄 2초, 구리 5초, 티타늄 10초, 텅스텐 20초, 우라늄 45초, 플라즈마 60초, 나노메탈 120초에 1개. 모두 현재 레시피 입력 없음 | 생산 가동/포화·용량·소속 기지별 수지와 해금 후 실제 생산 |
| 기지 소유권 | 재고는 고정 기지 ID로 분리. 기지 상실 시 재고를 자동 병합하지 않고 접근 중단. 건설·강화는 소속 은행에 지불 | 추가 기지 생성·운송·상실 후 자원 소실/중복 여부 |
| 전력/공격 | 공급권 연결·1초 정산, 공급 부족이면 전력 요구 공격 제한. 생성/소비 설정은 자산 값 유지 | 기지별 저장/수요/공급·정전과 실제 피해 |
| 운송 | 철도 Load/Unload가 기지 은행 Withdraw/Deposit을 사용. 부족·포화량만 실제로 이동 | 적재/하역·연료·대기·방어 충전·장시간 재보급 |
| 적/맵 진행 | 1일 예산 100, 일차당 25 증가, 90% 에너지 후 밤에 보스, 처치 후 제작 대기. 제작 전에는 공세 지속 | 일차별 생성·잔존·처치·기지 피해·보스 도달성 |
| 종료/저장 | 오브 제작 후 무보상 적 정리·공세 중단. 저장은 낮·안전 상태를 요구. 전체 저장 복원은 선행 QA에서 통과 | 자연 플레이 실패/완료와 동일 회차 불러오기 |

정적 카탈로그 원본 수치는 `Docs/Measurements/2026-10-03-playthrough-preflight/campaign-assets.json`에 있다. 씬 파일 해시·정의/모듈/설치 조건 경로·값을 포함하며 대상 씬을 로드하지 않았다. 카탈로그 밖의 기존 토대/레거시 도구는 실제 회차 HUD 카탈로그 기록으로 추가 확인한다. 정책 미정인 무료 비용이나 제작 이후 종료 규칙을 임의로 바꾸지 않았다.

## 발견한 수집 결함과 보완

재고의 주기 차이만 기록하면 같은 구간에 생산 4개·소비 4개가 있어도 0으로 보여 총생산/총소비를 잃는다. `ResourceBank.Changed`로 생산 입력/출력, 입금, 출금, 구매 차감, 실패 롤백, 복원, 용량 변경을 구분한다. 가상 출금도 표시하여 무한 자원 사용을 정상 경제로 오인하지 않는다. 관측이 없을 때 기록 배열/문자열을 만들지 않는다.

새 기지 은행이 생성될 때 구독하고 건물 등록·제거 직후 생명주기 이벤트를 제공한다. 관측자 예외는 개별 격리하고 카운터로 남긴다. 기록기가 망가져 결제/생산/등록 자체가 실패하는 일을 막는다. 기록 이벤트는 상태 변경 시도를 포함한다. 실패 구매는 차감과 롤백을 함께 분석해야 하며 차감 이벤트만 합산하면 안 된다.

추가한 7개 회귀는 상쇄되는 생산/소비, 구매 롤백, 여러 기지 건설 복원, 관측자 예외 격리, 제한 입금/가상 출금, 새 기지 첫 생산 구독, 건물 등록/제거를 다룬다. 전체 **292/292 통과**, 오류 0, 현재 씬 핸들·저장 파일 바이트 동일, dirty=false. 기존 검사 누락 0, 중복 씬 사례 통합 18, 새 관측 검사 7이다.

## 수집 도구 상태

`Tools/Testing/Balance/BalanceRecorder.cs`는 처음 컴파일만 검증했으며, 아래 후속 기록에서 현재 캠페인 씬 Play 통합도 확인했다. 현재 캠페인 씬에서 새 경로를 준비하고 Editor 일시정지 상태에서 관측을 시작하도록 제한한다. 동일 이름 회차 덮어쓰기, 다른 씬 전환, 무한 자원·시간 배율 변경을 허용하지 않는다. 실물 생존 회차는 아직 없다.

- 시작 정의/설치 조건/모듈/자원 레시피·HUD 카탈로그·소스 해시를 저장한다.
- 자원 변동, 건물 생성·손실·피해, 적 생성·처치 이벤트와 1초 상태 표본을 JSONL로 기록한다.
- 표본은 기지 재고·체력·레벨·전력·무기 저장 상태, 공세 예산/보스/에너지, 열차 상태·연료·화물·방어를 포함한다.
- 낮밤/단계/건설/열차 변화/명시 행동/60초 주기에 캡처를 예약한다. 같은 프레임의 여러 원인은 한 이미지와 각 이벤트 ID로 연결한다.
- 마지막 캡처 후 종료 기록을 쓴다. 비정상 Play 종료와 대기 중인 캡처, I/O 오류를 별도로 표시한다. 디스크 기록 실패 시 Editor를 일시정지하고 오류를 보존한다.
- 초기화/연속 호출/캡처/정상 종료/저장 경로 복구는 아래 두 QA에서 검증했다. 관측 부하 A/B 측정과 장기 회차 중 전투·물류 이벤트 검증은 남아 있다.

연구 실험은 미실행. 후속 실제 데이터 수집·밸런스 결과·최대 관측 생존 일차는 아직 미완료다.

추가 실행 확인: 비캠페인 Setup 호출은 준비 단계에서 거부됐고 회차 폴더를 만들지 않았다(`noncampaign-guard.json`). 관측 7개 재검사도 통과했으며 기존 6개 결과를 덮어쓰지 않고 새 시각 하위 폴더에 저장했다(`repeat-observation-command.json`).

## 후속 수집기 Play 통합 검증

StartRegionSandbox를 고정하고 `purpose=recorder-integration`, `normalPlay=false`인 두 격리 QA를 실행했다. 정상 생존 기록과 합산하지 않는다. 원본은 [Balance 측정 폴더](../Measurements/Balance), 요약·제한은 [integration-notes.json](../Measurements/Balance/integration-notes.json)에 있다.

| 회차 | 결과 |
| --- | --- |
| 20261003-recorder-integration | 135.88 게임 초, 139 표본, 캡처 6장. 최초 상태·동적 스크립트 재호출·마지막 캡처·종료·복구 통과. 철 생산기는 OutsideArea여서 생산 경로 미검증으로 보존 |
| 20261003-recorder-production | 31.13 게임 초, 34 표본, 캡처 2장. 정상 무료 정책으로 메인 Lv3 강화 후 전체 면적이 운영 영역에 든 철 생산기 설치. 자연 생산 15건·철 15개, 이벤트와 재고 표본 일치 |

첫 배치 명령은 잘못된 네임스페이스로 컴파일 실패했으며 실행 전에 거부됐다. 이를 수정했고, 첫 QA의 OutsideArea 결과는 삭제하지 않았다. 재검증 도구에는 전체 면적의 영역 포함 검사를 추가했다. 게임의 경제 규칙·시간·재고는 주입하거나 변경하지 않았다.

`audit_recording.py`로 이벤트 순서 연속성, 스크린샷 요청의 정확히 한 번 처리, PNG 해시, 자원 이벤트 연속성과 재고 일치, 관측 오류 0, 정상 종료·대기 캡처 0을 확인했다. 두 회차 모두 데이터 무결성 통과. 대표 화면을 직접 열어 HUD와 실제 기지·생산기가 보이는 것을 확인했다. 프레임 표본은 기록했지만 관측 부하 A/B 결과로 해석하지 않는다.

최종 Editor 상태는 같은 씬 1개, dirty=false, Play/일시정지/백그라운드=false, 저장 경로 재정의 없음이다([복구 확인](../Measurements/Balance/editor-restored.json)). 선행 `manifest.json`의 NOT_RUN은 작성 당시 상태이며 이 후속 결과로 대체한다. 장기 정상 생존과 학술 연구 실험은 모두 미실행 상태다.

후속 상태 갱신: 정상 기준 회차와 수집을 실제 실행해 3일차 오브 제작·동일 씬 저장 복원을 완료했다. [기준 회차 결과](2026-10-03-survival-baseline.md). 이 문서의 미실행 표기는 사전 감사 당시 상태다.
