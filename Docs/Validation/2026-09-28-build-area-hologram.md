# P3 가동 영역 셀 홀로그램 코드 적용

후속 기준 변경: [Canvas·실제 Hierarchy 이관](2026-09-28-canvas-hierarchy.md)을 우선한다. 이 문서는 이관 이전 단계의 기록이다.

2026-09-28. [실제 적용 준비](../Archive/2026-09-29/BELTFED_UI_실제적용_준비.md)의 P3 코드를 원본 프로젝트에 연결했다. **C# 컴파일 완료, Unity import·NUnit 실행·Play 시각/입력/성능 검증 대기**다. 씬·프리팹·저장 포맷은 변경하지 않았으며 게임 빌드는 실행하지 않았다.

## 적용 내용

- `BaseRegistry.Covers`가 실제 건물 가동 판정과 홀로그램·배치 피드백의 공통 영역 조회다. 일반 기지 모드는 활성 메인/서브만, 기존 모드는 같은 소속의 독립 영역 제공자만 허용한다. 조회 대상은 등록된 확정 건물이다. 임시 설치는 포함하지 않고, 회수 예약은 실제 확정 제거 전까지 유지한다.
- `CoverageRevision`을 분리했다. 등록/제거, 활성 상태, 소속 기지 생존, 선택 소속, 규칙 모드, 반경·형상·경계 위치 변화를 감지한다. 일반 기지뿐 아니라 기존 모드의 특수 제공자 강화도 감지한다. 기존 `Revision`과 일반 기지 레벨 추적도 유지한다.
- `BuildAreaHologramView`는 기존 2m/45° 격자의 셀 **전체**를 `IBuildArea.Contains`로 판정한다. 9개 재사용 메시와 청크별 1셀 주변 마스크로 합집합을 구성한다. 겹치는 제공자의 면/내부 외곽을 중복 생성하지 않는다. 중립 `WorldGridView`는 그대로 유지했다.
- 카메라가 같은 청크에 있고 영역 상태가 같으면 재생성을 생략한다. 영역 상태가 바뀌어도 셀 마스크가 같은 청크는 재생성하지 않는다. 지형 변경 도구를 추후 연결할 경우 `InvalidateSurface()`를 호출해야 한다. 현재 정적 지형에서는 프레임마다 지형을 재검사하지 않는다.
- 지형 검사 부분을 `OpenWorldContent.CheckTerrain`으로 추출해 실제 지면 배치와 공유한다. 타일 표면 높이를 우선 사용하며, 경계 밖/물/경사 등 지형 검사 실패 셀은 파란 채움 없이 빨간 교차 패턴으로 표시한다. 이는 지형 마스크이며 보스 예약·건물 점유·토대 예약을 모두 나타내는 설치 허용 지도가 아니다.
- `Shared/Resources/EternalSteam/BuildAreaHologram.shader`는 URP 투명 vertex-color 셰이더다. 셀 오브젝트·Collider·그림자는 만들지 않고, 소유한 메시와 머티리얼만 정리한다. 셰이더 로드/지원 실패 시 기존 영역 외곽선을 유지한다.
- 수정 모드에서만 표시하며 취소·성공 확정·패배의 취소 경로·컴포넌트 비활성화에서 즉시 숨긴다. 새 홀로그램이 있는 동안 기존 영역 외곽선을 숨긴다. 실패한 확정은 기존 편집/예약을 유지한다.
- `WorldEditSession.PreviewContent/PreviewFoundation/PreviewTower`는 배치 명령과 회수 충돌·임시 토대 예약·실제 PlacementSession 검사를 공유한다. 미리보기 조회는 예약을 추가하지 않는다. 배치 명령은 클릭 시 다시 검증한다.
- 카탈로그 건물은 전체 footprint를 파랑/주황/빨강과 교차 패턴으로 표시한다. HUD의 별도 `placement-hint`에 실제 실패 사유 또는 설치 가능·비작동을 표시한다. 기존 작업 결과 메시지는 덮어쓰지 않는다. 영역 충족은 전력 충족까지 보장하지 않으므로 확정 후 판정임을 명시한다. 토대/기존 포탑 도구도 공통 조회를 사용한다.
- 기존 임시 건물의 청록색과 회수 예약의 주황색, 기존 선택 공격 사거리 표시를 유지했다.

## Editor 실행 환경 복구 후 검증

1. 셰이더/UXML import와 `BuildAreaCoverageTests`, 기존 가동/건설/회수/전력 테스트를 실행하고 결과 XML을 확인한다.
2. 임시 저장 루트의 신규 StartRegionSandbox 세션에서 `VerifyBuildAreaHologram.Main`을 실행한다. 시작 121셀·9메시·Collider 없음·정지 100회 재생성 없음·한 청크 이동 시 3메시 재사용·즉시 취소 숨김을 확인한다. 이 도구는 현재 편집 중인 세션을 거부한다.
3. 영역 중첩, 서브 임시 설치/확정, 회수 예약/취소/확정, 강화, 제공자 파괴, 패배, 씬 종료를 각각 확인한다. 특히 대기 제공자와 회수 예약의 차이를 화면에서 확인한다.
4. 다중 footprint, 물/절벽/경계, 보스 3×3 예약, 확정/임시 토대·건물 충돌에서 미리보기 사유와 클릭 결과를 비교한다. 실패 확정 후 예약 유지도 확인한다. 이동 중인 기존 임시 건물과 방벽 다중 드래그의 개별 표현은 기존 편집기를 사용하므로 별도 회귀한다.
5. `VerifyWorldGridVisibility`와 P2 HUD 입력 도구를 실행한다. 일반/수정/선택 해상도별 캡처, 카메라 이동/정지와 영역 변경의 Profiler GC·메시 수·재생성 비용을 기록한다. 시각·성능 완료 판정은 이 결과 이후에 한다.
