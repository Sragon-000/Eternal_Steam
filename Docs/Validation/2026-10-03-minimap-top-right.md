# 미니맵 우상단 정렬

요청에 따라 두 Sandbox 씬의 원형 미니맵을 화면 우상단으로 올렸다. 이전 상단 56px·우측 16px 배치 여백을 제거하고, 프레임 RectTransform의 상단·우측을 화면 끝에 맞췄다. 프레임 이미지 자체의 투명 패딩은 유지한다. 부모 슬라이드와 우상단 앵커를 유지하여 Tab 이징도 계속 동작한다.

전투 화면의 `Esc · 메뉴` 안내는 미니맵 아래 8px로 이동한다. 건설 화면에서는 기존 우상단 안내 위치를 사용한다. 원형 크기와 시야 중심·월드 지름 150은 유지한다.

검증: 두 씬 × 7해상도(800×600, 1024×768, 1280×720, 1920×1080, 2560×1080, 3840×1080, 3840×2160) Play 검사 통과. 프레임의 상단·우측 오차 0.1px 이내, 화면 경계, 안내 분리, 원형 raycast, 외부 드래그/재진입, Tab/Esc 캡처 해제, 텍스처 재사용을 확인했다. 검사 중 런타임 오류는 0건이다. 800×600 캡처도 시각 확인했다. 이번 위치 수정에는 전체 EditMode 테스트를 반복하지 않았다.

저장된 씬 참조, 해상도별 결과·캡처, 수정 전 레이아웃 소스와 최종 에디터 상태는 `Docs/Measurements/2026-10-03-minimap-top-right/`에 기록했다. 연구 실험은 실행하지 않았다. HUD-08E 통합 인수는 별도 후속 단계다.
