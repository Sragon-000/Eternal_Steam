# 정상 플레이 내부 테스트 종합 결과 — 2026-10-03

정상 플레이의 시작·성장·추가 기지·철도 물류·전투·보스·오브·저장 복원 경로를 확인했고, 관측 중 발견한 열차 대기 방전과 숨은 건설 독 입력 잠금을 수정했다. 가장 긴 단일 회차는 **10번의 자연 공세를 완료하고 11일차 낮에 정상 클리어**했다. 이것은 실제 관측한 생존 기록이며 이론적 최대 생존 일수는 아니다.

카탈로그 24개 정의와 기존 포탑 4종의 설치, 무기 13종의 실제 전투 참여를 회차별 증거로 확인했다. 네 회차의 이벤트 **42,765행**, 자원 변경 **19,105건**, 상태 표본 **8,051개**, 기록 화면 **760장**을 보존했다. 별도 저장 복원 화면을 포함하면 **762개 PNG**다. QA·성능 측정 화면은 이 합계에 넣지 않았다. ## 자원·추가 기지·철도

장기 회차에서 메인/전초/넥서스의 최종 HP는 100/140/280이었다. 기관차·화물·토대·장착 방어·정상 정차/급탄/전력 충전/재출발을 함께 사용했다. 정상 보급 10주기, 총 40개 명령은 행동 로그에 남겼다.

| 자원/흐름 | 장기 회차 최종 수지 |
|---|---|
| 철 | 생산 7,208 = 기지 재고 7,121 + 화물 30 + 비용 57 |
| 석탄 | 생산 4,798 = 기지 재고 4,266 + 열차 연료 92 + 주행 소비 440 |

기지 간 배송은 내부 이동으로 처리하며 총생산에 중복 합산하지 않았다. 시작 설치 구간에 전력 부족 표본 3개가 있었지만 2~11일차 운영 영역 내 소비자 부족 표본은 0이었다. 세부 시간별·기지별 장부와 열차 표본은 [운용 비용 JSON/CSV](../Measurements/Balance/20261003-survival-improved-01/checkpoints/operating-costs-000030745)에 있다.

현재 일반 건설/강화 비용 참조는 비어 있어 무료 정책이다. 무한 자원 치트를 사용하지 않은 사실과 유료 성장 경제의 균형은 다른 문제다. 희소 자원의 재고 누적은 실제 관측했지만 현행 소비처만으로 최종 가격·생산 속도를 결정할 수 없다.

## 확인 후 적용한 개선

1. **비전투 열차 방전 수정.** 표적이 없는 동안 충전을 보존하고 기존 발사체/쿨다운 처리는 유지했다. 적 없는 첫 60초를 비교하면 기준은 약 40초 만에 0, 개선 후에는 200 유지다. 별도 장기 회차에서도 첫 전투 전 약 269초간 200이었다. 전체 생존 성과에는 배치·보급 운용·회차 길이 차이도 있으므로 전부 코드 수정 효과로 귀속하지 않는다. 관련 4개 필수 회귀를 추가했다.
2. **숨은 건설 독 입력 잠금 수정.** 비활성 건설 독의 멈춘 전환값 때문에 초기 전투 카메라/HUD 및 오브 명령이 막혔다. 독이 실제 활성 상태일 때만 전환 입력을 차단하도록 바꿨다. 숨은/보이는 독 회귀 1개 추가 후 현재 씬 전체 **297/297**, 실제 Play **14/14** 통과. [원인·코드·증거](2026-10-03-hidden-dock-input-fix.md).
3. **관측·실행 신뢰성 보완.** 자원 순변화 대신 모든 생산/소비 이벤트를 보존하고, 기존 포탑은 별도 실제 발사 카운터를 오브 제작 전에 수집했다. 생성 세대별 공세 연결, 스트리밍 감사, 종료 후 무손실 압축, 실패 명령과 도구 버전 보관을 적용했다. 정상 회차 실행 도중 제품 수치를 변경하지 않았다.

## 저장 복원·관측 부하·보존

기준/장기 회차의 실제 같은 씬 저장 복원은 savedUtc와 최상위 건물 순서 정규화 후 전체 상태가 정확히 같았다. 콘텐츠 2차는 한 기존 포탑 방향 x/z에 최대 1.79×10⁻⁷ 차이가 있어 **엄격 비교는 실패로 보존**했다. Quaternion/forward 변환의 방향 성분에만 10⁻⁶ 허용 기준을 별도 적용했으며 다른 필드는 정확히 같다. [엄격 비교와 기능 검토](2026-10-03-content-coverage-02.md#기록-감사와-저장-복원).

관측 부하 ABBA는 정상 클리어 후 일시정지 상태에서 각60프레임 준비+12초씩 수행했다. 전후 저장 상태는 정확히 유지됐다. 중앙값은 OFF 7.630~7.673ms, ON 7.619~7.641ms이며 ON에는 PNG 요청/기록 비용과 최대 지연이 포함된다. GC는 Editor와 측정 도구도 포함한다. 보조 전투 관측기 비용·활성 전투·배포 빌드 성능을 검증한 결과는 아니다. [원시 프레임·전후 상태](../Measurements/Balance/20261003-content-coverage-02/recorder-overhead).

네 회차 모두 종료 상태·연속 이벤트·재고·화면 요청/PNG 해시·압축 왕복을 감사했다. 압축 원본은 기존 이벤트를 그대로 복원하며 실패 회차도 삭제하지 않았다. 실패한 제작·저장·부하 시작 요청도 남겼다. 마지막 Editor 상태는 동일 씬 한 개, Play OFF, dirty=false, 저장 재정의 없음, 원래 백그라운드 설정 복구다.
