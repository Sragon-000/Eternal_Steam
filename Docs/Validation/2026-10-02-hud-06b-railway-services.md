# HUD-06B 화물·방어 UI 적용 기록

작업일: 2026-10-02. Unity 6000.3.14f1. 대상: StartRegionSandbox / OpenWorldSandbox.

## 적용 내용

기존 철도 외곽 패널에 화물·방어 전용 상세 화면을 저장했다. 입력칸은 기존 RailwayHud.Resource/Load/Unload 자체를 새 계층으로 옮겼고, 게임 규칙·운행·결제 코드는 바꾸지 않았다. 최초 자원 지정 후 고정 상태, 선택 역의 적재/하역, 적용 버튼을 분리했다. 방어칸은 크기/후보/장착/해제/강화/충전과 비용·축전지·불가 이유를 같은 화면에 표시한다.

두 씬의 정적 계층과 영구 콜백을 실제 Unity Editor에서 저장했다. 런타임은 상태·문구·배치만 갱신한다. 18px 실효 글자 크기를 유지하며, 본문은 마스크가 있는 스크롤 영역이고 운행 화면 복귀 버튼은 고정한다. 스크롤 안내와 입력칸 경계를 추가했다. 기존 테스트 UI는 ON 유지한다.

## 검증

측정: `Docs/Measurements/2026-10-02-hud-06b/`.

- `product-tests.xml`: 최종 281/281 통과, 실패·건너뜀 0 (13:26:03–13:26:37 UTC).
- `author.json`: 두 씬의 8개 서비스 행동과 동일 입력 필드 참조 저장.
- `play-result.json`: 최초 자원 지정/고정, 음수·초과·NaN·문자 수량 거부, 선택 역만 설정 적용, 그룹/운행/방어 복귀 시 작성 중 입력 보존.
- 같은 Play 검증에서 실제 역·선로·노선을 구성하고 운행시켜 이동 중 화물·방어 변경 제한을 확인했다. 정상 장착과 재호출의 중복 결제 방지, 실제 강화 비용/기지 레벨 상한, 충전 전력 보존, 해제 환급 없음과 배터리 유지도 확인했다.
- `railway-save-fixture.json`: 실제 노선 상태를 RailwayNetwork 스냅샷으로 직렬화·복원한 후 화물 자원/역별 수량/장착 상태 확인. 전체 게임 종료·재시작 인수는 HUD-07에서 수행한다.
- `resolutions.json`: 800×600, 1280×720, 1920×1080, 3840×1080에서 화물/방어 각 화면. 스크롤로 모든 입력·버튼에 접근한 뒤 화면 경계와 GraphicRaycaster 최상위 대상을 검사. 글자 실효 18px 검사와 상단/하단 스크린샷을 저장했다.
- Play 저장은 프로젝트 측정 폴더의 격리 경로를 사용하고 자동 저장을 중지했다. 실제 사용자 저장 데이터와 연구 실험은 사용하지 않았다.

## 발견과 조치

첫 author 호출은 비활성 건설 그룹을 FindFirstObjectByType 기본 검색이 찾지 못해 저장 전에 중단됐다. 기존 CanvasWorldHud의 RailwayHud 참조로 접근하도록 수정 후 두 씬 저장 성공. 오류 출력도 보존했다.

마지막 recompile 호출의 상태 조회는 도메인 재로드 중 연결 오류를 반환했다. 이후 live run_script와 최종 281개 테스트가 성공해 실제 컴파일 완료를 확인했다.

첫 Play 장착 검사는 기지 1레벨에서 방어 후보가 없어서 멈췄다. 이는 정상 해금 제한이다. 검증용 기지만 기존 IUpgradeControl로 2레벨까지 올려 비용·장착 검사를 수행했다. 충전 검증은 격리된 정차 기지 저장 전력을 30으로 준비한 뒤 실제 충전 명령을 실행했다. 전투/연구 성능 실험은 하지 않았다.

이동한 TMP 필드는 기존 CanvasHudLayout.Texts의 별도 배율 대상에서 제외했다. 새 화면의 물리 크기 기준과 중복 조정되지 않도록 했다. 전체 git diff --check는 Unity 직렬화 YAML의 빈 값 뒤 공백을 보고하며, 씬 YAML은 수동 정리하지 않았다.

## 범위와 다음 단계

운행 화면/그룹 전환은 입력을 유지한다. 다른 역 선택은 원래 규칙대로 선택 역의 저장 값을 불러오므로 미적용 입력 초기화를 화면에 알린다. 이동 중 화물 예약과 여러 역의 원자적 일괄 저장은 추가하지 않았다. 연결/노선 편집은 기존 화면을 유지하며 다음 HUD-06C에서 재구성한다. 최종 복합 입력·IME·전체 저장 재시작 인수는 HUD-07에 남긴다.

## 종료 상태

최종 소스 재검증에서도 Play/4해상도 모두 PASS. 대표 스크린샷(800×600 화물 상·하단, 1920×1080 방어, 최종 800×600 방어)을 직접 열어 문구·경계·스크롤 분리를 확인했다. GameView는 2560×1440으로 복구했다. `final-editor-state.json`에서 StartRegionSandbox, Edit 모드, 씬 변경 없음, 저장 격리 환경변수 해제, runInBackground=false, 테스트 컨트롤 저장 활성 상태를 확인했다. 커밋·푸시는 수행하지 않았다.
