# HUD 그룹 개편 첫 적용 묶음

2026-10-02. [단계별 작업 문서](../Implementation/HudGroups/README.md)를 기준으로 실제 적용을 시작했다. 이번 범위는 HUD-00 완료 및 HUD-01~03 구현/부분 검증이다. HUD-04 기지 자원 아코디언, HUD-05 건설 흐름, HUD-06 철도 재구성, HUD-07 최종 인수는 미착수이며 완료로 표시하지 않는다.

## 이번 적용

- 두 씬에 전투/건설 그룹과 방향별 슬라이드 호스트를 실제 Canvas 계층으로 저장했다. 기본은 전투이며 상단 Tab 안내 버튼도 저장된 영속 콜백으로 연결했다.
- 체력/통합 시간/미니맵은 전투, 자원/건설/철도/전력/선택/긴 목표 안내는 건설 그룹에 배치했다. 테스트 빠른 조작과 저장/일시정지/일반 알림은 공통 영역에 유지한다.
- HudModeGroups는 Tab과 버튼 전환, 일시정지에도 진행되는 0.24초 이징, 연속 반전, 그룹 입력 차단을 처리한다. 가까운 모서리 방향으로 나갈 때 내용 경계까지 계산한다. 정적 UI를 런타임에 만들지 않는다.
- 숨긴 건설/철도 편집의 상태는 유지하고 월드 입력을 중단한다. 드래그 중 전환은 드래그 종료를 안내한다. 그룹 진입만으로 건설 편집을 시작하지 않는다.
- 미니맵은 카메라 시야의 지면 중심을 기준으로 150×150 월드 범위를 표시한다. 전체 지형은 초기 1회 512×512 텍스처로 준비하고 UV를 잘라 표시한다. 범위 밖 지형은 빈 배경, 마커는 현재 투영으로 처리한다. 드래그 이동 시에는 누른 시점의 투영을 사용해 시야 이동 때문에 드래그 좌표가 누적 이동하지 않게 했다.

## 검증 증거

증거 루트: [2026-10-02-hud-groups](../Measurements/2026-10-02-hud-groups/).

- 전체 EditMode **271/271 통과**, 실패/생략 0, 20.178초: `product-tests.xml`.
- 새 집중 검사 **5/5 통과**: 두 씬의 저장 그룹/기본 상태/반전/시간 소속/런타임 UI 생성 없음, 세 위치의 미니맵 중심·150 범위·좌표 왕복.
- 두 씬 × 7개 해상도 = **14개 제품 UI Play 시나리오 통과**. 800×600, 1024×768, 1280×720, 1920×1080, 2560×1080, 3840×1080, 3840×2160. `matrix-StartRegionSandbox.txt`, `matrix-OpenWorldSandbox.txt`, 씬·해상도별 `*-play-result.json`.
- 각 시나리오는 기본 전투/숨긴 자원, 주요 패널 화면 경계, 그룹 버튼 GraphicRaycaster/PointerClick, 일시정지 중 전환, 빠른 반전, 빈 편집 상태 보존, 테스트 버튼 표시, 시야 이동에 따른 미니맵 중심 변화를 확인했다. 전투/건설 스크린샷 28개를 보관했다.

## 실패와 수정

- IMECompositionString 네임스페이스를 설치된 Input System의 LowLevel로 바로잡았다.
- 기존 회귀 8건은 비활성 부모 아래 ScrollRect 검색/이동한 컨테이너 경로, 상호 배타적 패널을 항상 동시에 표시한다고 가정한 검사였다. 활성 여부와 무관한 저장 참조 검색 및 그룹 소속/상호 배타 상태 검사로 갱신했다. 실패 XML은 `tests-before-group-contract.xml`에 유지했다.
- OpenWorldSandbox에는 Persistence가 없어 최초 Play 검사 도구가 실패했다. 저장 컴포넌트를 선택적으로 처리한 뒤 7개 해상도를 재실행해 통과했다. 이 씬의 저장/기지 규칙 기능 인수를 수행했다고 주장하지 않는다.
- 도메인 리로드 도중 일부 CLI recompile 상태 요청이 연결 오류를 반환했다. 이후 실제 명령 스크립트 실행과 전체 테스트 통과로 컴파일 상태를 확인했다. 실패 응답도 그대로 보관했다.

## 남은 인수와 제한

800×600에서 주요 경계는 맞지만 최종 가독성 목표(실효 글자 크기) 인수는 완료하지 않았다. 철도 전체 글자 통일과 작은 화면 작업 재배치는 HUD-05/06/07에서 마무리한다. 실제 키보드 Tab/IME 조합, 활성 드래그와 미확정 건물/선로 초안, 창 크기 변경 도중 전환, 맵 가장자리 클릭/드래그 및 교차 실패, 적 밀집 상태에서 갱신 비용은 추가 인수가 필요하다. 자동 PointerClick은 OS 마우스/키보드 수동 인수와 구분한다.

따라서 HUD-01~03은 적용·부분 검증 후 **검증 중**으로 유지한다. HUD-00의 기능 대응표와 배치 문서만 완료 처리했다. 새로운 연구 예비실험/벤치마크는 실행하지 않았다.

## 보존

작업 전 런타임 소스와 두 씬 사본/해시를 `baseline/`, `baseline.json`에 보관했다. 모든 Play 저장은 프로젝트 내부 `play-save/`로 격리했다. 종료 시 원래 StartRegionSandbox 편집 씬, 2560×1440 GameView, runInBackground=false를 복원하고 저장 환경변수를 해제했다. 이번 작업은 커밋/푸시하지 않았다.
