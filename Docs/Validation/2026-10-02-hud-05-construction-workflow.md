# HUD-05 건설 메뉴·편집 흐름 통합 검증

날짜: 2026-10-02. 제품 UI 적용과 회귀 검증이며 연구 실험은 실행하지 않았다.

## 적용 내용

StartRegionSandbox와 OpenWorldSandbox의 기존 Canvas/uGUI 계층에 비용 요약 ScrollRect를 저장했다. 카드를 누르면 해당 건물의 배치 준비에 들어간다. 그룹이나 건설 탭을 여는 것만으로는 편집 시작·예약·결제가 발생하지 않는다. 회수 작업은 ‘회수 선택’에서 시작한다.

선택 건물, 대기 작업 수, 지불 기지, 현재 확정 비용, 다음 1개 추가 후 총비용을 하단에서 확인한다. 긴 비용·부족 사유는 요약 영역에서 스크롤한다. 확정/전체 취소는 별도 고정 영역에 유지한다. 비용은 기존 WorldEditSession.Quote를 사용하며 경제 규칙을 바꾸지 않았다. 대기 작업이 있으면 ‘편집 종료’로 조용히 취소하지 못하게 한다.

기차역·선로·석탄 생성기는 공통 카탈로그의 ‘철도’ 분류에서 선택한다. 기존 철도 관리의 중복 건설 툴바는 저장 계층에 남겨 비활성화했다. 역의 두 클릭 방향 선택은 기존 월드 입력으로 유지한다. 철도 관리 자체의 목록/세부/노선 편집 재구성은 HUD-06 범위다.

건설 메뉴의 글자 기준을 통일하고 작은 화면에서는 최소 14 화면 픽셀을 확보하도록 배율을 반영한다. 헤더 버튼 너비, 비용 영역 높이, 카드 높이와 하단 전체 높이를 함께 계산한다. 선택 상세 높이는 전투 그룹 미니맵의 공간을 중복 차감하지 않도록 보완했다. 테스트 UI는 표시 상태를 유지한다.

## 검증 증거

측정 루트: `Docs/Measurements/2026-10-02-hud-05/`.

- `inventory.json`, `baseline/`: 적용 전 저장 계층과 비교 사본.
- `author.json`, `polish.json`, `polish-legibility.json`: 두 실제 씬의 저장 적용과 참조 연결.
- `product-tests.xml`: 최종 전체 EditMode **277/277 통과, 실패·건너뜀 0**. 2026-10-02 10:27:32Z ~ 2026-10-02 10:27:59Z. 신규 저장 계층/확정·취소 경계 검사 4개 포함.
- `play-result.json`: 공통 철도 카드→월드 임시 배치→확정/취소. 유한 재고 부족 시 미리보기 차단, 자원 무한 ON 예약 후 OFF 시 비용 재검사, 재고 보충 후 철 1개를 한 번만 지불, 취소 시 예약 해제·무결제 확인. 전투 그룹 왕복 및 철도 탭 요청 후 미확정 건설의 선택/예약/지불 기지 보존 확인. 실제 확정 버튼 포인터 raycast 및 저장 콜백 확인.
- `resolutions.json`: 800×600, 1280×720, 1920×1080, 3840×1080에서 카드 전체 높이·건설 패널/요약/자원 경계·확정/취소 가림 검사 통과. 각 `construction-WxH.png` 캡처를 저장했다.
- `construction-800x600.png`, `construction-1920x1080.png`: 직접 시각 확인. 작은 화면의 헤더 줄바꿈과 요약 영역 높이를 캡처 기반으로 보완했다.
- `final-editor-state.json`: 종료·원복 결과. 검증 저장은 측정 루트의 `play-save/`에 격리.

## 발견 및 수정

첫 회귀에서 800×600 카탈로그 뷰포트 높이가 카드보다 18.5 논리 단위 부족했다. 요약 영역을 포함해 하단 높이를 계산하도록 수정했다. 최초 실패 XML을 `product-tests-before-card-height-fix.xml`로 보관했다. 그 뒤 캡처에서 좁은 화면의 헤더 글자 줄바꿈과 세 번째 요약 행이 접히는 것을 발견해 버튼 너비 및 요약 높이에 실효 배율을 반영했다.

초기 recompile 일부 호출은 도메인 재로드 중 CLI 연결 오류를 반환했다. 후속 스크립트 실행·저장 및 실제 회귀 결과와 구분하며 이를 컴파일 실패로 집계하지 않는다.

## 범위와 후속 인수

이번 단계의 건설 흐름과 두 씬 저장 계층을 검증했다. 비용을 지불하는 Play 사례는 StartRegionSandbox의 선로 카드이며 일반 건설 비용 정책은 기존 회귀 테스트로 함께 확인한다. OpenWorldSandbox는 저장 계층/해상도 EditMode 검증에 포함했다. 철도 초안의 모든 상태, IME, 전체 HUD 소형 화면 가독성, 한 열 보조 패널 전환, 긴 이름/다종 비용의 실제 휠 스크롤 인수는 HUD-06/07에서 이어간다. 전체 UI 개편 완료를 뜻하지 않는다. 이번 작업에서 Git commit/push는 하지 않았다.
