# 선택 모듈 확장 검증

검증일: 2026-09-14. Unity 6000.3.14f1, macOS arm64.

원본 Editor와 별도의 임시 프로젝트에서 컴파일·에셋 생성·테스트를 수행했다. 최종 코드와 에셋은 원본 `Assets/EternalSteam`에 반영하고 바이트 일치 및 `.meta` 누락 없음을 확인했다. 새 스크립트의 GUID도 검증 프로젝트에서 생성한 에셋 참조와 일치시켰다.

| 항목 | 결과 |
|---|---|
| C# 컴파일 | 오류 없음 |
| EditMode | 26/26 통과 — [원시 결과](modules-editmode.json) |
| PlayMode | 4/4 통과 — [원시 결과](modules-playmode.json) |
| 공격 | 광역 필터, 관통 순서·폭·최대 개수, 연쇄 중복 방지·거리·피해 감소 |
| 투사체·효과 | 지연 피해, 사거리 이탈 후 추적, 슬롯 재사용 방지, 종료 정리, 독립 효과 만료와 설정 복사 |
| 넥서스·강화 | 선행 강화 제한, 체력 증가, 실제 파괴만 패배, 즉시 결과 전환, 초기화 |
| 자원·방벽 | 저장 용량, 입력·출력 원자적 반영, 저장소 제거 후 잔량 보존, 방벽 등록 해제 |
| 배치 원자성 | 생성·활성화 실패 시 넥서스·용량·방벽 등록 롤백, 임시 예약 유지 후 재확정 |
| UI | 카탈로그 12개 표시, 강화 버튼 실행, 전투 중 강화 차단, 결과 라벨, 초기화 |
| 시각 확인 | UI 렌더 텍스처로 한글·건물 목록 독립 스크롤·설치/회수/강화 버튼 확인 |

샘플 생성 중 macOS 대소문자 비구분 파일명 충돌을 발견해 건물 에셋 이름에 `Building_` 접두사를 적용했다. 생성 에셋과 검증 씬을 다시 만든 뒤 위 테스트를 통과했다.

기존 기반의 EditMode 14개·PlayMode 3개는 위 합계에 포함되어 함께 통과했다. 기존 LegacyDemo 코드·맵·빌드 순서·저장 형식은 변경하지 않았으며, 이번 확장에서는 기존 데모 3개 맵의 수동 회귀를 재실행하지 않았다. 실행 파일 빌드와 4,000마리 성능 측정도 수행하지 않았다. 확장 검증 씬의 동작을 대규모 전투의 성능 검증으로 해석하지 않는다.
