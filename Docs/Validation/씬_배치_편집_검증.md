# 씬 배치 편집 검증

2026-09-14 · Unity 6000.3.14f1 · 별도 검증 복제본 · 게임 빌드 없음.

- `SetupOpenWorldAuthoring`: 저장형 프리팹 5종, 재질 에셋, 편집 상태의 토대 2개·포탑 4개 씬 저장 완료.
- `VerifySceneAuthoring`: Play 없이 개체·프리팹·재질 참조 및 높이 확인. 토대 없는 설치·중복 거부, 배치 Undo/Redo, 회수 Undo, 씬 재열기 통과.
- `VerifyAuthoredPlay`: 저장된 4개 포탑 GameObject를 그대로 재사용함을 참조 동일성으로 확인. 토대 2개·포탑 4개로 등록, 100마리 UI 소환, 공격, 리셋, 실행 중 건설 UI 제거 통과.
- `VerifyLegacyCombatPresentation`: 기존 3개 맵의 4종 포탑, 연사·쿨다운·표현·리셋 통과.

검증은 저장형 배치와 전투 연결 범위다. 이번 변경에서 새 성능 측정이나 제품 빌드는 수행하지 않았다. 편집 중 프리팹 배치가 씬 저장의 원본이며 Play의 임시 전투 상태는 저장하지 않는다.
