# HUD-04 기지별 자원 아코디언 적용 검증

날짜: 2026-10-02. 범위: 제품 UI 구현 및 검증. 연구 실험은 실행하지 않았다.

## 적용

StartRegionSandbox와 OpenWorldSandbox의 실제 Canvas 계층에 기지 목록, 자원 행, 스크롤, 이전/다음 버튼과 영구 콜백을 저장했다. 페이지당 기지 4개를 재사용하며, 한 기지를 클릭하면 해당 행 아래에만 재고를 펼친다. 동일 행 재클릭은 접기다. stable ID로 조회를 유지하고 결제 기지 선택 API를 호출하지 않는다. 스크롤로 행 이름이 가려져도 상단 제목에 조회 기지 이름과 번호가 남는다. 기존 테스트 UI는 표시 상태를 유지했다.

## 검증 도구 보정과 한계

최초 UI 객체 수 검사에는 TMP가 글리프 렌더링에 생성하는 SubMeshUI가 포함돼 실패했다. UI 컨트롤 검증에서 해당 렌더링 객체를 제외한 뒤 통과했다. 추가 예약 fixture는 기지 6개 배치 후 같은 기지를 더 예약하지 못해 실패했으며, 철 생성기 예약으로 바꿔 통과했다. OpenWorldSandbox에는 Persistence가 없어 검증 도구의 null 보호를 추가했다. 모두 검증 도구 수정이며 실패 기록을 남겼다. 최초 테스트 CLI 30초 제한은 결과 XML과 구분한다. 최종 실행은 120초 제한으로 완료했다.

이번 단계는 기지 재고 조회 기능을 완료했다. 저해상도 전체 HUD 가독성, 긴 이름/큰 수량, 실제 휠·드래그 조작과 복합 건설/철도 예약의 최종 인수는 HUD-05~07에서 이어간다. 전체 UI 개편 완료를 뜻하지 않는다. Git commit/push는 이번 단계에서 하지 않았다.
