어댑터 테스트는 모든 후보 셀을 기존 footprint 규칙과 대조한다. 생성·활성화 실패와 확정 전 한도 변경 시 월드·포탑 목록·예약·요청 설정이 남지 않는지도 검사한다. 기본 원점의 기존 공통 격자와 짝수 좌표 중심의 레거시 격자를 함께 검사했다.

기존 전투·적 이동·인덱스·피해·효과·적 렌더링 메서드 12개는 타입 이름 변경을 제외하고 본문이 동일함을 확인했다. 사거리와 공격 방향의 기존 정규화 순서도 유지했다. 기존 씬·에셋·빌드 설정·저장 키·enum 순서를 변경하지 않았다.

진행 관련 검증은 별도 PlayerPrefs 키를 사용하고 종료 시 원래 프로필을 복원했다. 기존 데모의 전투 알고리즘을 새 공격 모듈로 이전한 것은 아니며, 이번 단계에서 실행 파일 빌드나 4,000마리 전후 성능 측정은 수행하지 않았다.
