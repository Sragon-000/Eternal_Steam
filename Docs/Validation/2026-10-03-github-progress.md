# GitHub 작업 현황 체크포인트 · 2026-10-03

이번 체크포인트는 HUD 그룹 전환·기지별 자원 목록, 건설 흐름, 철도 관리·서비스·편집 화면, Esc 정지/저장 메뉴, 원형 미니맵, 건설 하단 UI 축소와 미니맵 우상단 정렬까지 포함한다. 두 게임 씬의 저장된 uGUI 계층, 런타임 소스, 스프라이트/메타, 테스트와 저작·검증 도구, 계획·측정·캡처 기록을 함께 보존한다.

검증 근거: HUD-08D 전체 EditMode 297개 통과. 이후 미니맵 위치 수정은 두 씬 × 7해상도 Play에서 화면 경계 정렬·원형 입력·드래그·Tab/Esc 캡처 해제 검사를 통과했다. 상세 결과는 각 Validation 문서와 Measurements 디렉터리를 참조한다. 전체 HUD-08E 통합 인수와 실제 OS IME 검증은 남아 있다. 연구 실험은 실행하지 않았다.

대형 검증용 씬 사본은 `Docs/Measurements/**/*.unity` Git LFS 규칙으로 원본 바이트를 보존한다. Unity가 생성한 씬 YAML의 빈 값 뒤 공백은 재작성하지 않는다. 사용자 저장 대신 프로젝트 안의 격리 검증 저장과 결과물을 포함한다.
