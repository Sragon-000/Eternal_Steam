# 건설 하단 UI 축소 적용과 검증

HUD-08D의 건설 목록과 배치 작업 바를 두 Sandbox 씬에 적용했다. 단계 검증을 완료했다. 전체 EditMode 297개, 두 씬 × 7해상도, 실제 건설 결제·취소 흐름과 상세 콘텐츠 검사가 통과했다. 해상도 검사 중 런타임 오류는 0건이다. 다음 단계는 HUD-08E 통합 인수다. 연구 실험은 실행하지 않았다.

## 적용 내용

건설 목록은 건설·철도 전환, 가로 스크롤 분류, 아이콘·이름 중심의 단일 가로 카드 행으로 정리했다. 아래의 짧은 안내는 마지막 메시지를 표시한다. 기존 카드와 persistent callback을 재사용한다.

카드를 고르면 목록이 아래로 접히고 선택 건물·대기 수·지불 기지, 핵심 비용·부족 사유, 비용·목록·확정·취소 버튼을 표시하는 작업 바가 나온다. ‘목록’은 편집과 예약을 유지한 채 목록으로 돌아가고 ‘배치 복귀’로 계속 배치할 수 있다. 확정·취소는 목록으로 돌아간다. 분류와 가로 스크롤 위치를 유지한다.

| 상태 | 패널 높이 | 바닥 여백 포함 | 너비 |
|---|---:|---:|---|
| 목록 탐색 | 156px | 172px | 화면 너비−32px, 최대 1280px |
| 배치 | 80px | 96px | 동일 |
| 철도 / 좁은 화면의 선택 상세 | 52px | 68px | 동일 |

800×600에서도 목록은 화면 높이의 30% 이하, 배치 바는 18% 이하이다. 본문·버튼은 실효 18px, 보조 요약은 14px로 유지한다. 긴 이름은 말줄임하고 전체 비용은 스크롤 상세 창에서 확인한다. 내용이 길어져도 하단 패널 높이는 늘리지 않는다.

기존 다중 행 비용 요약은 별도 비용 상세 창으로 옮겼다. 확정·취소는 상세 스크롤 밖에 남아 계속 접근할 수 있다. 목표는 상단 1줄 요약과 ‘목표 보기’로 바꿨으며 긴 안내는 목표 상세 창에서 읽는다. 비용·목표 상세는 동시에 열리지 않는다. 좁은 화면에서 기존 건물을 선택하면 목록을 접고 선택 상세를 표시한다.

건설 화면의 기존 하단 알림 패널은 숨기고 목록 안내 또는 작업 바의 비용·실패 사유로 전달한다. 마지막 설치 불가 사유는 유효한 배치 지점을 다시 가리킬 때까지 유지한다. 기지 자원 목록은 내부 스크롤을 유지하며 물리 너비와 앵커를 조정해 중앙 배치 영역을 침범하지 않게 했다. 펼친 기지와 스크롤 위치는 Tab 왕복 후 유지한다.

목록·배치 전환은 0.24초 이징으로 아래 방향 이동과 페이드를 적용한다. 전환 중 UI·월드·카메라 입력을 막고, 사라지는 콘텐츠는 이징 종료 후 숨긴다. 새 목표·상세 계층도 기존 Tab 그룹의 위쪽·오른쪽 슬라이드에 포함한다. 정적 UI는 모두 Editor API로 실제 씬에 저장했으며 런타임에 재생성하지 않는다.

## 검증 기록

증거 디렉터리: `Docs/Measurements/2026-10-03-hud-08d/`.

| 검사 | 증거 |
|---|---|
| 전체 EditMode 테스트 | `product-tests.xml` |
| 두 씬의 저장된 참조·콜백 | `author.json`, `polish.json`, `details-slide.json`, `CompactConstructionDockTests` |
| 두 씬 × 7해상도 점유율·중앙 공간·폰트·버튼 raycast | 씬별 `*-results.json`, `*-status.txt`, PNG |
| 실제 예약·부족 비용·1회 결제·취소·Tab 보존·철도 전환 보호 | `play-result.json` |
| 기지 펼침·스크롤 복원, 좁은 선택 상세, 긴 이름·40줄 비용 | `details-result.json`, 관련 PNG |

해상도는 800×600, 1024×768, 1280×720, 1920×1080, 2560×1080, 3840×1080, 3840×2160이다. 해상도 검사는 실제 GraphicRaycaster와 저장된 버튼 콜백을 사용한다. 모든 OS 마우스·키보드 동작을 자동화한 결과로 해석하지 않는다. OpenWorldSandbox는 BaseRules를 사용하지 않으므로 캠페인 결제 검증은 StartRegionSandbox에서 별도로 수행한다.

## 발견한 문제와 수정

4K 화면 캡처에서 고정 크기 자원 목록이 Canvas 배율을 따르는 전력 패널과 겹치는 것을 발견했다. 전력 패널의 실제 하단 좌표를 기준으로 자원 목록의 상단에 최소 8px 간격을 확보하고 남은 높이 안에 목록을 제한했다. 두 씬의 해상도 검사에 겹침 방지 판정을 추가했다.

초기 배치 바에서는 복사된 텍스트 설정 때문에 제목이 생략되고 두 줄 비용이 잘렸다. 실제 TMP 선 높이에 맞춰 제목 영역과 비용 줄 높이를 조정하고, 여백·rich text·말줄임 설정을 명시했다. 취소 버튼은 짧은 ‘취소’로 표시한다. 분류 아이콘과 글자 사이 여백도 보존했다.

최초 전체 테스트의 4개 실패는 접힌 배치 바가 화면 아래에 대기하는 구조로 바뀌었는데 기존 검사가 숨겨진 변환을 표시 위치로 간주한 것이었다. 고정 버튼 배치 검사는 펼쳐진 위치에서 수행하도록 수정했다. 좁은 화면에서 선택 상세가 목록을 대체할 때는 숨겨진 카드의 뷰포트 높이를 표시 카드의 높이 기준으로 검사하지 않는다. 실제 펼쳐진 상태는 Play 해상도 검사로 검증한다.

중간 Play 검증은 대기 중 스크립트 가져오기로 도메인이 다시 로드되어 중단되었다. 해당 실행은 통과 근거로 사용하지 않는다. 소스 반영과 전체 테스트가 끝난 후 새 Play 세션에서 검사한다. 초기 검증 도구의 잘못된 날짜 경로와 애니메이션 갱신 전 측정도 수정했다.

## 범위와 다음 단계

기존 테스트 바로가기, 원형 미니맵, Esc 메뉴, 철도 규칙, 비용 계산과 저장 형식은 유지했다. 전체 통합 인수, 실제 OS IME 조합 등 기존 미검증 항목은 HUD-08E에서 계속 확인한다. 이번 단계만으로 HUD 전체 완료를 주장하지 않는다.

소스·두 씬·저작/검증 도구·격리 저장·변경 전 사본·캡처·해시는 모두 프로젝트 안에 남긴다. 일반 사용자 저장과 GitHub main은 변경하지 않는다.
