# 원형 미니맵 적용과 검증

2026-10-03 HUD-08C를 두 Sandbox 씬에 적용했다. 플레이어 시야 중심의 월드 150×150 투영에서 내접원을 표시한다. 원의 지름은 월드 150, 반지름은 75이며 지도 범위를 확대하지 않았다. 다음 단계는 HUD-08D 건설 하단 UI 축소이고, HUD-08 전체 통합 인수는 아직 남아 있다. 연구 실험은 실행하지 않았다.

## 적용 내용

- 저장된 `MinimapBody`에 원형 Image와 Mask를 추가하고, 기존 `CanvasWorldMinimap`을 그 아래에서 그린다. 사각 패널 이미지와 제목 버튼은 숨겼다. 기존 계층과 참조는 보존했다.
- 기존 금속·청록·황동 색에 맞춘 전용 `MinimapRing.png`를 built-in image_gen으로 생성했다. PNG 원본을 프로젝트에 복사했으며 테두리는 비상호작용 Image로 씬에 저장했다. 원형 마스크는 Editor 도구에서 수학적으로 생성한 별도 512×512 PNG다.
- 지도 내부 지름은 물리 px 기준 `clamp(화면높이×0.24, 144, 256)`이다. 오른쪽 위 앵커와 1:1 비율을 유지한다. 테두리에는 별도 여백을 둔다.
- 4K에서 Esc 안내가 미니맵과 겹치는 것을 발견해 안내의 글자와 여백도 물리 크기로 유지했다. 안내 아래와 미니맵 패널 위 사이의 간격을 해상도 검사에 포함했다.
- 정규화 원 내부 판정을 Graphic raycast, PointerDown/Drag, 카메라 키보드 차단에 공통 적용했다. 원 밖 투명 모서리는 미니맵이 입력을 받지 않는다.
- 원 안에서 시작한 드래그가 원 밖으로 나가면 포인터 소유권은 유지하고 지도 이동만 보류한다. 재진입 시 시작 투영으로 이동을 이어간다. 바깥에서 버튼을 놓거나 Tab/Esc/지도 크기 변경이 발생하면 캡처를 종료한다.
- 시야 윤곽선의 좌표를 사각형 가장자리에 강제로 고정하던 처리를 제거했다. 실제 선분을 원형 stencil mask로 자른다. 원 밖 마커를 테두리로 강제 이동하지 않는다.
- 기존 지형 텍스처를 재사용하며, 저장 형식·건설 비용·철도 규칙은 변경하지 않았다. 테스트 바로가기는 유지했다.

해상도는 800×600, 1024×768, 1280×720, 1920×1080, 2560×1080, 3840×1080, 3840×2160이다. 작은 화면과 4K 캡처를 직접 확인했다. 입력 검증은 raycaster와 이벤트 처리기 검증이며, OS 마우스 동작 전체를 자동화한 결과로 해석하지 않는다.

첫 전체 실행의 285개는 새 테스트가 실행 목록에 반영되기 전 결과였다. 최종 도메인에서 새 10개를 포함한 295개를 다시 실행했다. 초기 4K 크기 검사 실패는 Canvas와 레이아웃 갱신 전 측정에서 발생했고, 갱신 완료 후 측정하도록 검증 도구를 수정했다. OpenWorldSandbox의 첫 이동 표본은 강 위였으므로 실제 이동 가능한 두 지점을 선택해 정상 이동을 검사하고, 이동 불가 영역은 별도 맵 끝 검사로 확인했다. 최종 PASS 파일만 완료 근거로 사용한다.
