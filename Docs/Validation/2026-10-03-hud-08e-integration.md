# HUD-08E 통합 인수 검증

HUD-08E의 로컬 Unity Editor 통합 인수를 완료했다. 입력 유실·메뉴 뒤 입력 재활성화를 수정하고, 최종 전체 EditMode 297개와 두 씬 × 7해상도의 메뉴·건설·미니맵 검사를 통과했다. 연구 실험은 실행하지 않았다.

## 실제 OS 입력에서 발견한 문제와 수정

한글 입력 중 Esc를 누르면 TMP 입력란의 기본 `restoreOriginalTextOnEscape` 설정이 편집 시작 시 값으로 복원하여 새 입력을 지웠다. 두 씬의 HUD 입력란에 이 설정을 false로 저장하고 저장 계층 회귀 검사에 포함했다.

OS 한글 조합 종료와 Esc가 같은 프레임에 전달되는 경우에는 조합 종료 프레임을 기억해 메뉴 진입을 보류한다. 조합 후 다음 Esc는 메뉴를 연다.

입력란의 예약된 다음 프레임 활성화가 메뉴 개방 후 실행되어 뒤쪽 입력란에 글자가 들어가는 경로도 발견했다. 메뉴가 열릴 때 편집 중 입력 컴포넌트를 잠시 비활성화하고, 닫힘 애니메이션 종료 후 이전 enabled 상태와 포커스를 복원한다. 닫히는 중 재개방해도 기존 입력 참조를 유지한다. 메뉴 컴포넌트를 비활성화할 때에도 입력 상태를 복원한다.

## 검증 환경과 해석

`Docs/Measurements/2026-10-03-hud-08e/`의 프로젝트 내부 격리 저장을 사용한다. StartRegionSandbox는 실제 두 기지·두 역·왕복 노선으로 검증한다. OpenWorldSandbox는 BaseRules 미사용을 별도로 기록하며 캠페인 저장·철도 검증을 통과한 것으로 간주하지 않는다.

적 1,000개 밀집 검사는 제품 미니맵의 강제 Update 호출 120회(워밍업 제외)를 측정한다. 에디터의 해당 코드 경로만 포함하며 메시 제출·전체 프레임·목표 기기 성능 인수는 포함하지 않는다. 연구 확장 실험과 무관하다.

## 검증 도구 보정 이력

연속 실행 시 미니맵 검사가 건설 화면에서 시작한 첫 실행은 폐기했다. 전투 그룹 전환과 대기 후 측정하며 dock/circle 결과를 별도 디렉터리로 기록한다. 새 Play 세션은 캠페인 검증용 노선과 재고를 초기화하므로 BuildHud08EFixture를 다시 실행해야 한다. 이를 생략한 중간 배치 실패는 제품 실패/통과 근거로 사용하지 않는다. 실제 OS 입력 뒤 자동 검사에서는 시작 시 키·IME 이벤트와 메뉴·편집 상태를 초기화한다.

## 증거 목록

- `product-tests.xml`: 최종 소스 전체 EditMode 297개, 실패/스킵 0.
- `menu-result.json`: 입력 이벤트·조합 종료 동시 Esc·메뉴 재개방·배경 입력란 비활성화·포커스 복귀·초안·저장 제한.
- `*-resolutions.json`: Esc 메뉴·개발 도구·폐기 확인의 7해상도 접근성.
- `dock/*-results.json`, `circle/*-results.json`: 건설 탐색·배치·철도 전환·원형 미니맵.
- `services/resolutions.json`: 7해상도 × 화물/방어 화면, 긴 이름과 수량 상한.
- `save-result.json`: 실제 씬 재로드 전후 savedUtc 제외 전체 스냅샷 일치.
- `details-result.json`, `base-loss.json`: 상세 스크롤·긴 이름·선택 상태·기지 소실.
- `resilience-result.json`: 저장 쓰기 오류, 야간/적 저장 차단, 전환 중 Esc, 미니맵 밀집 측정.
- `*-edge.json`: 시야 중심, 맵 밖 클릭 거부, 텍스처 재사용.

## 실제 OS 입력 최종 결과와 범위

macOS의 실제 한글 조합 이벤트(ㅎ)를 관측했다. 조합 중 Esc 후 메뉴가 닫힌 상태를 확인했으며 조합 종료 프레임 가드는 최종 자동 이벤트 검사에도 포함했다. 최종 코드에서는 실제 한글 조합→Tab 확정/전투 전환→Tab 건설 복귀 후 텍스트와 포커스가 유지됐다. 이후 Esc 메뉴 진입 시 포커스가 해제되고, 메뉴 뒤에서 숫자 1을 눌러도 텍스트는 ㅎ 그대로였으며, 메뉴를 닫으면 같은 텍스트와 포커스가 복원됐다. `native-result.json`과 각각의 `native-tab-*`, `native-escape-*`, `native-background-input.json`이 최종 근거다.

중간 앱 제어가 `noWindowsAvailable`을 반환했고, 화면 전환과 입력 포커스 확보를 같은 프레임에 수행한 시도는 문자 전달이 일관되지 않았다. 앱 연결을 다시 잡고 화면 안정화 후 포커스를 확인하여 최종 재검증했다. `before-fix-*`, `before-focus-fix-*`는 실패 재현 기록이며, 빈 텍스트로 기록된 중간 시도도 최종 통과 근거로 사용하지 않는다. 이벤트 주입 전용 `menu-result.json`의 nativeOSIMEVerified=false는 해당 검사 자체의 범위를 뜻하며 별도의 실제 OS 기록과 구분한다.

철도 서비스는 7해상도 × 2상태, 순환 노선 편집은 7해상도 × 5상태를 통과했다. 실제 반환 선로 설치, 연결 오류 선택·수정·확인도 재검증했다(`editor/legacy-result.json`, `editor/resolutions.json`). 기지 없는 씬은 빈 목록과 기능 제한만 검증했다.

## 완료 판정과 제한

HUD-08A~E의 요청한 적용·로컬 통합 인수를 완료로 판정한다. 검증 대상은 Unity 6000.3.14f1/macOS Editor와 명시한 7해상도다. Windows/배포 빌드/다른 OS 입력기 전체의 검증이나 목표 기기 프레임 성능 인증으로 확대 해석하지 않는다. 미니맵 강제 갱신 측정은 적 1,000개에서 중앙값 0.1469ms, p95 0.1598ms였으며 전체 프레임 측정은 아니다.

최종 에디터는 StartRegionSandbox, Play 종료, 씬 dirty=false, 격리 저장 경로 해제, 테스트 UI 활성 상태다. 기록·도구·격리 저장·캡처·해시는 모두 Eternal_Steam 프로젝트 안에 남겼다. 이번 변경은 아직 별도 Git 커밋/푸시하지 않았다.
