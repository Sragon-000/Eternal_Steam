# 인게임 건설 전환 검증

- 날짜: 2026-09-14. Unity 6000.3.14f1, 검증용 복사본의 Play 모드. 게임 빌드는 수행하지 않음.
- 시작 씬은 준비된 Terrain과 카메라·UI를 유지하며 토대·포탑은 비어 있음.
- OpenWorldInput 활성화, OpenWorldHud.uxml 연결. 설치는 준비된 토대·4종 포탑 프리팹을 복제하고 공통 격자·건물 월드에 등록.

## 통과

- VerifyOpenWorldSandbox: UI 설치/수정 버튼, 토대 중복·경계, 지형 위 포탑 거부, 그리드·점유·높이, 프리팹 사용, 방향 취소, 4종 포탑 설치·공격·회수·재설치, 125마리 소환, 4,000 제한·초과 거부, 적 초기화 후 건물 유지.
- VerifyQuantityFocus: 새 Play 세션에서 W 이동과 수량 유지, 직접 클릭 시 숫자 편집, 영문·붙여넣기 거부, Enter·지형 클릭·소환 시 포커스 해제, 25마리 소환.
- VerifyOpenWorldCameraInput: 가상 W 이동, 수량 편집 중 이동 차단, 휠 줌, UI 위 줌 차단.
- git diff --check 통과.

입력 검증을 앞선 건설 검증 직후 실행한 최초 시도는 누적 Spawned 값 때문에 수량 단언이 실패했다. 새로운 Play 세션에서 재실행하여 통과했다. 독립 실행 시 빈 Play 상태에서 시작한다.

버튼 이벤트와 월드 클릭 처리 함수를 통한 설치 검증 및 가상 입력 테스트이며 수동 마우스 전체 동선 검증은 포함하지 않는다. Play 배치는 영구 저장하지 않는다. 기존 에디터 배치 도구는 사전 배치용으로 유지한다.
