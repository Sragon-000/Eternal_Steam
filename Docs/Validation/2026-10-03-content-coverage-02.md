# 콘텐츠 보완 2차 — 역할 참여·정상 완료·저장·관측 부하

같은 StartRegionSandbox의 정상 회차에서 남은 **대공 2종·기존 포탑 4종**의 실제 전투 참여를 확인했다. 두 공세와 보스의 적 226명을 전원 처치했고 3일차 낮에 오브 제작·저장을 완료했다. 메인/추가 기지 HP100/280 유지, 총 건물 피해180·전방 EMP 1개 파괴. 이 회차를 장기 회차와 합쳐 생존 일수를 늘리지 않는다.

## 배치·개입·실패를 포함한 결과

기존 포탑 4종은 실제 메인 위치에서 7.07~11.40m, 테슬라 4개 Lv5는 10.30~13.93m에 정상 배치했다. 첫 EMP 설치는 16m 안의 공간 부족으로 거부돼 실패를 보존하고 나머지 건설만 이어갔다. EMP Lv3는 21.21m에 설치됐으며 모든 전력/운영 조건을 실제 표본으로 확인했다. [배치값](../Measurements/Balance/20261003-content-coverage-02/initial-defense-placement.json), [실패 후 정상 재개](../Measurements/Balance/20261003-content-coverage-02/placement-adjustment.json).

첫 공세에서 기관총/냉기/화살과 대공 2종은 참여했지만 포 포탑은 발사0이었다. 전방 기지에 포/화살을, 다음 공세 전 메인 접근 측에 포를 정상 추가했다. 두 번째 자연 공세에서 전방 포12회·메인 접근 포11회 발사를 확인했다. 원래 메인 포가 0인 결과도 그대로 남는다.

| 종류 | 확인한 기록 |
|---|---:|
| 벌컨 대공 | 작동 신호26 |
| 스카이 플라즈마 | 작동 신호3, 발사체 갱신586 |
| 기존 기관총 | 실제 누적 발사37 |
| 기존 포 | 2개 개체에서12+11=23 |
| 기존 냉기 | 실제 누적 발사10 |
| 기존 화살 | 실제 누적 발사3 |

일반 무기의 작동/발사체 신호는 무기별 적중·처치 집계가 아니다. 기존 포탑은 전용 실제 발사 카운터로 검증했고, 오브 제작 시 초기화되기 전에 보존했다. [최종 카운터](../Measurements/Balance/20261003-content-coverage-02/combat-coverage-status.json). 추가 건설 과정의 소스 버전·명령·시각은 회차의 `tool-sources`, `*-command.json`, `events.jsonl.gz`에 남겼다.

## 정상 종료 중 발견한 입력 잠금

첫 오브 제작 시 에너지는 충분하고 편집/메뉴 잠금은 없었지만, 숨겨진 건설 독의 `Transitioning=true`가 HUD 명령을 차단했다. 제작 거부 뒤 저장/부하 비교의 보호 조건도 거부된 원문을 남겼다. 정상 건설 그룹 전환으로 독 전환이 끝난 뒤 같은 제작 명령이 성공했다. 실제 제작 시각은 1,152.411초이며 저장은 1,158.998초다. 명령 거부/분석 대기 시간을 추가 공세 성과로 주장하지 않는다.

제품 코드는 이 회차 중 변경하지 않았다. 회차 종료 후 입력 잠금을 수정했고 별도 실제 Play QA와 297개 회귀를 통과했다. [수정·검증](2026-10-03-hidden-dock-input-fix.md).

## 기록 감사와 저장 복원

- 주 기록4,578행·자원 변경1,154건·표본1,249개·PNG39장/화면 요청137건. 보조 전투933행. 모든 시퀀스·장부·화면 파일/해시·종료 대기 검사 통과. 철/석탄은 각각577 생산/최종 재고577이며 이번 회차에 철도 운송은 없다.
- 두 원본은 종료 후 압축 해제 왕복 검증을 거쳐 gzip으로 보존했다. 압축 파일을 다시 읽은 주 감사는 압축 전과 동일하다. [전체 감사](../Measurements/Balance/20261003-content-coverage-02/audit.json), [보조 감사](../Measurements/Balance/20261003-content-coverage-02/combat-coverage-audit.json).
- 같은 씬의 실제 `ContinueSaved`를 실행했다. **비트 단위 전체 일치는 실패**했고 원문 비교를 보존했다. 차이는 한 기존 포탑 `legacyDirection.x/z`의 최대 약1.79×10⁻⁷뿐이다. 저장 시각/건물 배열 순서를 정규화한 나머지 모든 자원·체력·강화·시계·맵 진행 필드는 정확히 같다.

[엄격 비교](../Measurements/Balance/20261003-content-coverage-02/reload-comparison.json), [방향 오차 검토](../Measurements/Balance/20261003-content-coverage-02/reload-direction-tolerance-review.json), [복원 화면](../Measurements/Balance/20261003-content-coverage-02/reloaded-screen.png).

## 관측 부하: 완료·일시정지 상태 ABBA

정상 완료 저장 후 시뮬레이션을 일시정지하고 주 기록기 Update를 OFF/ON/ON/OFF로 비교했다. 각60프레임 준비+12초 측정, ON구간에 PNG를 한 번 명시적으로 요청했다. 전체 저장 상태는 `savedUtc`를 제외하고 정확히 유지됐고 기록기 enabled를 원복했다. 보조 전투 기록기는 제작 전에 이미 종료됐다.

종료 뒤 같은 씬을 유지한 채 Play·저장 격리·백그라운드 설정을 원복했다. 학술 연구 실험은 실행하지 않았다.
