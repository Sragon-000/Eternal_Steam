# 공통 기반 1단계 검증 결과

검증일: 2026-09-14. Unity 6000.3.14f1, macOS arm64.

원본 프로젝트는 사용자 Editor에서 열려 있어, Assets/Packages/ProjectSettings를 복사한 임시 프로젝트에서 컴파일·테스트·샘플 에셋 생성을 수행했다. 최종 `Assets/EternalSteam` 전체 파일은 검증 복사본과 바이트 단위로 일치함을 확인했다. 기존 HordeDemo 코드·씬·Packages·ProjectSettings에는 변경이 없다.

| 검증 | 결과 |
|---|---|
| 최종 Unity 스크립트 컴파일 | 오류 없음 |
| EditMode | 14/14 통과 — [원시 결과](foundation-editmode.json) |
| PlayMode | 3/3 통과 — [원시 결과](foundation-playmode.json) |
| VerifyFoundationRegression | 세 맵 모두 통과: 로비, 출격, 수동 시작, 통과 후 클리어, 최초 보상, 중복 방지, 저장·해금, 다음 단계, 패배, 재도전, 설치 한도 저장 |
| VerifyStages | 1500/3000/5000 수량, 마지막 적 처리, 다음 단계·배치 유지, 전체 재시작, 통과 처리, 재도전 통과 |
| VerifyCapacityUpgrade | 자원 부족, 비용·한도, 저장 복원, 전투 구매 차단, 최대치, 5000마리 풀 재사용 통과 |
| 시각 확인 | 카메라 캡처로 격자·건물·부채꼴 확인, 별도 UI 렌더 텍스처로 한글·버튼·스크롤 확인 |
| 에셋 참조 | 새 파일의 .meta 누락 없음, 검증 소스/에셋과 원본 일치 |

PlayMode에서 발견한 MaterialPropertyBlock 생성 시점 오류는 Awake/Configure로 옮겨 수정했다. 방향 미리보기·취소·확정뿐 아니라 프리팹의 AttackPivot이 확정 방향을 따르는지도 최종 테스트에 포함한다.

헤드리스의 합성 화면 캡처는 검은 화면이어서 카메라와 UI를 각각 렌더링해 점검했다. 실제 사용자 Editor에서 마우스로 전체 흐름을 수동 조작한 검증이나 실행 파일 빌드는 수행하지 않았다. UI 이벤트는 PlayMode 테스트에서 버튼 이벤트로 검증했다.

대규모 전투 성능 측정은 후속 전투 이전 단계의 작업이다. 이번 결과는 기존 전투의 성능 향상이나 4,000마리 부하에서의 프레임 동등성을 의미하지 않는다. 회귀 도구는 별도 임시 저장 키를 사용하고 정리했다.
