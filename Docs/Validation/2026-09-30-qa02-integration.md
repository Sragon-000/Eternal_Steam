발견·수정: `RailwayNetwork.CanRecover`는 점유 역/운행 선로를 막지만 `WorldEditSession.Confirm`이 이를 호출하지 않았다. 모든 회수 세션을 검증한 뒤 각 철도 건물에 보호 규칙을 적용하고, 하나라도 실패하면 제거를 시작하지 않도록 연결했다. 또한 역 회수 후 `RailwayNetwork`가 역 표시 이름을 복구용 이력으로 보존하는데, `SingleMapPersistence.Validate`는 모든 이름이 현재 설치 역에 대응해야 한다고 요구해 저장이 실패했다. 현재는 설치 역이 존재하면 소속 기지를 대조하고, 철거된 역의 이름은 활성 또는 상실 기지 이력에 연결될 때 허용한다. `Capture`의 상실 기지 목록은 남은 건물뿐 아니라 재고 장부·철도 이름 이력도 포함한다. 이 수정 전 실제 저장 오류는 `역 이름의 건물/기지 참조 오류`였고, 수정 후 같은 회수 시나리오에서 저장·재로드가 통과했다.

Unity EditMode 전체 **198/198 통과**. 검증 뒤 Edit Mode, `Application.runInBackground=false`, 임시 저장 환경변수 해제, 씬 dirty=false를 확인했다. 독립 빌드·강제 종료는 QA-07, 실제 포인터·해상도 입력은 QA-06에 남긴다.
