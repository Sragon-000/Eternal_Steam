# WASD / 적 수량 입력 충돌 수정

Unity 6000.3.14f1, 별도 Editor 검증 복제본. 게임 빌드 없음.

- 수량 필드는 직접 포인터 클릭 전까지 읽기 전용이며 자체 및 내부 텍스트 입력의 focusable을 끈다.
- UI 방향 탐색이 수량 필드로 포커스를 옮기지 않게 한다. 일반 버튼도 키보드 포커스를 받지 않는다.
- 입력 중 숫자만 받으며 잘못된 붙여넣기는 이전 값으로 되돌린다.
- Enter/Esc, 월드 클릭, 소환·초기화·실행 버튼으로 편집을 끝내고 카메라 입력을 복원한다.

`VerifyQuantityFocus`: 프로그램적 Focus 시도 및 W 키/문자 이벤트, 직접 클릭 편집, 편집 중 문자 차단과 카메라 정지, 숫자 허용, 잘못된 붙여넣기 거부, Enter·월드 클릭·소환 후 입력 해제, 정확한 25마리 소환 통과.

`VerifySceneAuthoring`: 초기 배치가 없는 Terrain 씬 복사본에서 토대 2개와 포탑 4종 생성 → 저장·재열기 → 회수·Undo/Redo 통과. 테스트 개체는 원본 씬에 저장하지 않았다.

제공했던 샘플 토대 2개·포탑 4개만 시작 씬에서 제거했다. 배치 모드는 앞선 명시적 요청의 편집 모드 방식을 유지했으며, Play 중 배치를 원하는지 사용자에게 확인을 요청한 상태다.
