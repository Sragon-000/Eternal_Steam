# 고정 메인 기지와 시작 플레이 루프

2026-09-21. 원본 `Assets/EternalSteam/Scene/Tests/StartRegionSandbox.unity`에 적용. 게임 빌드는 하지 않았다.

## 확정된 해석

사용자 확인: **메인 기지 정면 가장자리부터 앞쪽 11×11칸**.

- 1칸은 2m. 메인 기지 점유 4×4칸의 정면 끝에서 앞으로 22m 확장한다.
- 영역은 22m 정사각형이며 뒤쪽으로 확장하지 않는다. 4칸짜리 기지와 11칸짜리 영역은 폭의 홀짝이 다르므로, 좌우 중심을 +X 방향으로 반 칸(1m) 맞춰 실제 설치 격자 경계와 일치시킨다. 1셀 건물 전체가 들어가는 칸은 정확히 121개다.
- 지형상 설치 불가능한 절벽·강·경계는 범위 안에 있어도 기존 지면 검사로 제한한다.
- 서브 기지의 중심 기준 범위·레벨별 확장은 유지한다.

## 적용

- 기존 시작 지점 XZ `(16.97, 11.31)`에 메인 기지 모델을 **씬에 저장**했다. Play 시작 시 `SceneStartingBase` 모델을 일반 배치 트랜잭션으로 등록한다. 점유·체력·전력 저장·피격 대상·기지 영역을 동일 개체에 연결하며 모델을 중복 생성하지 않는다.
- 메인 기지는 건물 인벤토리에서 제외하고 수동 추가 배치도 차단한다. 회수 불가 규칙은 유지한다.
- `IBuildAreaGeometry`가 공통 영역 중심과 좌표 변환을 제공한다. 건물 가동, 전력 공급, 영역 표시, 에너지 추출, 소환 안전 영역에서 같은 정면 범위를 사용한다.
- 실제 Imported Map 인스턴스를 시작 지점 기준 Y축 45° 회전했다. 높이 캐시를 다시 생성하고 보스·지원 소환 위치도 회전된 지형에서 전체 점유 크기로 재검증했다. 외부 맵 프리팹 원본은 수정하지 않았다.
- `AdvanceSimulation`을 공통 진행 경로로 사용한다. 시간·전력·자원 생산·에너지 추출·야간 공세·이동·공격이 같은 경과 시간을 사용한다. 수정 상태와 시간 정지는 전체 진행을 멈추며, 확정/취소 후 별도 전투 실행 없이 이어진다. 프레임 지연은 0.1초 이하 단계로 나누고 처리하지 못한 시간은 보존한다.
- 상단 시간/자원/테스트 패널은 위로, 하단 인벤토리는 아래로 접고 펼친다. 기존 위치와 정보 순서를 유지했다. 접기는 표시만 바꾸며 수정 상태·선택 분류·임시 작업을 취소하지 않는다. 하단 수정/확정 버튼은 남는다.

## 플레이 흐름

고정 메인 기지로 시작 → 수정에서 정면 영역에 발전기·생산 건물·방어 건물 배치 → 확정 → 생산·전력·에너지 추출 → 밤 자동 공세 → 90% 확보 이후 보스 → 보스 처치 → 상단 오브 제작으로 클리어.

전력은 발전기와 포탑 운용을 연결한다. 일반 자원 재고, 기지 전력, 맵 에너지는 서로 다른 상태로 유지한다. 확정되지 않은 자원별 건설·강화 비용이나 저장/맵 이동 규칙은 이번 작업에서 새로 정하지 않았다.

## 검증

- `Tools/VerifyStartLoop.cs`: 씬 모델 재사용, 자동 메인 1개, 수동 메인 거절, 정면 121셀, 발전기/자원/방어 배치·가동, 실제 자원 적립, 편집·시간정지 동결/재개, 인벤토리 상태 유지, 실제 야간 적·보스 생성, 보스 처치와 오브 제작.
- `Tools/VerifyHudFolds.cs`: 연결된 UI 버튼 콜백으로 상단 3개 패널과 하단 인벤토리 접기/펼치기 검증.
- 원본 씬 재시작 후 자동 기지 중복 없음. 회전된 시작 기지 전체 지면과 3×3 보스 지면 검증.
- 실제 PlayerLoop 관찰: 300프레임 동안 시간 2.0252초 진행, 일시정지 1초 동안 변화 0. 처음에는 백그라운드 Editor가 프레임을 진행하지 않아, 검증 실행 중에만 `Application.runInBackground`를 켠 뒤 측정했다. 프로젝트의 영구 실행 설정은 변경하지 않았다.
- Editor 컴파일 오류 및 검사 시점 콘솔 오류 0. 화면 확인: `Validation/start-loop-expanded.png`, `Validation/start-loop-folded.png`.
- 기존 수동 메인 설치를 가정했던 CLI 검증 도구는 자동 설치된 메인도 사용할 수 있도록 수정했다. 이전 검증 결과를 이번 전체 회귀 통과로 간주하지 않는다.
