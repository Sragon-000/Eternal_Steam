## 3. 구현 전에 정할 경계와 미정 사항

### 기존 결정과의 충돌

1. **DAY 능력치 증가:** 두 문서는 증가를 명시하지만 이전 사용자 요청은 미적용/검토였다. 수량 곡선과 능력치 곡선을 별도로 준비하고 능력치 증가는 승인 전 비활성으로 유지한다. 고정 피해 1과도 충돌하므로 어느 적 능력치가 증가하는지 확정해야 한다.
2. **시간 소유:** 과거 기지별 독립 라운드와 새 문서의 맵 DAY를 연결해야 한다. 제안은 맵별 DAY와 맵 내 공통 밤/웨이브다. 다른 맵의 DAY·생산·재활성화 타이머가 방문하지 않을 때 진행하는지는 별도 결정이다.
3. **영역 밖 설치:** 이전에 허용한 외부 설치·범위 밖 비작동을 유지하는 호환안으로 설계한다. 새 문서가 외부 설치 자체를 금지하려는 것인지는 확인한다. 기존 외부 전초를 정상 기지로 셀지/영역 제공자로 남길지도 미정이며 자동으로 기지 수에 포함하지 않는다.
4. **비활성 건물 피격:** 원문의 TBD-014는 미정이다. 기존 피격 가능 동작은 유지하되 새 기획 확정으로 표시하지 않는다.

### 수치·공간·진행 미정

- 기획의 1칸을 기존 2m·45도 건설 셀과 통일할지, 별도 맵 셀로 둘지 결정한다. 통일 시 최소 맵은 300m×300m의 논리 영역이므로 현재 50m 프리팹과 상당한 차이가 있다.
- 메인 기지 오브젝트의 점유 크기와 최초 설치 허용 구역은 이번 문서에 없다. 11×11은 제공 범위이지 외형 점유 크기로 간주하지 않는다.
- 11→12처럼 홀짝이 바뀌는 범위는 중심 유지/한쪽 셀 추가 중 선택한다. 영역 판정·에너지 셀·안전 영역·표시는 같은 규칙을 사용한다. 건물 전체 점유가 들어가야 가동되는 현재 판정은 확인 전 보존한다.
- 칸당 초기량·초당 추출률·추출 주기·오브 목표량·적 처치 보상·기지 강화 비용·해금표·보스 전투 설정이 필요하다. `칸당 추출량 × 추출 주기`는 초당량×초인지, 회당량인지 단위를 먼저 고정한다.
- 45/45/10 중 앞의 45는 목표 비율이지 경로별 상한이 아니다. 재배치로 새로운 칸을 추출할 수 있으므로 총 추출 비중을 45%로 강제하지 않는다.
- 자연 회복 여부는 TBD 표에 ‘확정’만 있고 본문의 명시적 회복 규칙은 없다. 고갈은 저장하고 자동 회복을 넣지 않는 제안으로 두며 확인한다.
- 에너지의 오브 제작 외 소비처는 없다. 소비를 도입하면 누적 100%여도 현재 잔액이 부족해 진행이 막힐 수 있으므로 별도 설계가 필요하다.
- 유효 스폰 셀 수가 목표보다 적거나 0개인 경우: 안전 범위/중복 금지를 깨지 않고 가능한 위치만 사용하며 미소환 예산을 보류하는 제안. ‘항상 8개’와 물리적 불가능 상황의 처리 기준 확인 필요.
- 낮 잔존 적, 낮 전환 시 미소환 예산, 보스전이 낮까지 이어질 때 소환, 클리어 직후 남은 적 처리, 맵 최소 소환 간격, 웨이브 주기·물량 표는 미정.
- 기존 직선 경로 필터는 도달 못 하는 칸을 배제해 ‘동일 확률’의 모집단을 바꾼다. 유효 칸이 단순 지면인지 도달 가능한 지면인지 확정하고, 지형 우회가 필요하면 별도 경로 탐색 작업을 잡는다.
- 메인 파괴 후 재시작/체크포인트, 서브 회수의 레벨·현재 HP·환급 및 재건 비용, 9종 오브 효과/특수 건물 목록, 재활성화 발동 방식·전투 종료·보상은 원문상 미정이다.
- 본문의 Day 1~7은 플레이 예시로 취급하며 고정 보스 출현일·클리어 제한으로 구현하지 않는다.

## 5. 단계별 적용과 완료 조건

### A. 맵·격자 계약과 기지 기반

대상: MAP-001, MAIN-001~006, SUB-001~009, BUILDING-001~005.

- MapId와 메인/서브 정의를 만들고 기존 넥서스의 호환 ID를 매핑한다. UI 명칭은 기지로 전환한다.
- 메인 1개·서브 레벨/수량 한도를 배치 예약과 전체 확정 양쪽에서 검사한다. 같은 작업에 여러 기지를 넣거나 여러 토대 월드를 사용해도 제한을 우회하지 못하게 한다.
- 메인 확정 후 회수/이동 차단. 실패 시 실행만 종료하며 저장 삭제·자동 재시작은 하지 않는다.
- 서브 범위와 최대 HP는 원문 식을 적용한다. 메인 강화는 범위를 늘리지 않는다.
- 가동 범위를 전체 정상 기지의 합집합으로 전환한다. 회수 예정은 확정 전까지 범위를 유지하고 파괴 시 즉시 제거한다. 범위 밖 건물 자체는 남는다.
- 완료: 1/5/10개 경계, Lv.10·11~20칸·HP100~280, 중복 범위 A 제거 후 B 유지, 메인 파괴만 실패, 기존 설치/회수/포탑 회전·냉각 회귀.

### B. 맵 에너지 추출과 표시

대상: ENERGY-001~005, RESOURCE-001~002.

- 맵의 모든 논리 셀에 동일 초기량을 갖는 잔량 배열을 둔다. 저장·재방문·기지 재배치로 잔량이 복구되지 않는다.
- 추출은 기지 개수대로 반복하지 않고 합집합의 미고갈 셀에 한 번 적용한다. 셀별 `min(남은 양, 이번 주기 추출량)`을 지급하며 실제 지급량만 셀에서 차감한다.
- 공유 ResourceBank와 맵 에너지 원장을 분리한다. 칸 추출 누적/일반 적 처치 누적/보스 보상/현재 잔고를 구분한다.
- 원자 지급 함수가 보스 전 누적을 목표의 90%로 제한한다. 다수 적 처치와 추출이 같은 프레임에 발생해도 초과 지급하지 않는다. 보스 10%를 더해 정확히 100%가 되도록 고정 소수 단위/목표량 분할을 정의한다.
- 추출 진행도와 확보 진행도를 각각 표시한다. 임계 판정에 UI 반올림 값을 사용하지 않는다. 보스 보상은 획득 총량에 포함하되 기지 추출로 표시하지 않는다.
- 완료: 중첩·회수·재배치·고갈, 89.99→90 정확한 잔여 지급, 대량 처치 중복 보상 차단, 다른 맵 에너지 혼용 불가. 45% 경로별 강제 제한 없음.

### C. 안전 범위와 야간 일반 소환

대상: SAFE, SPAWN-000~004, SPAWN-DESTROY.

- 매일 밤 한 번, 안전 영역 밖 유효 셀에서 같은 확률로 중복 없이 정상 기지 수+1개의 위치를 선정한다. 위치는 밤 동안 유지한다. 저장 가능한 난수 상태/시드로 재현한다.
- 기지 설치·회수·파괴·강화 시 유효한 기존 위치를 최대한 유지하고 부족분만 추가한다. 과잉 위치 해제 순서도 결정적으로 정의한다.
- 전체 적 물량은 위치 수와 분리한다. 위치가 없어져도 대기 예산을 다른 지점으로 넘기며 적을 감소시키지 않는다. 실체 생성은 기존 동시 처리 한도·최소 적 간격을 적용한다.
- 현재 검증용 누적 1억 제한을 제품의 모든 DAY 합계 제한으로 사용하지 않는다. 요청 API는 개발자 기능으로 분리하고 제품 소환 예산에는 적합한 정수형·수명 범위를 둔다.
- 실제 생성 위치가 포인트 주변으로 퍼지면 주변 좌표도 안전/지면/점유/간격을 재검증한다.
- 완료: 균등 무복원 추첨, 같은 밤 위치 유지, 기지 수 변화/안전범위 덮임, 위치 0개 보류, 예산 보존, 동시 10만에서 매 적×전맵 셀 검사 없음.

### D. 보스 조건·소환·보상·오브 제작

대상: BOSS, ORB, CLEAR.

상태 흐름:
`공략 → (낮 90%: 보스 대기 / 밤 90%: 즉시 보스전) → 보스전 → 제작 대기 → 클리어`
정상 진행 어느 단계에서든 메인 기지 파괴는 실패로 전환한다. 동시 보스 사망/메인 파괴는 처리 우선순위를 확정한다.

- 90% 도달 즉시 지면 추출과 일반 적 에너지 지급을 중단한다. 경고는 한 번 표시한다. 직접 보스 소환 버튼이나 최소 DAY 조건은 만들지 않는다.
- 보스 출현 때 일반 소환 정책을 고정 8개로 전환한다. 안전 범위에 가려진 고정 위치마다 균등 임시 위치 1개를 대체한다. 고정 위치 복구 시 대체 위치 1개를 제거한다. 대기 예산/기존 적은 전환만으로 삭제하지 않는다.
- 보스 자신의 위치는 별도이며 안전 범위로 비활성화하지 않는다. 건물과 겹칠 때 실제 생성 충돌 처리 규칙은 정한다.
- 보스 사망은 동일 EncounterId에 대해 불완전 오브와 목표량 10%를 한 번 지급한다. 이후 지면 추출을 재개하지 않는다. 일반 적의 보스 이후 지역 에너지 지급은 명시 규칙 확인 전 추가하지 않는다.
- 오브 제작은 해당 맵 에너지 목표량과 불완전 오브를 한 트랜잭션으로 소비하고 완벽 오브 소유·영구 해금·맵 클리어를 기록한다. 이중 클릭/재로드/콜백 재호출로 중복 획득 불가.
- 완료: 낮/밤 임계·개발자 전환 반복에도 보스 한 번, 8개 대체 복원·보스 안전 예외, 90+10=100, 잘못된 맵 재료 거부, 보스 처치만으로 클리어하지 않음, 제작 순간 일반 신규 소환/남은 소환 큐 중단.

### E. 다중 맵·저장·생산 거점

대상: MAP-003, CLEAR-004, OUTPOST, ORB-FUNCTION.

- 고정 MapId·BaseId·BuildingId와 저장 버전을 도입한다. 현재 GUID는 런타임 생성이므로 로드 시 동일 식별자 복원이 필요하다. 기존 데모 저장과 분리/호환하고 성공 전 원본 저장을 바꾸지 않는다.
- 맵별 기지·레벨·건물·고갈 셀·DAY·소환 계획·진행 단계·보스 보상 상태를 보존한다. 완벽 오브·영구 해금·일반 재고는 캠페인 상태로 관리한다.
- 클리어 맵의 건물은 유지하고 생산을 계속한다. 씬이 로드되지 않았을 때도 논리 생산으로 처리하며 활성 씬과 동시 이중 생산하지 않는다. 오프라인 생산은 별도 승인이 없으면 추가하지 않는다.
- 다음 맵 메인 기지는 Lv.1이며 이전 맵 레벨/설치 수를 공유하지 않는다. 일반 자원만 공유한다.
- 완료: 클리어→다음 맵→재방문, 재고·시설·고갈 보존, 영구 해금 어디서든 사용, 보스 보상/제작 도중 저장 복구, 손상 저장 처리, 기존 저장 회귀.

### F. 재활성화와 확장 콘텐츠

대상: REACTIVATE, RE-SPAWN, TBD-009/012.

- 발동 조건이 확정되면 3 DAY 준비와 남은 시간 UI를 붙인다.
- 재활성화는 외곽 8개 특수 균열을 사용하며 안전 범위로 막지 않는다. 보스전 일반 고정 8개와 좌표를 공유하더라도 정책/ID는 분리한다. 보스는 원래 별도 위치를 사용한다.
- 반복 전투의 물량·스펙·보상·종료 조건과 9종 오브 효과/특수 건물은 기획 대기. 최초 클리어 보상을 다시 지급하지 않는다.
- 완료: 3 DAY 경계·맵 전환/저장, 안전 영역 예외, 반복 종료 후 생산 거점 복귀, 영구 오브 중복 없음.

## 6. 공통 검증과 실제 구현 착수 범위

모든 단계에서 메인/서브의 수명과 상태 변화에 연결된 참조·구독을 해제하고, 정의 에셋에 HP·현재 레벨·타겟·고갈량을 기록하지 않는다. 밤 전환·기지 영역 변경만으로 매 프레임 전맵 셀을 새로 할당하지 않는다. 4천/1만/10만 적 비교는 동일 맵·시드·배치로 CPU 중앙값/p95·GC를 3회 측정한다. 구현 단계에서도 게임 빌드는 별도 요청 없이는 수행하지 않는다.

기존 시간 기록에 자동 진행 검증 미통과가 남아 있으므로 A 착수 전에 GameClock·생산의 실제 프레임 진행, 수정/정지, UI 버튼/월드 입력 분리를 재검증한다. 직접 Tick 호출 테스트를 실제 시간 검증과 혼동하지 않는다.

권장 첫 구현 범위는 **A: 메인/서브·범위·기지 한도**다. 선행으로 칸 단위·메인 점유/설치 위치·홀짝 영역 정렬을 확정한다. 그 다음 **B 에너지**와 **C 일반 스폰**을 별개로 검증하고 **D 보스·오브**에서 연결한다. E의 저장 계약은 A부터 고려하지만 실제 맵 전환은 단일 맵 사이클이 검증된 뒤 적용한다. 현재 50×50 프리팹은 소규모 검증용으로 보존하며 최종 맵 요구 충족으로 보고하지 않는다.
