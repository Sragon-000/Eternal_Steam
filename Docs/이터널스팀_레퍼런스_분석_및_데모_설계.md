# 이터널스팀 레퍼런스 분석과 데모 설계

> 이 문서는 2026-09-10 초기 분석 기록입니다. 현재 구현 범위는 루트 README를 따릅니다. 2026-09-24 추가 레퍼런스는 [BELTFED](References/BELTFED.md)를 참고하세요.

조사일 2026년 9월 10일 · 대상 Sir, We Have an Orc Problem · 기획 검토용

## 1 핵심 판단

이터널스팀 데모는 적이 몰려오고, 플레이어가 포탑을 설치하고, 포탑이 자동으로 공격하는 기본 동작을 검증한다. 아래 원작 분석은 참고 자료이며 데모 구현 범위는 5절을 따른다. 원작은 짧은 인크리멘털 타워 디펜스로, 승패와 관계없이 얻은 자원으로 포탑을 해금하고 강화한다. 수동 능력이 위기 대응을 담당한다. [S1]

최소 구성은 테스트 맵 1개, 적 1종, 기본 포탑 1종이다. 재화·강화·수동 능력·저장·승패 판정은 데모 범위에 포함하지 않는다. 별도의 목표 플레이 시간도 설정하지 않는다.

### 정보를 구분하는 기준

| 표시 | 의미 |
| --- | --- |
| 공식 확인 | 개발사 상점 설명, 공지, 공식 업적에 직접 명시된 내용 |
| 플레이어 보고 | 공략 작성자의 경험. 출시 빌드와 업데이트에 따라 달라질 수 있음 |
| 설계 해석 | 확인된 시스템이 만드는 재미와 선택에 대한 분석 |
| 데모 제안 | 이터널스팀을 위해 새로 정한 규칙과 초기 수치 |

### 먼저 바로잡을 점

기존 기획서에는 처치 재화로 포탑을 설치하고 강화한다고 적혀 있다. 하지만 원작의 전투 중 재화 소비·즉석 강화 규칙은 이번 자료만으로 확정할 수 없다. 데모에서는 적이 이동하는 동안 포탑을 무료로 설치한다. 준비 단계와 전투 단계를 분리하지 않는다.

### 버전 차이

개발자의 출시 전 공개 테스트 안내는 5개 레벨, 포탑 4종, 능력 2종, 약 50개 강화와 90~120분 분량이었다. 이는 정식판 전체 분량이 아니다. [S3] 출시 후 자료와 혼동하지 않는다.

## 2 전투와 배치 시스템

### 원작에서 확인한 흐름

플레이어 공략에 나타난 흐름은 스테이지 선택 → 포탑 배치와 방향 설정 → 전투 시작 → 수동 공격과 능력 사용 → 결과 확인 → 연구 → 재도전이다. Space로 전투를 시작하고 마우스로 미사일을 조준·발사한다는 보고가 있다. 자동 미사일도 조준 위치는 커서를 따르는 것으로 설명된다. [S6 · 플레이어 보고]

### 지형과 물량

공개 테스트 플레이어는 적들이 기지 쪽 최단 경로로 몰리면서 서로 밀려 좁은 통로를 통과한다고 설명한다. 코너와 합류점에 화력을 집중하고 출구에는 잔적 처리용 포탑을 두는 전략을 제시한다. 다만 당시의 무제한 설치 관련 설명은 현재 정식판 규칙으로 채택하지 않는다. [S4 · 출시 전 플레이어 보고]

설계 해석: 길을 따라 적을 오래 맞히는 배치가 유리하다. 일렬 관통, 넓은 범위 공격, 남은 소수 처리의 효율이 달라지기 때문에 포탑의 총 공격력뿐 아니라 사선과 병목 형태가 선택을 만든다.

### 조준과 공격 피드백

공식 업데이트는 탄 퍼짐과 탄 크기를 포함하도록 조준 미리보기를 수정했고, 레이저를 흔들림 없이 직선으로 발사하는 강화도 추가했다. 사격 방향과 투사체 범위가 실제 전략 요소임을 뒷받침한다. [S2 · 공식 확인]

### 승패와 완벽 방어

일부 적이 빠져나가도 생존할 수 있으며 전원 처치와 생존은 별도 결과라는 플레이어 보고가 있다. 완벽 방어용 자원과 일반 생존 결과를 구분한다. 정확한 자원명, 반복 지급 여부, 해금 조건은 직접 플레이로 추가 확인해야 한다. [S6 · 플레이어 보고]

공식 업적에는 특정 레벨 생존, 포탑 1개만 사용, 포탑 없이 생존, 포탑 종류 제한 등이 존재한다. 같은 맵에 다른 제약을 주어 재도전을 유도하는 구조는 확인된다. [S5 · 공식 확인]

## 3 포탑과 수동 능력

아래 7종은 정식 출시 후 Steam 공략에서 보고된 포탑이다. 역할은 공략의 사용 경험을 짧게 정리했다. 원작의 정확한 공격력·가격·최대 레벨이나 보편적인 티어 순위로 해석하지 않는다. [S7 · 플레이어 보고]

| 포탑 | 보고된 특징 | 데모 반영 |
| --- | --- | --- |
| Gunner | 빠른 연사와 잔적 처리, 성장 후 군집 대응 | 리벳 기관포 |
| Mortar | 범위 피해와 밀쳐내기 | 후속 확장 |
| Cannon | 느린 발사와 강한 관통 | 후속 확장 |
| Flamethrower | 화상과 지원 효과 | 후속 검토 |
| Tesla Coil | 연쇄 공격과 제어, 넓은 방향 대응 | 후속 확장 |
| Grenade Launcher | 둔화와 피해 증폭 지원 | 후속 검토 |
| Laser | 장거리 관통과 벽 반사 | 후속 확장 |

설계 해석: 주력 피해·제어·잔적 처리의 조합은 추후 포탑 확장 시 참고할 수 있다. 이번 데모에는 단일 대상을 자동 공격하는 기본 포탑만 사용한다.

### 원작 능력의 확인 수준

| 능력 | 확인한 내용 | 근거 |
| --- | --- | --- |
| Strafing Run | 넓은 구간을 공격. 사용 횟수 강화가 추가됨 | 공식 S1·S2 |
| Orbital Laser | 개발사가 능력으로 소개 | 공식 S1 |
| Nuke | 광역 위기 대응. 단일 사용 피해량 업적 존재 | 공식 S1·S5 |
| Missile | 직접 조준하는 수동 공격 | 플레이어 S6·S8 |
| Cryo Beam | 냉각 제어 능력. 특정 조합 업적에 포함 | 공식 S5 / 플레이어 S8 |

능력 전체 목록과 각 능력의 자원·연료·횟수·재사용 대기시간 체계는 아직 완전하게 확인되지 않았다. 수동 능력은 이번 데모에 포함하지 않는다.

## 4 영구 성장과 반복 플레이

### 강화가 다음 도전에 남는다

전투 승패에 관계없이 얻은 자원을 포탑 해금과 강화에 쓰는 영구 성장 구조는 공식 설명으로 확인된다. [S1] 공략은 공격력·연사·관통·배치 가능 수량과 경제 강화를 구분한다. 추가 포탑 수량을 늘릴지 기존 포탑을 강화할지 선택하는 형태다. [S9 · 플레이어 보고]

### 경제에서 확인한 세부 규칙

공식 데모 패치에서는 항복 시 고정 보너스 자원을 지급하지 않도록 바꾸었고, 패배 또는 생존으로 전투를 끝내면 지급되도록 했다. 비례 보너스는 항복에도 유지된다고 설명한다. 이 규칙은 해당 데모 패치 시점의 근거이며 최신 전체 정산식을 확정하지는 않는다. [S2]

출시 시점 공략에는 Silver Orc 관련 수입 강화, 전투 종료 보너스, 생존과 완벽 방어 보상의 구분이 보고되어 있다. 정확한 획득 확률·가격과 총 연구 비용은 최신 값으로 사용하지 않는다. [S9]

### 재도전 동기를 만드는 방식

설계 해석: 실패한 도전도 다음 구매에 기여하고, 구매한 강화가 같은 배치의 결과를 개선하면 재시도 이유가 생긴다. 반대로 같은 맵을 변화 없이 반복해야 한다면 성장 과정이 지루해질 수 있다. 영구 성장은 이번 데모에 포함하지 않는다.

### 결과 화면의 역할

공식 데모 업데이트는 상세 전투 결과, 적 수를 보여주는 레벨 선택 화면, 강화의 누적 값 툴팁, 능력 통계 패널을 추가했다. [S2] 결과 화면은 이번 데모에 포함하지 않는다.

### 수치 복사보다 검증할 질문

위치를 옮겨야 하는 실패인지, 공격력이 부족한 실패인지 구분되는가. 강화를 한 번 샀을 때 결과가 눈에 띄게 달라지는가. 수동 능력이 위기 대응에 도움이 되는가. 다음 구매까지 걸리는 반복 횟수가 부담스럽지 않은가. 이 질문은 추후 성장 시스템을 추가할 때 참고한다.

## 5 최소 데모 구현 범위

목표는 적의 이동, 포탑 설치, 자동 공격이 한 화면에서 이어지는 동작을 확인하는 것이다. 아래 세부 조작은 최소 구현을 위한 기본안이다.

### 적이 몰려온다

테스트 맵 1개에 입구와 이동 경로를 둔다. 적 1종이 일정 간격으로 생성되어 경로를 따라 이동한다. 끝에 도착한 적은 제거한다. 기지 체력과 승패 판정은 만들지 않는다.

### 포탑을 설치한다

적이 이동하는 동안 마우스로 설치 가능한 바닥을 클릭하면 기본 포탑이 설치된다. 재화나 해금 조건은 없다. 경로 위와 기존 포탑에 겹치는 설치만 막는다. 이동·회수·수동 회전 기능은 필수가 아니다.

### 포탑이 자동으로 공격한다

포탑은 사거리 안의 가장 가까운 적을 찾아 일정 주기로 자동 공격한다. 발사체 또는 간단한 사격 효과로 공격을 보여주고, 적의 체력이 0이 되면 제거한다. 대상이 죽거나 사거리에서 벗어나면 다른 적을 찾는다.

### 최소 콘텐츠와 화면

맵 1개, 적 1종, 포탑 1종으로 구성한다. 임시 도형이나 스프라이트로 먼저 연결한다. 메인 메뉴, 스테이지 선택, 결과 화면, 연구 화면은 필요하지 않다.

### 이번 데모의 완료 기준

1. 실행하면 적이 반복 생성되어 경로를 따라 이동한다.
2. 적이 이동하는 중에 여러 포탑을 설치할 수 있다.
3. 포탑이 사거리 안의 적을 자동 공격하고 처치한다.
4. 적이 없으면 공격을 멈추고, 새 적이 들어오면 다시 공격한다.
5. 경로 끝에 도달한 적과 처치된 적이 누적되지 않는다.

### 작업 순서

적 생성과 이동 → 포탑 설치 → 적 탐색과 자동 공격 → 피해와 제거 순서로 연결한다. 한 화면에서 이 흐름이 작동하면 데모 범위는 완료다. 재화·강화·능력·저장·다중 맵·추가 포탑은 후속 작업으로 둔다.
