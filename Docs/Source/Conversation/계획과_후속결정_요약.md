# 채팅으로 전달된 계획·후속 결정 요약

보관일: 2026-09-20. 이 파일은 대화 내용의 요약이며 첨부 원문이나 전체 채팅 내보내기가 아니다. 실제 적용 상태는 Docs의 적용 결과를 확인한다. 초기 요청과 후속 수정은 서로 다른 시점의 요구로 구분한다.

## 공통 기반 계획

사용자가 전달한 「Eternal Steam 전체 개선 계획 — 콘텐츠를 조합하는 공통 기반」은 기존 데모를 유지하면서 정의 에셋과 개체 실행 상태를 분리하고, 기능별 모듈·명시적 카탈로그·배치/회수 트랜잭션·표적 핸들·공통 생명주기를 구축하는 계획이었다. 첫 완료 범위는 공통 기반과 별도 검증 씬이다. 신규 경제·성장·콘텐츠 수치는 확정하지 않으며 기존 3개 맵·저장 호환을 유지한다. 레거시 배치→전투→콘텐츠/UI→진행/저장 순으로 이전하고 EditMode·PlayMode·대규모 적 성능을 검증한다.

후속 결정: 모듈화는 개발 구조의 책임 분리이며 플레이어가 기능을 선택하는 시스템을 뜻하지 않는다. 씬은 EternalSteam/Scene에서 관리한다. 원본 프로젝트에서 작업하고 게임 빌드는 하지 않는다. RTK 사용을 중단한다.

## 방벽·건물 피격 및 적 공격 계획

- 방벽/방어 건물 체력 100, 일반 건물·전초 50, 넥서스 1,000. 토대는 공격 대상 제외.
- 적은 넥서스에 도착해 사라지지 않고 건물 외곽 1m에서 공격한다. 첫 공격까지 1초 대기하고 이후 1초마다 피해 1. 피해 1은 고정, 나머지 수치는 검증 설정.
- 지상 적은 10m 내 방어 건물을 우선 탐색하고 진로의 방벽/건물을 먼저 파괴한다. 공중 적은 방벽을 통과하며 방어→일반→넥서스를 선택하고 방벽은 공격하지 않는다.
- 같은 우선순위는 거리→등록 ID. 유효 목표 유지, 장애물 파괴 후 재탐색. 냉각은 이동만, 기절은 이동·공격 모두 차단.
- 기존 체력 모듈, 명시적 전투 역할, 전역 표적 핸들, 건물 공간 인덱스, 적 슬롯별 배열 상태 사용. 탐색은 0.25초 분산. 이동 구간 전체와 회전된 점유 영역 충돌 검사.
- 확정된 건물만 등록. 회수 예정은 유지. 범위 밖 비작동 건물도 피격·차단 가능. 파괴 시 외형/점유/표적 해제, 토대는 유지.
- 넥서스 파괴는 해당 기지만 영향. 다른 기지로 재선정하며 모두 없어지면 소환 대기 보류, 잔여 공격 대상 처리 후 대기.
- 원본 StartRegionSandbox와 기존 오픈월드에 적용. 길찾기·낮밤·라운드·저장은 당시 범위 밖. 4천/1만/10만 비용·GC 측정.

## 건설·입력 후속 결정

- 플레이어 캐릭터 없이 탑뷰, WASD 카메라 이동·휠 줌. 인게임 수정/확정으로 건설한다.
- 수정 버튼 재클릭은 수정 취소 및 임시 배치 취소. 기존 건물 클릭은 즉시 제거가 아닌 회수 예정, 확정 시 회수.
- 넥서스 범위에 그리드를 표시하고 토대 없이 방어 건물 설치 가능. 후속 회의에서 외부 설치 가능·영역 밖 비작동 승인. 그리드는 수정 중에만 표시.
- 포탑은 방향 지정 대신 원형 사거리 자동 공격. 일반 상태에서 포탑 클릭 시 사거리 표시. 냉각 적 재탐색과 개별 포탑 회전속도 모듈 요청.
- 방벽의 최초 드래그 연속 배치는 후속 요청으로 두 클릭 시작/끝점 직선 배치로 변경. 사각 드래그는 수정 중 회수 예정 복수 선택.
- 프리팹 맵을 기존 시작 씬에 적용. 맵과 시계 UI를 런타임 전용 생성이 아닌 에디터에서 관리하도록 요청.

## 일정과 구현 범위의 후속 결정

첨부 일정 계획.md는 최소 완료선을 적 디자인/애니메이션까지로 정하고 이후 맵 확장·추가 건물·기차 물류·반복 테스트를 둔다. 날짜별 적 강화, 저장 건물, 서브 기지 이동·회수는 검토 사항이다.

이후 사용자는 세부 기획 중이므로 시간 시스템/UI만 먼저 적용하도록 제한했다. 낮·밤 시계는 절반씩 나눈 원형을 요청했다. 그 다음 일정의 자원 생산 및 2.1 최상단 UI까지 허용하고 2.2 이후 제한/개수 등은 기획 대기로 남겼다. 이전 계획의 모든 기능이 승인·완료된 것으로 취급하지 않는다.
