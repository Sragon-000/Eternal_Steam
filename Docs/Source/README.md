## 첨부 파일 원본 사본

이 대화에서 사용자가 직접 첨부한 7개 Markdown 문서와 1개 참고 이미지다. 제공된 Downloads 경로에서 바이트 변경 없이 복사했고 SHA-256과 파일 크기로 일치 여부를 검증했다. 파일명만 한글 NFC 표기로 통일했으며 본문은 수정하지 않았다. Downloads 원본은 그대로 유지한다. 전송 이후 원본 파일이 수정되었는지까지는 확인할 수 없으므로 보관 시점의 파일 사본이다.

기획 원본과 구현 상태는 구분한다. 이 폴더의 과거 계획이 최신 요청을 덮어쓰지 않으며, 실제 적용/미적용 상태는 상위 Docs의 결과 문서를 따른다. 새 원본이 도착하면 기존 사본을 덮어쓰기보다 날짜/버전을 구분하여 보관한다.
