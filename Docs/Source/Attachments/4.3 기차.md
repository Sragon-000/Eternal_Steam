# 기차 · 기차역 시스템 요구사항

> 문서 목적: 플레이어가 선로라는 물리 시설을 직접 건설하고, 여러 기차역과 선로 구간을 연결해 **폐쇄 순환 노선**을 구성한다. 노선에 배정된 기차는 순환 운행하며 자원을 운송하고 이동형 방어 수단으로도 운용된다.  
> 문서 상태: 구현 기준 초안. 합의된 기본 구조를 정의했으며, `결정 필요` 항목은 후속 설계에서 확정한다.

---

## 1. 시스템 개요

| 구분 | 규칙 |
| --- | --- |
| 시스템 목표 | 외곽 기지에서 생산한 일반 자원을 원하는 기지로 운반하고, 철도 경로에 이동형 방어력을 제공한다. |
| 기차역 | 설치 시 방향을 지정하는 `2×2칸` 건물이다. 여러 선로 연결 포트를 가질 수 있으며, 플레이어가 각 포트를 진입 또는 진출로 지정한다. 노선은 사용할 포트를 구간별로 지정한다. UI 이름은 `<기지 이름> 역`으로 표시한다. |
| 선로 설치 | 선로는 자동 생성하지 않는다. 플레이어가 **방벽과 동일한 설치 방식**으로 1칸씩 직접 배치한다. |
| 선로 | 선로는 맵에 타일 단위로 설치하는 단방향 물리 시설이다. 설치만으로 노선이 생성되지는 않는다. |
| 노선 | 노선은 플레이어가 역의 순서와 역 사이 선로 구간을 지정해 만드는 폐쇄 순환 경로다. 마지막 역에서 첫 역으로 이어져야 한다. |
| 기차 배정 | 유효한 노선을 생성하면 기본 기차 1대를 자동 생성해 해당 노선에 배정한다. 추가 기차 배정은 확장 기능이다. |
| 자원 처리 | 각 화물칸에 적재할 자원 종류를 하나 지정한다. 각 역은 화물칸별 자원의 적재 목표량과 하역량을 설정하며, 기차는 역마다 하역 후 적재한다. 실제 적재량은 해당 시점의 역 가용 재고와 해당 화물칸 여유량을 넘을 수 없다. |
| 순환 운행 | 기차는 `A → B → C → D → A`처럼 노선에 등록된 역을 순서대로 방문하고 계속 순환한다. 각 구간은 노선에 지정된 진행 방향으로 연결되어야 한다. |
| 적 AI 대상 | 적은 선로와 기차를 공격 대상으로 선택하거나 기차에 어그로를 끌지 않는다. 선로는 공격·파괴 불가 오브젝트다. |
| 연료 | 연료칸의 최대 석탄량은 노선에 연결된 역 하나당 50개를 기준으로 계산한다(임시값). 플레이어가 운행 시작 전에 직접 적재하며, 운행 중에는 자동 보급하지 않는다. 다음 구간 이동에 필요한 석탄이 부족하면 역에서 대기한다. |

### 1.1 시스템 범위

- 철도는 현재 맵 안의 기지 사이에서만 연결한다. 맵 간 운송은 범위에서 제외한다.
- 운송 대상은 철·구리·티타늄 등 일반 자원이다. 지역 에너지, 완벽한 오브, 진행 아이템은 운송하지 않는다.
- 전력은 기지별 저장·공급 규칙을 유지하며, 철도로 운송하지 않는다.
- 기차역은 기지 설치 범위 밖에 존재하면 비활성화된다. 비활성 역에 연결된 노선은 운행할 수 없다.

## 2. 핵심 개념

### 2.1 선로의 정의와 개념

```text
방향이 지정된 선로 타일들의 연결 = 역 사이를 잇는 단방향 물리 구간
선로 설치만으로는 역 순서, 운행 방향, 기차가 정해지지 않음
```

- 선로는 타일 단위로 건설·회수하는 단방향 물리 오브젝트이며, 기차가 한 방향으로 이동할 수 있는 연결을 제공한다.
- 인접 선로의 자동 외형 연결은 시각 표현만 처리한다. 경로 지정이나 노선 생성은 하지 않는다.
- 선로 타일이 연속되어도 플레이어가 노선을 구성하기 전에는 기차가 운행하지 않는다.
- 하나의 선로 구간은 출발역의 지정 진출 포트에서 도착역의 지정 진입 포트까지 기차가 한 방향으로 이동할 수 있는 연속 경로다.
- 노선 편집 시 선로 구간의 진행 방향이 정해진다. 이미 다른 노선에 배정되어 있거나 진행 방향이 반대인 선로 구간은 사용할 수 없다.

### 2.2 노선의 정의와 개념

노선은 선로 자체와 구분되는 플레이어 설정 데이터다. 노선에는 방문 순서가 정해진 역 목록과 각 역 사이를 잇는 선로 구간 목록이 포함된다. 노선은 최소 2개의 서로 다른 역을 포함하며 마지막 역에서 첫 역으로 돌아오는 폐쇄 경로여야 한다.

기차역은 여러 선로 연결 포트를 가질 수 있다. 플레이어는 포트마다 진입 또는 진출 역할을 지정하고, 노선의 각 구간은 출발역의 진출 포트와 도착역의 진입 포트를 하나씩 지정한다. 한 역에 여러 진입·진출 포트가 있어도 기차는 자신이 배정된 노선 구간의 포트만 사용한다.

```text
A역 ──구간 1──▶ B역 ──구간 2──▶ C역 ──구간 3──▶ D역
 ▲                                                     │
 └────────────────────── 구간 4 ──────────────────────┘

노선 순서: A → B → C → D → A
```

- 플레이어는 이미 설치된 선로와 기차역을 이용해 역의 방문 순서와 각 구간의 진입·진출 포트를 지정하고 노선을 확정한다. 각 구간의 선로는 지정 포트와 방문 순서 방향으로 운행 가능한 단방향이어야 한다.
- 화물은 목적지 역을 개별 지정하지 않는다. 각 화물칸에 지정된 자원에 대해 역별 적재 목표량과 하역량을 설정하며, 기차는 방문 순서대로 이를 적용한다.
- 첫 역으로 되돌아오는 마지막 구간이 없거나, 어느 구간이든 선로가 끊겨 있으면 노선을 만들 수 없다.
- 노선의 방향은 플레이어가 지정한 역 순서로 고정한다. 반대 방향 운행은 반대 방향으로 설치·배정한 별도 선로 구간과 별도 노선으로 구성한다. 기존 선로를 반대 방향 노선과 공유할 수 없다.
- 동일 역을 한 노선의 중간 경유지로 중복 등록할 수 없다. 역 포트에서 여러 노선이 갈라지는 것은 허용하지만, 기차가 운행 중 진출 포트를 선택하는 동적 분기와 선로 중간의 분기·합류는 초기 구현에서 지원하지 않는다.
- 노선 생성 성공 시 기차 1대를 자동 생성·배정한다. 이후 추가 기차를 같은 노선에 배정하는 기능은 확장 범위다.

### 2.3 기차의 정의와 운행 조건

기차는 선로 위를 실제로 이동하며 화물을 운송하고 전투에 참여하는 개별 게임 객체다. 노선은 기차의 운행 경로를 정의하는 별도 데이터다. 기차가 존재하더라도 유효한 노선에 배정되지 않으면 이동하거나 운송하지 않는다.

- 유효한 폐쇄 순환 노선을 확정할 때 기본 기차 1대를 생성해 해당 노선에 배정한다.
- 노선이 없거나, 삭제됐거나, 선로 단절 등으로 유효하지 않으면 기차는 정지 상태이며 운행하지 않는다.
- 기차는 배정된 노선의 방향과 역 순서만 따라 이동한다. 노선 밖 선로로 임의 진입하거나 경로를 자동 탐색하지 않는다.
- 노선 운행 재개 조건을 충족하면 정지 중인 기차는 해당 노선에 따라 운행을 재개한다. 재개 시점과 중단 중 화물 처리는 후속 규칙을 따른다.

### 2.4 노선과 기차의 관계

| 항목 | 규칙 |
| --- | --- |
| 노선 | 순서가 있는 역 목록과 각 구간의 출발·도착 포트, 선로 경로를 가진 폐쇄 순환 운행 계획이다. |
| 기본 기차 | 노선 생성 시 1대를 자동 생성해 배정한다. |
| 추가 기차 | 같은 노선에 복수 기차를 배정하는 기능은 이후 확장으로 다룬다. |
| 역 정차 | 기차는 노선의 역을 지정 순서대로 방문한다. 역별 적재·하역 조건은 운송 설정에 따른다. |
| 운송 소유권 | 적재 시 해당 역 기지 재고에서 차감하고, 하역 시 해당 역 기지 재고에 더한다. 적재·하역은 역별 운송 설정과 화물칸 잔량에 따라 적용한다. |

### 2.5 설치부터 운행까지의 전체 흐름

1. 플레이어가 기차역을 설치하고, 선로 연결 포트와 포트의 진입·진출 역할을 정한다.
2. 플레이어가 각 구간의 출발역 진출 포트에서 다음 역 진입 포트까지 단방향 선로를 직접 설치한다. 마지막 구간도 첫 역의 지정 진입 포트까지 연결해 순환을 닫는다.
3. 노선 편집에서 첫 역과 나머지 역의 방문 순서, 각 구간에 사용할 진입·진출 포트 및 선로를 정한다.
4. 시스템이 모든 구간의 연결·방향과 순환 완결성을 확인한다. 유효하면 노선을 확정하고 기본 기차 1대를 자동 생성·배정한다.
5. 플레이어가 기본 기차의 화물칸에 운송 자원을 하나 지정하고, 각 역의 해당 화물칸 적재 목표량과 하역량을 설정한 뒤 운행에 필요한 석탄을 준비한다.
6. 생성된 기차는 정지 상태로 대기한다. 플레이어가 노선 UI에서 `운행 시작`을 누르면 노선의 첫 역부터 운행한다.
7. 기차는 순서대로 역을 방문해 각 역에서 10초 정차한다. 정차 중에는 역 설정의 하역량만큼 먼저 내리고, 남은 공간에 적재 목표량만큼 싣는다. 구간 이동에는 통과하는 선로 타일마다 1초가 걸린다.

유효한 노선이 없거나 노선 경로가 끊긴 상태에서는 기차가 운행하지 않는다. 노선 생성은 기차를 배정하지만 자동으로 운행을 시작하지 않는다.

## 3. 선로 직접 설치 요구사항

### 3.1 방벽과 동일한 설치 경험

선로는 방벽 설치와 동일하게 **건설 메뉴에서 선로를 선택한 뒤, 맵 타일을 클릭하거나 드래그하여 연속 배치**한다.

| ID | 요구사항 | 상세 / 검증 기준 | 우선순위 |
| --- | --- | --- | --- |
| RAIL-001 | 설치 모드 | 플레이어는 건설 메뉴에서 `선로`를 선택하여 설치 모드에 진입할 수 있어야 한다. | Must |
| RAIL-002 | 타일 직접 배치 | 클릭한 유효 타일에 선로 1칸을 설치할 수 있어야 한다. | Must |
| RAIL-003 | 드래그 연속 배치 | 방벽처럼 드래그한 경로의 유효 타일에 선로를 연속 설치할 수 있어야 한다. 드래그 경로의 모든 타일을 순서대로 검사한다. | Must |
| RAIL-004 | 설치 미리보기 | 설치 전 유효 타일은 설치 가능 상태와 비용을, 불가 타일은 불가 사유를 미리 보여야 한다. | Must |
| RAIL-005 | 자동 외형 연결 | 인접한 선로 타일의 방향에 따라 직선·모서리 외형을 자동으로 연결해 표시한다. 이는 외형 처리이며 경로를 자동 생성하는 기능이 아니다. | Must |
| RAIL-006 | 설치 가능 지형 | 선로는 평지에만 설치할 수 있다. 언덕·절벽·이동 불가 지형에는 설치할 수 없다. | Must |
| RAIL-007 | 점유 타일 차단 | 건물, 방벽, 기차역, 다른 설치물이 차지한 타일에는 선로를 설치할 수 없다. 설치 과정에서 기존 건물을 자동 철거하지 않는다. | Must |
| RAIL-008 | 선로 타일 보호 | 선로가 설치된 타일에는 방벽·건물 등 다른 설치물을 새로 배치할 수 없다. | Must |
| RAIL-009 | 설치 비용 | 선로 1칸마다 건설 비용을 즉시 차감한다. 비용 종류와 수치는 방벽의 건설 비용 처리 규칙을 따른다. 구체 수치는 결정 필요다. | Must |
| RAIL-010 | 설치 범위 | 선로의 설치 가능 범위, 회수·철거 방식, 비용 환급 규칙은 방벽의 규칙을 그대로 적용한다. | Must |
| RAIL-011 | 선로 공격·파괴 불가 | 선로는 적이 공격 대상으로 선택할 수 없으며, 피해를 받거나 파괴·손상되지 않는 오브젝트다. | Must |

### 3.2 선로의 통행 규칙

| ID | 요구사항 | 상세 / 검증 기준 | 우선순위 |
| --- | --- | --- | --- |
| RAIL-012 | 단방향 통행 | 선로 구간은 한 방향으로만 기차를 통과시킨다. 선로 방향은 해당 구간을 사용하는 노선 확정 시 지정된 역 방문 순서에 맞춰 기록한다. | Must |
| RAIL-013 | 노선 외 운행 금지 | 선로가 설치되어 있어도 유효한 노선에 포함되지 않은 구간에서는 기차가 운행하지 않는다. | Must |
| RAIL-014 | 역방향 별도 건설 | 반대 방향 운행은 기존 선로를 공유하지 않고 반대 방향의 별도 선로 구간과 노선을 사용한다. | Must |
| RAIL-015 | 경로 연속성 | 노선의 각 구간은 출발역의 지정 진출 포트에서 도착역의 지정 진입 포트까지 끊김 없이 이어져야 한다. | Must |

### 3.3 노선 구성 및 확정 절차

선로 건설과 노선 설정은 별도 단계다. 플레이어가 역 순서와 각 구간을 지정하고, 첫 역으로 되돌아오는 모든 구간이 유효할 때 노선을 확정한다.

```text
1. 기차역을 설치하고 역 사이 선로 구간을 직접 건설
2. 노선 편집에서 첫 역과 방문할 역 순서를 지정
3. 마지막 역에서 첫 역으로 돌아오는 구간을 지정
4. 시스템이 각 구간의 지정 진입·진출 포트와 선로 구간의 연속성 및 순환 완결성을 검사
5. 유효하면 노선 확정 및 기본 기차 1대 자동 생성·배정
6. 기차는 정지 상태로 대기하며, 플레이어가 노선 UI에서 `운행 시작`을 눌러야 운행한다
```

| ID | 요구사항 | 상세 / 검증 기준 | 우선순위 |
| --- | --- | --- | --- |
| RAIL-101 | 복수 연결 포트 | 기차역은 복수의 선로 연결 포트를 제공해야 한다. 포트 수와 정확한 타일 좌표는 `TRN-TBD-001`에서 확정한다. | Must |
| RAIL-102 | 포트 역할 지정 | 플레이어는 각 연결 포트를 진입 또는 진출로 지정할 수 있다. 진입·진출 방향은 서로 반대일 필요가 없으며, 동일 역에 여러 진출 포트를 둘 수 있다. | Must |
| RAIL-103 | 역 순서 편집 | 플레이어는 노선 편집에서 첫 역과 최소 1개의 다음 역을 지정하고 방문 순서를 구성할 수 있어야 한다. | Must |
| RAIL-104 | 구간 경로 검사 | 지정된 모든 연속 역 쌍에 대해 출발역의 지정 진출 포트에서 다음 역의 지정 진입 포트까지 끊기지 않고 지정 방향으로 통행 가능한 선로 경로가 있어야 한다. | Must |
| RAIL-105 | 폐쇄 경로 검사 | 마지막 역에서 첫 역의 진입 연결점으로 돌아오는 유효 선로 구간이 있을 때만 노선을 확정할 수 있다. | Must |
| RAIL-106 | 경로 실패 안내 | 선로 단절, 미연결·중복 사용 포트, 누락된 마지막 구간, 선로 중간 분기 등 실패 원인을 노선 편집 화면에 표시한다. | Must |
| RAIL-107 | 자동 건설 금지 | 노선 편집은 선로를 자동 설치·보정·우회 생성하지 않는다. 필요한 구간은 플레이어가 직접 건설한다. | Must |
| RAIL-108 | 노선 표시 | 확정된 노선의 이름, 역 방문 순서, 진행 방향, 구간별 연결 상태를 UI에 표시한다. | Must |
| RAIL-109 | 기차 자동 배정 | 유효한 노선 확정 시 기본 기차 1대를 생성해 노선에 배정한다. | Must |
| RAIL-110 | 연결 해제 | 노선의 역 또는 선로 구간이 회수·비활성화되어 순환 경로가 깨지면 노선 운행을 중지하고 상태를 표시한다. | Must |

| --- | --- | --- | --- |

## 4. 운송 및 자원 요구사항

### 4.1 적재·하역 규칙

| ID | 요구사항 | 상세 / 검증 기준 | 우선순위 |
| --- | --- | --- | --- |
| TRN-001 | 기지 재고 출입구 | 기차역은 독립 재고를 보유하지 않고 연결된 기지 재고의 출입구로 동작한다. 적재한 자원은 해당 기지 재고에서 즉시 차감하고 화물칸 재고로 이동하며, 하역한 자원은 해당 기지 재고에 즉시 더한다. 기지 재고를 공동 재고로 합치지 않는다. | Must |
| TRN-002 | 화물칸별 운송 자원 고정 | 각 화물칸에 운송할 일반 자원 하나를 지정한다. 지정 후에는 정지·운행 상태와 관계없이 해당 화물칸의 운송 자원을 변경하거나 다른 종류의 자원을 적재할 수 없다. | Must |
| TRN-003 | 화물칸별 역 적재·하역 설정 | 노선의 각 역은 각 화물칸에 지정된 자원에 대해 적재 목표량과 하역량을 독립적으로 설정할 수 있다. 둘 다 0이면 그 화물칸 기준으로 통과역처럼 동작한다. | Must |
| TRN-004 | 하역 후 적재 순서 | 기차가 역에 도착하면 해당 역의 하역 설정을 먼저 적용하고, 그 뒤 남은 화물칸 공간에서 적재 설정을 적용한다. | Must |
| TRN-005 | 실제 하역량 | 실제 하역량은 `min(역 하역 설정값, 기차 화물칸 현재량, 연결 기지 재고의 남은 공간)`이다. 기지 재고가 가득 차 하역하지 못한 화물은 화물칸에 남기고 다음 순환의 같은 역에서 다시 하역을 시도한다. | Must |
| TRN-006 | 실제 적재량 | 실제 적재량은 하역 후 남은 화물칸 공간, 역 적재 설정값, 적재 시점의 역 가용 재고 중 가장 낮은 양이다. 생산량 수치나 시간 단위로 적재 목표량을 별도 제한하지 않는다. | Must |
| TRN-007 | 순환 중 운송 | 기차는 노선의 모든 구간을 한 방향으로 순환한다. 하역하지 않은 화물은 다음 역으로 유지하며, 역별 설정에 따라 매 방문마다 증감한다. | Must |
| TRN-008 | 역방향 운송 | 반대 방향으로 자원을 운송하려면 반대 방향 선로와 별도 노선을 구성한다. 동일 선로를 역방향 노선과 공유하지 않는다. | Must |
| TRN-009 | 적재 목표량 검증 | 플레이어는 역별 적재 목표량을 0 이상 화물칸 최대량 이하로 지정할 수 있다. 목표량은 생산량과 비교하지 않으며, 실제 적재 때 역 가용 재고가 부족하면 가능한 양만 싣는다. | Must |
| TRN-010 | 역 발송·수신 역할 | 역을 출발 전용 또는 도착 전용으로 고정 분류하지 않는다. 각 역에서 발송과 수신을 독립적으로 설정할 수 있으며, 한 역이 두 역할을 모두 수행하거나 둘 다 설정하지 않고 통과역으로 동작할 수 있다. | Must |

### 4.2 운행 및 연료

| ID | 요구사항 | 상세 / 검증 기준 | 우선순위 |
| --- | --- | --- | --- |
| TRN-101 | 운행 단위 | 기차는 노선의 첫 역에서 출발해 등록된 역을 순서대로 방문하고, 한 바퀴를 돌아 첫 역으로 복귀한 뒤 다음 순회를 계속한다. | Must |
| TRN-102 | 운행 중지 | 노선 UI에서 `운행 중지`를 선택하면 `중지 요청` 상태가 된다. 기차는 현재 선로 구간을 끝내고 다음 역에 도착한 뒤 `정지` 상태가 된다. | Must |
| TRN-103 | 석탄 소모 | 운행 중에는 석탄을 소모해야 하며, 선로 길이가 길수록 요구량이 증가해야 한다. | Must |

| TRN-105 | 연료 부족 | 다음 선로 구간을 이동하는 데 필요한 석탄이 부족하면 해당 역에서 출발하지 않고 대기한다. 플레이어가 연료칸에 석탄을 보충한 뒤 운행을 재개한다. | Must |
| TRN-106 | 노선 중단 | 노선의 역 비활성화, 선로 단절, 기차 파괴 시 운행을 중지하고 기차 화물 상태를 보존 또는 처리한다. 세부 규칙은 결정 필요다. | Must |
| TRN-107 | 구간 이동 시간 | 기차의 구간 이동 시간은 해당 구간에서 통과하는 선로 타일 수 × 타일당 1초로 계산한다. 기차역 타일은 선로 타일 수에 포함하지 않는다. | Must |
| TRN-108 | 역 정차 시간 | 기차는 각 노선 역에서 기본 10초 정차한다. 이 정차 시간 안에 역별 설정에 따라 하역 후 적재를 적용한다. | Must |
| TRN-109 | 순환 시간 표시 | 노선 UI는 구간 이동 시간과 역 정차 시간을 합산한 예상 순환 시간을 표시한다. | Must |

### 4.3 화물 운송 설정

| 항목 | 1차 구현 기준 | 결정 필요 사항 |
| --- | --- | --- |
| 운송 품목 | 화물칸마다 자원 하나를 지정한다. 지정 후에는 변경할 수 없다. 노선은 특정 자원에 고정되지 않는다. | 없음 |
| 화물칸 | 초기 기본 기차는 용량 `1,000`의 화물칸 1개만 가지며, 그 화물칸은 한 종류의 자원만 보관한다. 이후 화물칸이 추가되면 칸마다 서로 다른 자원을 지정할 수 있다. | 자원별 적재 단위 |
| 역별 설정 | 각 역에서 화물칸별 자원의 적재 목표량과 하역량을 설정한다. 도착 시 모든 화물칸의 하역을 먼저 적용한 뒤 적재를 적용한다. 최소 보유량은 두지 않으며, 기차는 해당 기지의 가용 재고를 0까지 적재할 수 있다. | 없음 |
| 운행 조건 | 운행 시작 버튼을 누르면 화물이 없어도 순환 운행할 수 있다. 자원이 있을 때 설정량 범위에서 적재하며, 가용 재고가 부족하면 가능한 양만 적재한다. 석탄은 노선 역 수 × 50개(역당 임시 기준)를 최대량으로 하여 운행 전에 플레이어가 직접 적재하며, 운행 중 자동 보급하지 않는다. | 구간별 석탄 소모량 |
| 저장 한도 | 기차역은 별도 저장소를 갖지 않는다. 하역량은 기차 현재량과 연결 기지 재고의 남은 공간을 넘을 수 없으며, 기지 재고가 가득 차면 화물을 유지해 다음 순환에 다시 시도한다. | 기존 기지 재고 한도와 연동 |

## 5. 기차 운행·편성·전투 요구사항

### 5.1 운행 및 정지 상태

기차 상태는 다음처럼 구분한다.

| 상태 | 정의 | 다음 상태 |
| --- | --- | --- |
| 정지 | 아직 운행을 시작하지 않았거나, 중지 요청을 완료해 운행하지 않는 상태다. 자동 출발하지 않는다. | 플레이어가 운행 시작을 누르고 조건을 충족하면 `구간 이동 중` |
| 구간 이동 중 | 현재 역에서 노선상 다음 역으로 이동하는 상태다. | 다음 역 도착 시 `역 정차 중` |
| 역 정차 중 | 역 도착 후 기본 10초 동안 머물며 화물칸별 하역·적재를 처리한다. 중지 요청이 없으면 정차 종료 후 자동 출발한다. | 정차 종료 후 `구간 이동 중`; 다음 구간 연료가 모자라면 `연료 부족 대기`; 중지 요청이 있으면 `정지` |
| 중지 요청 | 운행 중지 입력 후 현재 선로 구간을 끝내고 다음 역에 도착하기 전까지의 상태다. | 다음 역 도착 시 `정지` |
| 연료 부족 대기 | 다음 구간 이동에 필요한 석탄이 부족해 역에서 출발하지 못하는 상태다. 플레이어가 석탄을 보충하고 운행을 재개해야 한다. | 재개 시 `구간 이동 중` |
| 노선 오류 정지 | 노선 또는 선로 경로가 무효여서 운행할 수 없는 상태다. 오류를 해결해도 자동 출발하지 않으며, 플레이어가 운행을 다시 시작해야 한다. | 유효성 복구 후 운행 시작 시 `구간 이동 중` |

| ID | 요구사항 | 상세 / 검증 기준 | 우선순위 |
| --- | --- | --- | --- |

### 7.1 핵심 구현 규칙

- 선로 설치는 방벽과 동일한 타일 배치 이벤트·비용 차감·드래그 연속 설치 규칙을 사용한다.
- 인접 선로의 자동 외형 연결은 설치 편의 기능일 뿐, 역 사이 구간이나 순환 노선을 자동 생성하지 않는다.
- 노선 구성은 선로 설치와 별도이며, 플레이어가 역 방문 순서를 지정한다. 시스템은 지정된 모든 구간과 마지막 역에서 첫 역으로 돌아오는 구간이 유효한지 검사한다.
- 폐쇄 순환 노선 확정 시 기본 기차 1대를 자동 생성해 배정한다. 추가 기차 배정과 복수 기차 충돌 제어는 초기 구현 범위에서 제외한다.
- 노선 생성만으로 기차가 자동 출발하지 않는다. 기차는 정지 상태로 생성되며, 플레이어가 운행 시작 버튼을 눌러야 움직인다.
- 기차는 빈 상태로 원점에 귀환하는 왕복 모델을 사용하지 않는다. 노선의 지정 방향으로 모든 역을 순환한다.
- 노선은 운송 자원에 고정되지 않는다. 화물칸마다 운송 자원을 하나 고정하며, 각 역에서는 화물칸별 설정한 하역량만큼 먼저 하역하고 화물칸 여유와 역 재고가 허용하는 만큼 적재 목표량을 적재한다.
- 역 포트의 역할과 방향은 플레이어가 지정한다. 기차는 노선 구간에 기록된 진입·진출 포트만 사용하며, 선로 타일은 노선이 지정한 방향으로만 통행할 수 있다. 역방향 운행은 별도 선로를 요구한다.
- 적은 선로를 공격·파괴할 수 없으며, 기차를 공격 대상으로 지정하거나 기차의 어그로에 반응하지 않는다.
- 구간 이동 시간은 선로 타일당 1초, 역 정차 시간은 역마다 10초로 계산한다.
- 운송 중 파괴·중지된 화물 처리 규칙이 확정되기 전까지는 화물 상태를 저장 데이터로 보존할 수 있어야 한다.

## 10. 변경 이력

| 일자         | 변경 내용                                                                                                          |
| ---------- | -------------------------------------------------------------------------------------------------------------- |
| 2026-09-23 | 자동 최단 경로·양방향 공동 재고 방식을 제거했다. 선로를 방벽처럼 플레이어가 직접 설치하도록 변경하고, 출발역 적재 → 도착역 하역의 단방향 자원 운송과 A→B→C→A 순환 노선 규칙을 반영했다. |
| 2026-09-24 | 선로와 노선의 개념을 분리했다. 노선은 플레이어가 역 순서와 선로 구간을 지정해 만드는 폐쇄 순환 경로로 정의하고, 노선 생성 시 기본 기차 1대를 자동 배정하도록 변경했다. 추가 기차 배정은 확장 기능으로 분류했다. |
| 2026-09-24 | 화물은 지정 목적지 역에서만 하역하도록 했다. 역 설치 시 방향을 지정해 출구 방향을 정하고, 선로는 단방향으로 정의했다. 역방향 운송은 별도 선로와 노선을 사용한다. 역 정차 시간은 10초, 선로 타일 이동 시간은 타일당 1초로 추가했다. |
| 2026-09-24 | 선로 통행 규칙과 기차 운행 규칙을 별도 절로 정리했다. 유효한 노선이 없거나 무효하면 기차가 정지하며, 유효 경로가 복구된 뒤에만 운행을 재개하도록 했다. |
| 2026-09-26 | 초기 기차의 화물칸을 1개로 제한하고, 화물칸마다 운송 자원 하나를 고정하도록 변경했다. 목적지별 화물 대신 화물칸별 역 적재 목표량·하역량을 사용하며, 매 정차 시 하역 후 적재를 적용하도록 정리했다. |
| 2026-09-26 | 초기 화물칸 최대량을 1,000으로 확정했다. 적재 목표량은 생산량 기준시간과 비교하지 않고 정차 시점의 역 가용 재고·화물칸 여유량으로만 제한하며, 운행 중에는 운송 설정을 수정할 수 없도록 했다. |
| 2026-09-26 | 기차역을 독립 저장소가 아닌 연결 기지 재고의 출입구로 정의했다. 기지 재고가 가득 차 하역하지 못한 화물은 기차에 유지하고, 다음 순환의 같은 역에서 다시 하역을 시도한다. |
| 2026-09-26 | 기지 재고의 최소 보유량은 두지 않기로 했다. 기차는 역별 적재 목표량과 화물칸 여유량이 허용하면 해당 기지의 가용 재고를 모두 적재할 수 있다. |
| 2026-09-26 | 노선은 운송 자원에 고정하지 않고, 화물칸마다 운송 자원을 지정하도록 구조를 수정했다. 초기 기차는 화물칸이 1개라 한 자원만 운송하지만, 이후 화물칸을 추가하면 한 노선에서 여러 자원을 함께 운송할 수 있다. 화물칸에 지정한 자원은 이후 변경할 수 없다. |
