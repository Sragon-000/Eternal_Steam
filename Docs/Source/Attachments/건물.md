

### 건물 정의
- 건물은 해당 게임에서 설치 가능한 모든 오브젝트를 "건물"로 분류 한다. 

1) **방어 건물:** 적을 직접 공격하거나 적의 이동·행동을 방해해 넥서스 방어에 기여하는 건물
   - 예시: 포탑, 감속 장치, 범위 공격 타워, 방벽
2) **자원 건물:** 건설과 운영에 필요한 자원을 생산·저장·변환하는 건물
   - 예시: 자원 채굴기, 발전기, 자원 저장소, 정제 시설
3) **설치 건물:** 직접 공격하거나 자원을 생산하지 않지만, 전장의 공간·배치 조건·이동 경로에 영향을 주는 건물
   - 예시: 벽, 관문, 장애물, 통로 변경 장치, 타워 설치대
4) **기타 건물:** 위 세 분류에 속하지 않으며, 기지의 핵심 목표·진행·편의 기능을 담당하는 건물
   - 예시: 넥서스, 건설 관리소, 연구소, 장식물

### 건물 기본 정보

각 건물은 아래 정보를 가진다.

- **건물 종류:** 방어 건물, 자원 건물, 설치 건물, 기타 건물 중 하나로 구분한다.
- **점유 격자 크기:** 건물이 점유하는 격자의 범위를 가진다.
- **설치 가능 여부:** 현재 위치에 설치할 수 있는지 확인한다.
- **회수 가능 여부:** 회수 모드에서 선택할 수 있는지 결정한다.

## 건물 배치 및 회수 규칙

### 기본 배치 규칙

[[기본 시스템]]

- 타워는 하나 이상의 격자를 점유한다.
- 설치 가능 격자와 설치 불가 격자를 구분한다.
- 타워를 설치하려는 위치가 유효하면 배치 가능 상태로 표시한다.
- 이미 점유된 위치 또는 설치 불가 영역에는 배치할 수 없다.

![격자 기반 배치 예시](assets/배치-격자-예시.svg)

### 임시 배치 및 설치 확정

1. 건물 배치 모드에 진입하면 설치 가능한 격자를 표시한다.
2. 설치 가능한 격자를 클릭하면 해당 위치에 건물을 반투명한 임시 상태로 표시한다.
3. 임시 상태의 건물은 실제 건설된 건물로 처리하지 않으며, 전장과 자원에 반영하지 않는다.
4. 설치 확정 전에는 다른 건물도 계속 임시로 배치할 수 있다.
5. 설치 확정 버튼을 누르면 임시 배치된 건물들을 실제 건물로 반영한다.
6. 취소 또는 회수 기능을 사용하면 임시 배치된 건물들을 모두 제거하고 배치 전 상태로 되돌린다.

### 임시 배치 격자 점유 및 충돌 규칙

1. 건물 배치를 시작하면 건물이 차지할 격자 목록을 계산한다.
2. 계산된 모든 격자가 설치 가능 상태인지 확인한다.
3. 모든 격자가 유효하면 해당 격자를 임시 점유 상태로 예약한다.
4. 임시 점유된 격자는 다른 건물의 배치 검사에서 설치 불가로 처리한다.
5. 임시 배치 건물을 이동하거나 선택 해제하면 이전에 예약한 격자를 해제한다.
6. 설치를 취소하면 모든 임시 점유 예약을 해제한다.
7. 설치를 확정하면 임시 점유 상태를 실제 점유 상태로 변경한다.
8. 설치 확정 직전에 격자 상태를 다시 검사해 충돌이 있으면 확정을 차단한다.

### 설치 확정 결과

- 임시 배치된 모든 건물은 확정 직전에 설치 가능 여부를 다시 검사한다.
- 하나라도 설치 불가 상태이면 전체 설치를 확정하지 않는다.
- 설치 불가한 건물은 빨간색으로 표시한다.
- 설치 가능한 임시 건물과 설치 불가한 임시 건물은 모두 임시 상태로 유지한다.
- 플레이어가 설치 불가한 건물을 이동하거나 해제한 후 다시 확정할 수 있다.

### 임시 회수 및 회수 확정

1. 회수 모드에 진입하면 회수 가능한 건물을 구분해 표시한다.
2. 회수할 건물을 클릭하면 해당 건물을 회수 예정인 반투명한 임시 상태로 표시한다.
3. 회수 확정 전에는 여러 건물을 계속 선택하거나 선택을 취소할 수 있다.
4. 임시 회수 상태의 건물은 회수 확정 전까지 실제 건물 상태와 기능을 유지한다.
5. 확정 회수 버튼을 누르면 임시 선택된 건물들을 실제로 회수한다.
6. 취소 버튼을 누르면 임시 회수 상태를 모두 해제하고 기존 배치 상태로 되돌린다.

### 회수 제한

- 회수 가능 여부가 활성화된 건물만 회수 모드에서 선택할 수 있다.
- 회수할 수 없는 건물은 선택 대상에 포함하지 않는다.
- 회수할 수 없는 건물은 일반 상태로 표시한다.

## 건물 배치 및 회수 UI

### 버튼 종류 및 개수

전체 버튼 종류는 4개로 구성한다.

- **설치:** 건물 임시 배치 모드로 전환한다.
- **회수:** 건물 임시 회수 모드로 전환한다.
- **확정:** 현재 모드의 임시 작업을 실제 상태로 반영한다.
- **취소:** 현재 모드의 임시 작업을 해제하고 일반 상태로 돌아간다.

### 모드별 버튼 사용 개수

- **일반 상태:** 설치, 회수 — 2개
- **설치 모드:** 확정, 취소 — 2개
- **회수 모드:** 확정, 취소 — 2개

‘확정’ 버튼은 설치 모드에서는 임시 배치를 확정하고, 회수 모드에서는 임시 회수를 확정한다. ‘취소’ 버튼도 현재 모드의 임시 작업을 취소하는 공용 버튼으로 사용한다.

### 버튼 활성화 규칙

- 임시 배치 또는 임시 회수 대상이 하나 이상 있을 때만 `확정` 버튼을 활성화한다.
- 임시 작업이 없으면 `확정` 버튼은 비활성화한다.
- 설치 모드와 회수 모드에서는 `확정`, `취소` 버튼만 표시한다.
- 일반 상태에서는 `설치`, `회수` 버튼만 표시한다.

## 건물 상태 표시 규칙

- **설치 가능 격자:** 초록색으로 표시한다.
- **설치 불가 격자:** 빨간색으로 표시한다.
- **임시 배치 건물:** 반투명하게 표시하고 파란색 또는 흰색 외곽선을 사용한다.
- **설치 완료 건물:** 투명 효과 없이 기본 그래픽으로 표시한다.
- **임시 회수 건물:** 반투명하게 표시하고 주황색 외곽선 또는 점선을 사용한다.
- **회수 완료 건물:** 건물과 점유 격자를 제거한다.

색상과 함께 투명도 및 외곽선을 사용해 상태를 구분한다.
