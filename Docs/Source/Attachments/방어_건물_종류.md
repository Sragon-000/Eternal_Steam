### 강화 규칙

**성능 10% 향상**은 공격력 하나만 의미하지 않고 해당 방어 건물이 가지고 있는 **모든 성능 관련 수치**를 기준으로 합니다.

예를 들어 기본 성능이 `피해량 100 / 사거리 30m / 폭발 반경 10m / 지속시간 2초`라면 강화 1레벨 상승 시 각각 **+10%**가 적용됩니다.

반대로 **시간이 짧아질수록 성능이 좋아지는 수치**는 감소합니다. `공격 주기`, `재사용 대기시간`, `충전시간` 등이 여기에 해당하며 강화 1레벨당 **10% 감소**합니다.

따라서 기본 공격 주기가 10초라면 다음 강화 단계에서는 **9초**가 되는 방식입니다.

다만 `관통 적 3명`, `미사일 3발`, `연쇄 4회`처럼 **정수 단위만 사용할 수 있는 수치**는 10%를 내부적으로 누적하고, 증가량이 1에 도달했을 때 실제 수치를 +1시키는 방식이 적합합니다. 예를 들어 최대 대상 3명에 +30%가 누적되면 약 3.9명이므로 **4명으로 증가**시키는 식입니다.

그리고 공격 각도는 현재 **회전형 포탑은 대부분 360°**, 긴 포신으로 방향성이 강한 **레일건 계열만 180°**로 우선 설정했습니다. 이 각도를 제한하면 배치 방향 자체가 전략 요소가 될 수 있습니다.




### 상태 이상 종류


| 효과/상태 이상    | 설명                                                                                   |
| ----------- | ------------------------------------------------------------------------------------ |
| **폭발**      | 공격이 명중한 지점을 중심으로 지정된 반지름 내 모든 적에게 피해를 준다.                                            |
| **연쇄**      | 최초 공격 대상 주변(대상 기준 반지름 5m 범위)의 적들을 대상으로 공격이 5초간 전이 한다. (중복 전이 가능하다.)                  |
| **관통**      | 탄환이 최초 대상에게 명중한 후 사라지지 않고 진행 방향에 있는 추가 적을 공격한다. 공격 사거리를 벗어나는 경우에 탄환이 사라진다.           |
| **과열**      | 3초 동안 이동 속도를 **20% 감소**시키며, 플라즈마 레이저로부터 받는 피해가 **20% 증가**한다.                         |
| **충격파**     | 충격파에 적중한 적을 **2초 동안 '행동불가' 상태**로 만든다.                                                |
| **행동불가**    | 지속시간 동안 이동과 공격 및 특수 행동을 할 수 없다. 지속시간 종료 후 즉시 정상 행동을 재개한다.                            |
| **플라즈마 폭발** | 폭발 범위 내 모든 공중 적에게 피해를 주고 **화상** 상태를 부여한다.                                            |
| **화상**      | 3초 동안 1초 간격으로 지속 피해를 받는다.                                                            |
| **둔화**      | 일정 시간 동안 이동 속도가 30% 감소                                                               |
| **전이**      | 전이는 가장 가까운 적을 대상으로 최초 공격 피해량의 80% 감소된 피해를 준다. 대상에서 대상으로 전이 할 때 마다 80% 만큼 감소한 피해를 준다. |
