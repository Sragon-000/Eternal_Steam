# 노선표 · 노선 구성 UI 설계

> 문서 목적: 플레이어가 설치한 기차역과 단방향 선로를 노선표 UI에서 순서대로 연결해 폐쇄 순환 노선을 구성하고, 유효성 검증·확정하는 화면 흐름과 입력 이벤트를 정의한다.  
> 문서 범위: 노선표 화면, 버튼·컨트롤, 이벤트, 상태 전이, 화면 이미지 구성 초안. 선로 타일의 설치 조작과 화물 인계량 계산은 이 문서에서 정의하지 않는다.  
> 문서 상태: UI 설계 초안. 확정된 규칙과 추가 결정이 필요한 항목을 구분한다.

---

## 1. 설계 원칙

- 선로는 맵에 설치하는 단방향 물리 경로다. 노선표는 설치된 선로를 선택된 역 순서에 따라 논리적인 운행 노선으로 등록한다.
- 노선은 첫 역에서 시작해 등록된 역을 순서대로 방문하고, 마지막 역에서 첫 역으로 돌아오는 폐쇄 순환 구조다.
- 노선표는 역을 `출발역 전용` 또는 `도착역 전용`으로 분류하지 않는다. 모든 역은 발송과 수신을 각각 설정할 수 있으며, 한 역에서 둘 다 설정할 수도 있다. 아무 설정도 없는 역은 운행상 통과 역이다.
- 노선에는 최소 2개의 서로 다른 역이 필요하다. 역 개수에 임의의 고정 상한을 두지 않는다. 사용 가능한 역과 실제 맵 크기, 유효한 선로 경로가 구성 범위를 제한한다.
- 기차역은 복수의 선로 연결 포트를 가진다. 플레이어는 각 포트를 진입 또는 진출로 지정하며, 노선 순서상 각 구간은 출발역의 지정 진출 포트와 다음 역의 지정 진입 포트를 사용한다.
- 선로는 한 방향으로만 통행한다. 반대 방향 순환을 구성할 때는 반대 방향의 별도 선로를 사용하며 선로 구간을 공유하지 않는다.
- 역의 복수 포트로 여러 노선이 연결되는 것은 허용한다. 기차가 운행 중 진출 포트를 선택하는 동적 분기, 선로 중간의 분기·합류·교차, 복수 노선의 선로 공유는 초기 범위에서 지원하지 않는다. 구간의 통행 경로와 사용할 포트 쌍을 하나로 특정할 수 없으면 노선 검증에 실패한다.
- 노선 확정 시 기본 기차 1대가 자동 생성·배정되지만, 기차는 정지 상태로 대기한다. 플레이어가 운행 시작을 눌러야 운행한다.
- 운행 중 노선의 역 순서·구간·포트 수정은 임시 편집본으로 저장하고, 기차가 현재 노선의 한 바퀴를 마쳐 출발 역으로 돌아온 뒤 재검증하여 적용한다. 적용 전까지는 기존 노선으로 운행한다. 미적용 편집은 취소할 수 있다.
- 운행 중 예약 수정에서는 현재 출발역을 첫 역으로 유지한다. 나머지 역의 순서 변경·추가·제거는 허용한다.
- 운행 중인 기차가 사용하는 선로는 수정하거나 철거할 수 없다. 선로 변경은 기차를 정지시킨 뒤 가능하다.
- 기차 상태는 `정지`, `구간 이동 중`, `역 정차 중`, `중지 요청`, `연료 부족 대기`, `노선 오류 정지`로 구분한다. `역 정차 중`은 역에서 10초간 화물을 처리한 뒤 자동 출발하는 상태이며, `정지`는 플레이어가 다시 운행을 시작하기 전까지 출발하지 않는 상태다.
- 노선 관련 UI 진입 경로는 전역 노선 관리와 역별 노선 문맥 보기로 분리한다. 전역 UI는 모든 노선을 관리하고, 역 문맥 UI는 선택 역이 포함된 노선만 보여주고 편집한다.
- 역은 설치 시 소속 기지 이름과 해당 기지에서의 설치 순번을 조합한 기본 이름을 가진다. 예: `주기지 기차역 1`, `제1 서브기지 기차역 1`. 순번은 기지별로 관리하며, 역을 철거해도 다른 역 이름을 다시 매기지 않는다.
- 세부 화물 전달량·분배 계산은 UI 흐름 이후 별도 논의 대상으로 둔다. 노선표는 역별 발송·수신 설정에 진입할 수 있는 자리를 제공한다.

## 2. 화면 흐름

```text
기본 맵
  ├─ 전역 노선 메뉴 → 전체 노선 목록
  │   ├─ 새 노선 → 편집 → 첫 역·방문 역 추가·순서 편집
  │   │                         → 마지막 역에서 첫 역으로 순환 연결
  │   │                         → 검증 → 확인 → 확정 → 상세(기차 정지)
  │   └─ 노선 선택 → 별도 노선 상세 → 편집 / 운행 시작·중지
  └─ 기차역 선택 → 해당 역 소속 노선만 표시
                       └─ 노선 상세 / 수정
```

각 단계는 가능하면 노선 편집 화면 안의 상태로 처리한다. 경로가 유효하지 않을 때 별도 오류 화면으로 이동시키지 않고, 편집 화면에 해당 역·구간과 오류 사유를 표시한다.

| 상태 ID | 화면 상태 | 진입 조건 | 플레이어 목표 | 완료 조건 |
| --- | --- | --- | --- | --- |
| ROUTE-UI-00 | 전체 노선 관리 목록 | 기본 맵의 노선 메뉴 선택 | 모든 노선 확인·관리 또는 새 노선 작성 | 새 노선 생성 또는 대상 노선 열기 |
| ROUTE-UI-00A | 역별 노선 정보 | 맵에서 기차역 선택 후 노선 정보 열기 | 선택 역이 포함된 노선과 그 상태 확인·수정 | 대상 노선 선택 또는 새 노선 편집 진입 |
| ROUTE-UI-01 | 첫 역 지정 | 새 노선 초안 생성 | 순환 노선의 기준이 될 첫 역 지정 | 유효한 역 선택 |
| ROUTE-UI-02 | 방문 역 편집 | 첫 역 지정 완료 | 다음 방문 역들을 순서대로 등록 | 최소 2개 역 및 필요한 구간 지정 |
| ROUTE-UI-03 | 순환 연결 | 방문 순서 입력 중 또는 완료 후 | 마지막 역에서 첫 역으로 돌아가는 구간 등록 | 폐쇄 경로 연결 |
| ROUTE-UI-04 | 경로 검증 결과 | 플레이어가 검증 실행 | 오류를 확인하고 수정하거나 다음 단계 진행 | 모든 검증 항목 통과 |
| ROUTE-UI-05 | 노선 확인 | 경로 검증 통과 | 요약과 운행 방향 확인 | 노선 확정 또는 편집 복귀 |
| ROUTE-UI-06 | 확정 완료·기차 대기 | 노선 확정 성공 | 생성된 노선·기차 상태 확인 | 운송 설정 또는 운행 시작으로 이동 |

## 3. 노선 관리·편집 화면 구성

### 3.1 노선 관리 목록

**화면 목적**: 전역 노선 메뉴에서 맵의 모든 노선을 확인하고 새 노선을 시작하거나 기존 노선을 관리한다. 역을 눌러 진입한 경우에는 이 전체 목록이 아니라 해당 역 문맥 화면을 연다.

**표시 요소**

- 노선 이름 또는 기본 생성 이름
- 기지 이름과 기지별 순번을 포함한 역 이름, 등록 역 순서와 역 개수
- 순환 완결·오류 상태
- 배정 기차 유무와 정지·운행 상태
- 노선별 `열기`, `수정` 및 `새 노선` 기능
- 전체 목록에서만 노선 간 비교·탐색이 가능하며, 선택 역 진입에서는 그 역을 포함하는 노선만 노출

**버튼과 이벤트**

| 버튼/입력 | 활성 조건 | 이벤트 | 처리 및 다음 상태 |
| --- | --- | --- | --- |
| 전역 `노선` 메뉴 | 항상 | `OpenGlobalRouteBoard` | 모든 노선을 표시하는 전체 노선 관리 목록을 연다. |
| `+ 새 노선` | 노선 구성에 사용할 수 있는 역이 2개 이상일 때 | `CreateRouteDraft` | 임시 노선 데이터를 만들고 첫 역 지정 상태로 이동한다. |
| 노선 행 선택 / `열기` | 노선이 목록에 있을 때 | `OpenRoute(routeId)` | 선택 노선의 대시보드 또는 편집 상태를 연다. |
| `닫기` | 항상 | `CloseRouteBoard` | 기본 맵으로 돌아간다. |

**전체 노선 목록 화면 요소**

| 화면 영역 | 표시 내용·행동 |
| --- | --- |
| 상단 제목 | `전체 노선`, 등록 노선 수, `+ 새 노선` 버튼 |
| 목록 행 | 노선 이름, 등록 역 수·순서 요약, 경로 유효성, 배정 기차 상태, 예상 순환 시간 |
| 역 표기 | 기지명과 기지별 번호가 포함된 자동 역 이름을 사용해 동명 역을 구분 |
| 행 선택 | 목록 안에 상세 패널을 띄우지 않고 별도 노선 상세 화면으로 이동 |
| 빈 목록 | 등록 노선이 없음을 설명하고 `새 노선 구성` 진입 제공 |
| 오류 노선 | 목록에서 오류 상태와 시작 불가 상태를 텍스트로 표시. 선택 시 상세에서 오류 구간과 이유를 확인 |

전역 목록은 모든 노선을 찾고 진입하는 화면이다. 지도상의 특정 역을 선택해 들어온 경우는 전체 목록을 보여주지 않고 `3.1.2 역 선택 문맥의 노선 정보`를 사용한다. 이 두 진입 화면은 선택 노선 상세 및 노선 편집 화면을 공통으로 사용한다.

### 3.1.1 전체 관리 화면의 버튼별 상호작용과 다음 상태

| 현재 상태 | 버튼/입력 | 이벤트 및 시스템 처리 | 화면 변화·다음 상태 | 실패·비활성 처리 |
| --- | --- | --- | --- | --- |
| 기본 맵 | 전역 `노선` 메뉴 | `OpenGlobalRouteBoard`; 저장된 전체 노선을 불러온다. | 전체 노선 목록 | 불러오기 실패 시 오류 안내 후 맵 상태 유지 |
| 전체 노선 목록 | `+ 새 노선` | `CreateRouteDraft`; 임시 편집 데이터를 만든다. | 새 노선 편집 화면 | 사용할 역이 2개 미만이면 비활성화하고 필요 조건 안내 |
| 전체 노선 목록 | 노선 행 선택 / `열기` | `OpenRoute(routeId)`; 선택 노선의 데이터·상태를 불러온다. | 별도 노선 상세 화면 | 대상 노선이 삭제·무효화됐으면 최신 목록으로 갱신하고 안내 |
| 전체 노선 목록 | `맵으로` / `닫기` | `CloseRouteBoard`; 목록만 닫는다. | 기본 맵 | 편집 중인 미저장 데이터가 있으면 편집 취소 확인을 거친다. |
| 노선 상세 | `전체 노선` / `목록으로` | `ReturnToGlobalRouteBoard`; 목록 위치와 선택 노선을 유지한다. | 전체 노선 목록 | 없음 |
| 노선 상세 | `노선 편집` | `EditRoute(routeId)`; 기존 방문 순서와 구간을 임시 편집 데이터로 복사한다. | 기존 노선 편집 화면 | 운행 중이면 적용 시점이 한 바퀴 완료 후임을 표시한다. |
| 유효·정지 상태의 노선 상세 | `운행 시작` | `RequestTrainStart`; 최신 유효성 및 배정 기차 상태를 확인한다. | 노선 상세에서 기차 상태가 `구간 이동 중`으로 변경 | 노선이 무효하거나 기차가 없으면 시작하지 않고 원인 표시 |
| 운행 중인 노선 상세 | `운행 중지` | `RequestTrainStop`; 현재 구간을 끝내고 다음 역에서 정지하도록 요청한다. | 도착 전에는 `중지 요청`, 다음 역 도착 후에는 `정지` 표시 | 중지 요청 중 목적 역을 함께 표시 |
| 새 노선 편집 | `경로 검증` | `ValidateRouteDraft`; 역 개수, 중복, 구간 방향·연결, 순환 완결 여부를 검사한다. | 통과하면 노선 확인 상태, 실패하면 편집 화면에 오류 강조 | 실패 역·구간과 수정 방법을 함께 표시하고 노선은 생성하지 않음 |
| 새 노선 확인 | `노선 확정` | `CommitRoute`; 최신 경로를 재검증한 뒤 노선 저장과 기본 기차 1대 생성을 한 번 처리한다. | 노선 상세, 기차는 `정지` 상태 | 재검증 실패 시 편집 화면으로 돌아가 최신 오류 표시; 중복 입력으로 기차 중복 생성 금지 |
| 기존 노선 편집 | `변경 저장` | `UpdateRoute`; 임시 변경을 검증한다. 기차가 정지 상태면 즉시 저장하고, 운행 중이면 현재 출발역을 첫 역으로 유지한 변경을 한 바퀴 완료 후 적용할 예약 수정으로 저장한다. | 정지 기차면 해당 노선 상세, 운행 중이면 예약 변경 상태의 노선 상세 | 검증 실패 또는 운행 중 출발역 변경 시 편집 상태 유지, 이전 저장 데이터 보존 |
| 예약 노선 편집 | `예약 변경 취소` | `CancelPendingRouteUpdate`; 아직 적용되지 않은 편집본을 폐기한다. | 기존 노선 상세, 기존 노선 운행 유지 | 이미 적용된 수정은 취소할 수 없고 일반 노선 편집으로 처리 |
| 편집 화면 | `취소` | `CancelRouteDraft` 또는 `DiscardRouteChanges`; 임시 변경을 버린다. | 새 노선이면 전체 목록, 기존 노선이면 기존 상세 | 미저장 변경이 있으면 폐기 확인 전까지 유지 |
| 노선 상세 | 역 이름 선택 | `OpenStationRouteContext(stationId)`; 해당 역이 포함된 노선 문맥을 연다. | 역 정보 패널의 해당 노선 요약으로 이동 | 전체 노선 목록으로 확장하지 않음 |

**상태별 화면 차이**

| 경우 | 전체 목록 표시 | 상세 화면 표시 | 주 행동 |
| --- | --- | --- | --- |
| 등록된 노선 없음 | 빈 상태 안내, 노선 수 0 | 해당 없음 | `새 노선 구성` |
| 여러 노선 중 미선택 | 모든 노선 행과 각 상태 요약 | 해당 없음 | 새 노선 또는 행 선택 |
| 유효한 노선 선택 | 선택 시 목록 화면을 벗어남 | 순환 순서·구간 요약·기차 상태·예상 시간·화물 요약 | 편집, 운행 시작/중지, 목록 복귀 |
| 무효 노선 선택 | 목록 행에 오류 상태를 텍스트로 표시 | 오류 원인·문제 구간, 운행 시작 불가 상태 | 노선 편집 |
| 운행 중인 노선 선택 | 목록 행에 현재 기차 상태와 예약 노선 변경 여부 표시 | 현재 상태와 운행 제어 표시 | 운행 중지, 노선 편집 또는 예약 변경 취소 |
| 새 노선 작성 중 | 목록 대신 임시 편집 화면 | 역 순서와 경로 검증 결과 | 역 추가, 검증, 확정 또는 취소 |

### 3.1.2 역 선택 문맥의 노선 정보

**화면 목적**: 플레이어가 맵에서 기차역을 선택했을 때 그 역을 포함하는 노선의 정보와 해당 노선 편집 진입을 제공한다. 전체 노선 관리 화면의 축소 복제본이 아니라, 선택 역에 문맥이 고정된 상세 화면이다.

기차 상태 표기는 `정지`, `구간 이동 중`, `역 정차 중`, `중지 요청`, `연료 부족 대기`, `노선 오류 정지`를 사용한다. `역 정차 중`은 10초간 화물을 처리한 뒤 자동 출발하며, `정지`는 플레이어의 재시작 입력까지 운행하지 않는다. 운행 중지 요청은 현재 구간 완료 후 다음 역에 도착하기 전까지 `중지 요청`으로 표시한다.

**표시 요소**

- 선택한 역의 이름과 설치·연결 상태
- 이 역이 포함된 각 노선의 이름, 방문 순서상 위치, 이전 역과 다음 역
- 해당 노선의 유효성, 기차 정지·운행 상태 및 예상 순환 시간
- 이 역에서의 발송·수신 설정 진입점
- 선택 역이 어떤 노선에도 속하지 않는 경우의 빈 상태와 `새 노선에 추가` 진입점

| 버튼/입력 | 활성 조건 | 이벤트 | 처리 및 다음 상태 |
| --- | --- | --- | --- |
| 역 정보의 `노선` 탭 | 역 선택 패널이 열려 있을 때 | `OpenStationRouteContext(stationId)` | 선택 역을 포함하는 노선만 목록으로 표시한다. |
| 노선 항목 선택 | 해당 역을 포함한 노선이 있을 때 | `SelectStationRoute(routeId, stationId)` | 해당 노선 요약과 선택 역의 순서·이전/다음 연결 정보를 표시한다. |
| `이 노선 수정` | 선택한 노선이 수정 가능한 상태일 때 | `EditRouteFromStation(routeId, stationId)` | 노선 편집 화면을 열고 선택 역을 강조하되 기존 방문 순서를 유지한다. |
| `새 노선에 추가` | 선택 역이 설치되어 있고 새 노선 편집이 가능한 때 | `CreateRouteDraftFromStation(stationId)` | 새 노선 초안을 만들고 선택 역을 첫 역 또는 추가 역으로 등록할지 편집 흐름에서 지정한다. |
| `닫기` / 뒤로 | 항상 | `CloseStationRouteContext` | 역 정보 패널 또는 맵으로 돌아간다. |

선택 역에 연결된 노선이 여러 개라면 모두 표시하고, 각각 독립적으로 선택·편집한다. 한 노선에서 역이 차지하는 순서나 구간을 바꾸는 작업은 그 노선만 대상으로 한다. 전체 노선 비교·정리 작업은 전역 노선 관리 메뉴에서 수행한다.

새 노선 버튼의 사용 가능 조건은 선로 설치 완료를 미리 강제하지 않는다. 역을 선택한 뒤 경로가 없으면 구간 편집·검증 과정에서 원인을 표시한다.

### 3.2 노선 편집 화면

**화면 목적**: 첫 역, 방문 순서, 구간 방향을 정하고 기존 선로만으로 순환이 가능한지 확인한다.

**화면 영역**

| 영역 | 표시·조작 내용 |
| --- | --- |
| 중앙 맵 | 설치된 역, 연결 포트, 선로 방향, 편집 중인 경로, 순서 번호, 경로 오류 강조 |
| 역 순서 패널 | 첫 역과 경유 역의 순서 목록, 선택 상태, 각 역에서 사용하는 진입·진출 포트 |
| 구간 정보 패널 | 선택 구간의 시작 역·진출 포트·도착 역·진입 포트, 선로 연결 상태, 선로 타일 수, 이동 방향 |
| 하단 동작 영역 | `역 추가`, `순환 연결`, `경로 검증`, `노선 확정`, `취소` 등 현재 상태에 맞는 행동 |
| 피드백 영역 | 최근 검증 결과, 현재 선택 역·구간의 오류, 확정 불가 사유 |

**주요 버튼과 이벤트**

| 버튼/입력 | 활성 조건 | 이벤트 | 처리 및 다음 상태 |
| --- | --- | --- | --- |
| `첫 역 지정` | 편집 목록에 첫 역이 없을 때 | `SetRouteStart(stationId)` | 유효한 역을 첫 역으로 등록하고 첫 역 지정 상태를 완료한다. |
| `+ 역 추가` | 첫 역이 지정되어 있고 추가할 수 있는 역이 있을 때 | `BeginAddRouteStop` | 맵에서 추가 역을 선택하는 입력 상태로 전환한다. |
| 맵의 역·포트 선택 | `+ 역 추가` 입력 상태일 때 | `AppendRouteStop(stationId, arrivalPortId)` | 역과 진입 포트를 목록 끝에 추가하고 직전 역의 진출 포트부터 선택 포트까지 단방향 경로를 검사한다. |
| 역 행 선택 | 역이 목록에 있을 때 | `SelectRouteStop(stationId)` | 맵에서 해당 역과 연결 구간을 강조한다. |
| `위로` / `아래로` | 선택 역을 이동할 수 있을 때 | `ReorderRouteStop(stationId, newIndex)` | 임시 방문 순서를 바꾸고 영향을 받은 양쪽 구간을 다시 검사한다. |
| `역 삭제` | 첫 역 이외의 역 또는 삭제 가능한 역 선택 시 | `RemoveRouteStop(stationId)` | 해당 역과 이어진 임시 구간을 목록에서 제거하고 연결 검증을 초기화한다. |
| `첫 역 변경` | 역이 2개 이상 등록됐을 때 | `ChangeRouteStart(stationId)` | 선택 역을 목록 맨 앞에 두고 순환 구간들을 다시 계산한다. |
| `순환 연결` | 방문 역이 2개 이상이고 마지막 구간이 아직 등록되지 않았을 때 | `CloseRouteCycle` | 마지막 역의 진출 포트부터 첫 역의 지정 진입 포트까지 기존 선로 연결을 확인해 닫힌 구간을 추가한다. |
| `순환 해제` | 순환 구간이 임시 등록되어 있을 때 | `ReopenRouteCycle` | 마지막 구간을 임시 노선에서 제거하고 역 순서 편집으로 돌아간다. |
| `경로 검증` | 첫 역·방문 역 2개 이상·순환 연결이 지정됐을 때 | `ValidateRouteDraft` | 모든 역·구간·방향·폐쇄 조건을 검사하고 결과 상태로 이동한다. |
| `노선 확정` | 검증 상태가 유효하고 확인 화면에 있을 때 | `CommitRoute` | 노선을 저장하고 기본 기차 1대를 정지 상태로 생성·배정한다. |
| `취소` | 편집 중일 때 | `CancelRouteDraft` | 임시 편집을 폐기하고 목록 또는 맵으로 돌아간다. 이미 저장된 노선은 변경하지 않는다. |

### 3.3 노선 확인 화면

**표시 요소**

- 노선에 등록된 역 순서(첫 역으로 돌아오는 연결 포함)
- 역마다 진입·진출 연결의 완료 여부
- 구간별 선로 길이와 진행 방향
- 총 선로 타일 수와 예상 순환 시간
- 기본 기차 생성·배정 및 정지 대기 안내
- 경고·검증 결과

**버튼과 이벤트**

| 버튼 | 활성 조건 | 이벤트 | 처리 및 다음 상태 |
| --- | --- | --- | --- |
| `노선 확정` | 필수 검증 전체 통과 | `CommitRoute` | 노선 저장, 기차 생성·배정, 확정 완료 상태로 이동한다. |
| `편집으로 돌아가기` | 항상 | `ReturnToRouteDraft` | 임시 노선 편집 상태를 복원한다. |
| `취소` | 항상 | `CancelRouteDraft` | 임시 노선을 폐기한다. 확정 전에는 실제 노선·기차를 생성하지 않는다. |

## 4. 이벤트·상태 전이

### 4.1 기본 전이

```text
목록
 └─ 새 노선 → 첫 역 지정
                  └─ 역 추가·순서 수정 ↔ 구간 확인
                        └─ 순환 연결 → 경로 검증
                              ├─ 실패 → 편집 상태 + 오류 강조
                              └─ 통과 → 노선 확인
                                            ├─ 편집으로 돌아가기 → 편집 상태
                                            ├─ 취소 → 목록/맵
                                            └─ 확정 → 노선 저장 + 기차 정지 대기
```

### 4.2 이벤트 처리 요구사항

1. UI 입력은 먼저 현재 화면 상태에서 허용되는지 검사한다.
2. 역 추가·순서 변경·삭제는 임시 편집 데이터에 적용하며, 확정 전까지 실제 노선 데이터를 바꾸지 않는다.
3. 구간 경로는 설치된 단방향 선로와 노선 구간에 지정한 출발역 진출 포트·도착역 진입 포트를 따라 검사한다. 자동 선로 설치나 우회는 생성하지 않는다.
4. 검증 실패 시 편집 화면을 유지하고, 실패 역·구간을 맵과 목록에서 함께 강조한다.
5. 확정 이벤트가 성공한 경우에만 노선 저장과 기본 기차 생성이 발생한다. 확정 이벤트 중복 입력은 기차를 중복 생성하지 않아야 한다.
6. 저장 중 맵 상태가 변해 검증이 무효가 되면 확정을 취소하고 최신 오류를 표시한다.
7. 취소·실패·비활성 버튼 입력은 자원·노선·기차 데이터를 변경하지 않는다.

### 4.3 필수 검증 및 오류 표시

| 검증 ID | 검사 내용 | 실패 시 UI 피드백 |
| --- | --- | --- |
| ROUTE-VAL-001 | 서로 다른 역이 최소 2개 등록됐는가 | 필요한 역 개수와 추가 가능한 역 선택 안내 |
| ROUTE-VAL-002 | 각 구간의 출발 진출 포트와 도착 진입 포트가 유효하고 역할이 맞는가 | 역할이 맞지 않거나 연결이 빠진 포트 강조 |
| ROUTE-VAL-003 | 각 연속 역 사이에 지정 포트 쌍을 잇는 단방향 연속 선로가 하나로 특정되는가 | 단절 또는 복수 경로 구간 강조 |
| ROUTE-VAL-004 | 마지막 역의 지정 진출 포트에서 첫 역의 지정 진입 포트까지 연결됐는가 | 순환을 닫는 마지막 구간과 포트 강조 |
| ROUTE-VAL-005 | 역이 중복 등록되지 않았는가 | 중복 역 목록과 제거 행동 표시 |
| ROUTE-VAL-006 | 선로 구간이 다른 노선에 이미 배정되지 않았는가 | 점유된 구간과 다른 노선 상태 표시 |
| ROUTE-VAL-007 | 모든 역과 선로가 활성·존재 상태인가 | 비활성 역·회수된 선로와 복구 안내 표시 |
| ROUTE-VAL-008 | 구간별 포트 지정, 방향, 선로 중간 분기·합류 제한을 만족하는가 | 위반 포트·타일과 허용 경로 조건 표시 |

검증 완료 상태는 색상만으로 구분하지 않고 `유효`, `오류`, `확인 필요` 문구와 아이콘을 함께 사용한다. 확정 불가 사유는 버튼 비활성화만으로 끝내지 않는다.

## 5. 화면 이미지·와이어프레임 템플릿

각 노선표 화면 이미지를 만들 때 다음 구성을 기록한다. 실제 게임 스킨이나 해상도가 아직 정해지지 않은 경우, 버튼·패널·맵 관계만 보여주는 와이어프레임을 먼저 만든다.

```markdown
#### [ROUTE-UI-ID] 화면 이름

- 화면 상태 및 진입 이벤트:
- 화면 목적:
- 주요 상호작용:
- 버튼·컨트롤과 활성 조건:
- 이벤트 및 성공 전이:
- 오류·비활성 상태:
- 맵에 표시할 요소:
- 패널·버튼 배치:
- 강조할 선택·오류:
- 이미지에서 생략할 정보:
- 검토 기준:
```

### 5.1 편집 화면 와이어프레임 초안

```text
┌────────────────────────────────────────────────────────────────────┐
│ 노선 편집 · 임시 노선 이름                         [취소] [검증]  │
├─────────────────────┬──────────────────────────┬─────────────────┤
│ 역 방문 순서         │                          │ 선택 구간 정보  │
│ 1. [첫 역]           │       맵 / 선로           │ A 진출 → B 진입 │
│ 2. [역 추가]         │   진행 방향·구간 강조     │ 연결 상태       │
│ 3. [역 추가]         │   진입·진출 포트 표시     │ 타일 수 / 시간  │
│ [위로] [아래로]      │                          │ [구간 확인]     │
│ [역 삭제] [+ 역]     │                          │                 │
├─────────────────────┴──────────────────────────┴─────────────────┤
│ 상태: 미완성 / 오류 위치·이유       [순환 연결] [노선 확정*]     │
└────────────────────────────────────────────────────────────────────┘
* 검증 통과 전에는 노선 확정 비활성
```

### 5.2 전체 관리 UI 상태별 시안

시안은 상호작용에 따라 화면이 바뀌는 임시 목업이며, 최종 게임 스킨이 아니다. 상태 선택으로 각 화면 구성을 확인하고, 노선 행 선택·뒤로가기·편집·운행 제어·역 추가·검증·확정 버튼을 직접 눌러 화면 전이를 살펴본다.

| 시안 상태 | 화면에 표시할 핵심 구성 | 진입·상호작용 |
| --- | --- | --- |
| 기본 맵 | 전역 노선 관리 진입과 역 선택 진입 | `노선 관리`는 전체 목록, 기차역 선택은 역 문맥 화면으로 이동 |
| 전체 노선 목록 | 전체 노선 행, 각 노선의 역 수·순서 요약·유효성·기차 상태·예상 시간, 새 노선 버튼 | 노선 행 선택 시 별도 상세 화면 |
| 선택 노선 상세 | 순환 역 순서, 상태, 기차, 예상 순환 시간, 총 선로 길이, 화물 설정 요약 | `노선 편집`, `운행 시작/중지`, `목록으로`, 역 선택 |
| 역 문맥 정보 | 선택 역 이름, 포함 노선, 방문 순서, 이전·다음 역, 운행 상태 | `이 노선 상세/수정`; 다른 노선 목록은 표시하지 않음 |
| 기존 노선 편집 | 기존 방문 순서를 보존한 편집 목록, 역 추가, 경로 검증·변경 저장·취소 | 정지 중 저장은 즉시 반영. 운행 중 저장은 예약 상태로 표시되고 한 바퀴 완료 후 적용 |
| 새 노선 구성 | 빈 방문 목록, 설치 역 선택, 순서 추가, 검증·확정·취소 | 확정 성공 시 노선 상세로 이동하고 기차를 정지 상태로 생성 |
| 빈 노선 목록 | 등록 노선 0개 안내, 새 노선 진입 | `새 노선 구성` 선택 |
| 검증 오류 | 누락된 순환 구간 또는 연결 문제와 오류 문구 | `노선 편집`으로 복귀; 확정·운행 시작 불가 |

시안 목업의 샘플 노선명과 수치는 화면 밀도와 상호작용 확인용 예시이며 게임 데이터 기준이 아니다. 노선 삭제, 복제, 검색·정렬 등 미확정 기능은 시안 버튼으로 추가하지 않는다.

### 5.3 확인 화면 이미지 구성

- 맵에는 전체 순환 경로와 방향 화살표, 순서 번호를 표시한다.
- 요약 영역에는 역 순서, 구간 길이, 총 길이, 예상 순환 시간을 표시한다.
- 검증 상태와 해결되지 않은 오류를 글자로 명시한다.
- `노선 확정`, `편집으로 돌아가기`, `취소`의 우선순위를 구분한다.
- 확정 성공 상태 이미지에는 새 기차가 생성됐지만 아직 정지 상태임을 표시한다.
