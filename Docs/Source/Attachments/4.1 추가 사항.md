### 자원-건물 연결

- 기존 자원으로 만든 광물 자원은 방어 건물 운용과 연결하지 않는다. 
- "전력 발전기" 건물을 설치하여 매 초 일정량의 전력을 생산하며 추가로 해당 전력은 메인 기지와 서브 기지에서 저장한다. 
	- 메인 기지와 서브 기지의 전력 보관 총 양은 정해져 있으며 업그레이드를 통해서 저장 양을 늘릴 수 있다. 
	- 전력은 설치 범위의 방어 건물을 대상으로 전력을 공급. 적절한 생산량과 소비를 균형 있게 설치해야 하는 것을 목표로 한다.
	- 전력은 퍼센트/수치로 표시 100%/20000 과 같이 78%/17293 처럼 표시한다. 
	- 방어 건물은 매 초 전력을 소모 / 전력 발전기는 매 초 전력을 생산한다.
	- 기지와 기지는 전력을 서로 공유하지 않는다. 
			- 하나 맵 컨텐츠 구성을 완료하고 이후에 "전력 코어" 아이템을 통해서 운송 수단을 만들어 전달 하는 방식으로 확장 예정.
				- 운송 수단으로는 "기차" 활용 예정.


- 기존 자원은 기지와 건물을 강화하는 용도로 사용한다.
