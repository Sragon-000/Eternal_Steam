

### 1. 분류 버튼 

건물 분류 버튼으로 "방어" , "자원", "기타" , "설치" 4가지 버튼으로 구성.

### 1.1 분류 버튼 UI 위치 

버튼은 "방어" , "자원", "기타" , "설치" 순서대로 버튼이 건물 인벤토리 상단 왼쪽부터 순서대로 나열. 

처음 분류 선택되어 있는 영역은 "방어"로 방어 건물이 처음 해당 UI를 키거나 표시하는 경우 나오게 되며 이후에 다른 분류를 선택하고 UI를 닫더라도 다시 키면 "방어" 분류로 초기화 된다.

-> 초기 분류 항목은 "방어" 다 



### 2. 수정, 확정 버튼 


"수정", "확정" 버튼 2개로 구성.

- 수정 버튼과 확정 버튼은 수정 버튼만 활성화 되어 있으며, 수정 상태이지 않는 경우에는 비활성화 상태로 반투명 상태로 확정 버튼이 작동하지 않아야 한다.
- 확정 버튼은 수정 상태에서만 활성화 되어 있으며 확정을 눌러 수정을 완료한 이후에는 다시 작동하지 않는 초기 환경으로 돌아간다.
  
-> 처음 UI를 보았을 경우 수정 버튼만 활성, 확정 버튼은 비활성  
### 1.1 수정, 확정 버튼 UI 위치 


"수정", "확정" 버튼은 건물 인벤토리 상단 오른쪽에 이미지와 같이 순서대로 나열. 

-> 오른쪽 상단을 기준으로 왼쪽에 수정 버튼, 오른쪽에 확정 버튼
### 3. 건물 인벤토리 

- 건물 인벤토리에는 설치 가능한 건물들이 표시되며 분류 기준에 따라 표시되는 건물이 달라진다. 
- 건물 인벤토리는 8개 이상 항목이 넘어가게 될 경우 다음 줄로 넘어가서 표시한다.
