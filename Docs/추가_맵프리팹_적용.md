# 추가 맵 프리팹 적용

2026-09-18. Assets/Prefab_Map/MapCreater .prefab을 원본 StartRegionSandbox 씬에 에디터에서 배치해 저장했다. 실행 중 맵 생성 방식이 아니다.

- 원본 프리팹·구성·메시·재질은 수정하지 않았다. 씬 인스턴스에 188개 MeshCollider와 지면 레이어를 추가했다.
- 50×50, 1m 타일의 원래 크기/회전을 유지했다. 건설 격자는 기존 2m·45도를 유지한다.
- 평탄한 표면을 추출하고 급격한 높이 차/가장자리 주변은 제외한 1,627개 통행 셀 및 보이지 않는 Terrain 높이 캐시를 연결했다. 물/특수 지형의 의미 분류는 이 프리팹에 정의되어 있지 않으므로 형상 기반 검증 정책이다.
- 기존 맵 루트는 비활성 상태로 보존했다. 적용 전 씬 사본은 Scene/Tests/StartRegionSandbox_BeforeImportedMap 1.unity에 있다. 최초 적용 실패 전 생성된 BeforeImportedMap.unity 사본도 남아 있다.
- 카메라 시작점을 8m 토대 설치가 가능한 평지로 옮겼다. 기존 지역 자원 검증 데이터는 새 맵 기획으로 재작성하지 않았다.
- 기존 직선 이동/통행 검사를 연결했으며 지형 우회 길찾기를 추가한 것은 아니다.

Tools/VerifyImportedMap.cs: 원본 씬 Play에서 넥서스 설치·확정, 적 10마리 실제 생성, 생성 위치 통행 가능 판정 통과. 씬 재로드 후 콜라이더·높이 에셋·토대 설치 지면도 확인했다. 게임 빌드는 하지 않았다. 대규모 적 성능이나 모든 높이 경계의 이동은 이번 검증 범위가 아니다.
