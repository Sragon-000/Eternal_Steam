## 건물.md

| 원문 항목 | 구현과 이번 조치 |
|---|---|
| 설치 가능한 오브젝트를 건물로 분류 | BuildingDefinition / BuildingInstance. 분류가 기능을 자동 부여하지 않음 |
| 방어·자원·설치·기타 분류 | BuildingCategory 4종. 모듈 구성과 분리 |
| 점유 크기·설치 가능·회수 가능 | Footprint, TerrainRule / OccupancyRule, Recoverable |
| 다중 격자·설치 불가 영역·실제 점유 충돌 | BuildGrid와 PlacementSession. 회전해도 정수 점유 계약 유지 |
| 임시 배치·복수 추가·전체 확정·전체 취소 | 공통 기반에 구현됨. 오픈월드의 즉시 설치를 WorldEditSession 임시 작업으로 연결 |
| 임시 상태는 전장·자원에 미반영 | 프리팹 미리보기만 생성, 실제 BuildingWorld·전투 등록은 확정 시 수행 |
| 예약 소유자·예약 충돌·이동·선택 해제 | 공통 예약 유지. 오픈월드 임시 포탑 이동과 토대 예약/이동 구현 |
| 선택 해제 시 예약 해제 | **후속 합의로 변경:** 선택만 해제할 때 예약은 유지. 이동 성공·개별 제거·전체 취소 시 해제 |
| 확정 직전 전체 재검사·부분 설치 금지 | 동일 월드뿐 아니라 여러 토대의 PlacementSession을 묶어 검사·생성·활성화. 실패 시 생성 개체 정리, 예약 유지 |
| 실패한 임시 건물은 빨강, 나머지도 임시 상태 유지 | 오픈월드 재검사 결과에 따라 외곽선·반투명 색상 갱신 |
| 임시 건물 이동·개별 제거 | 오픈월드 선택 후 이동/개별 제거. 이동 실패 시 이전 위치·예약 유지 |
| 복수 회수·선택 해제·확정 전 실제 상태 유지 | RecoverySession + WorldEditSession. 실제 포탑 등록·점유는 회수 확정까지 유지 |
| 회수 불가 대상 제외·누락 대상 검증 | 공통 Recoverable 검사. 여러 토대 전체 재검증. 누락 시 전체 보류, UI에서 회수 목록 해제 가능 |
| 설치·회수·확정·취소 공용 작업 버튼 | 오픈월드 일반 상태에는 설치/회수, 작업 중에는 확정/취소. 건물 종류·선택 건물 동작은 별도 표시 |
| 임시 대상 없으면 확정 비활성 | UI CanConfirm. 방향 변경은 방향 클릭 후 활성 |
| 초록/빨강 격자·반투명·외곽선 | 오픈월드 위치 미리보기와 임시 건물 표시 적용. 설치 대기 청록 외곽선, 회수 예정 주황 외곽선. 공유 재질 변경 없이 개별 재질 복사 후 복원 |

토대는 먼저 확정해야 그 위에 포탑을 예약할 수 있다. 토대의 회수는 현재 오픈월드 제품 규칙에 포함하지 않으며, 포탑 회수를 지원한다. 임시 토대는 이동·개별 제거·전체 취소할 수 있다.

## 방어_건물.md

| 원문 항목 | 구현 위치 / 상태 |
|---|---|
| 공격력·공격 주기·사거리·전체 부채꼴 각도·대상 종류 | AttackModuleDefinition. 주기는 초, 각도는 전체 각도 |
| 단일·광역·관통·연쇄·투사체 | InstantDamage 및 각 AttackExecutionDefinition 구현. ModuleSandbox 검증 조합 |
| 둔화·기절·방어력 감소 | StatusEffectDefinition, IStatusReceiver, StatusState |
| 체력 | HealthModuleDefinition. 정의 공유와 실행 상태 분리 |
| 최근접 선택·동률 ID 순서 | NearestTargetSelector |
| 더 가까운 적이 와도 타겟 유지 | AttackModule.CurrentTarget. 사망·범위 이탈·종류 불일치 시 재선정 |
| 필터 변경 시 공격 불가 타겟만 해제 | **이번 수정:** 지상 → 전체처럼 기존 타겟이 유효하면 유지. 호환 필터 변경 때 무조건 해제하던 차이 수정 |
| 지상/공중/전체를 포탑별 설정 | IAttackControl.Kinds, FoundationHud의 선택 포탑 설정 |
| 중심 간 XZ 거리·부채꼴 경계 포함 | Sector.Contains와 테스트 |
| 방향 미리보기 후 확정·작업 중 행동 불가 | BuildingInstance 방향 편집과 SandboxSession. **이번 연결:** 오픈월드 설치된 포탑도 선택 → 부채꼴 방향 클릭 → 확정/취소 지원 |
| 즉시 피해 시 발사 조건 판정 | AttackModule → InstantDamage |
| 발사 후 범위 밖이어도 투사체 유지 | ProjectileAttackDefinition. 중심 도달 시 피해. 타겟 소실/세대 재사용 시 소멸하는 검증용 정책 |
| 장애물 시야 차단 | 원문도 향후 기능. 현재 거리·각도·종류만 판정하며 시야 차단은 추가하지 않음 |
| 넥서스 레벨을 넘지 않는 강화 | UpgradeModuleDefinition + ILevelLimit |

**연결 범위:** 위 새 전투 규칙은 공통 모듈과 FoundationSandbox/ModuleSandbox에 구현돼 있다. OpenWorldSandbox의 기존 4종 포탑은 앞서 합의한 레거시 공격 호환 경로를 유지한다. 그 포탑의 공격을 새 최근접 타겟/공중 필터/넥서스 강화로 바꾼 것은 아니다. 이번에는 설치 작업·방향 편집·회전 격자를 오픈월드에 연결했다. 모든 검증용 기능이 모든 씬에 연결되었다고 간주하지 않는다.

## 기타_건물.md

| 원문 항목 | 구현 위치 / 상태 |
|---|---|
| 넥서스가 핵심 기지 | NexusModuleDefinition, IBaseObjective |
| 넥서스 파괴 시 즉시 게임 종료 | NexusState.Lost → SandboxSession 결과/패배 전환 |
| 일반 건물 최대 레벨은 넥서스 현재 레벨 | UpgradeModuleDefinition, ILevelLimit. 넥서스 없는 조합에서는 제한 건물 강화 불가 |
| 넥서스 강화 후 다른 건물 강화 | ModuleSandbox의 선택 → 강화 UI와 테스트 |

기차를 넥서스로 삼는 규칙, 낮밤, 운행, 자원 비용·경제 밸런스는 대화 중 아이디어이며 확정된 문서 규칙이 아니다. 이번 대조 과정에서 임의로 추가하지 않았다.

## 45도 3D 설치

- XZ 지면 위의 격자를 **Y축 기준 45°** 회전한다. 층을 쌓는 복셀/3축 격자는 아니다.
- WorldGridGeometry가 토대 위치와 지형 검사, BuildGrid가 월드↔격자 변환을 담당한다.
- 토대 프리팹·그리드 선·칸 중심·미리보기·배치/이동/회수 판정이 같은 회전을 사용한다.
- 토대는 8×8m, 내부는 2m 간격 4×4. 회전된 네 모서리까지 Terrain 경계·경사를 검사한다.
- 건물 공격 방향은 격자 회전과 별개이며 마우스로 자유롭게 정한다.
- 기존 저장된 토대는 실제 Transform 회전을 읽어 점유를 계산한다. 지형·재질·기존 씬 파일을 덮어쓰지 않는다.
- 기존 공통/레거시 격자는 기본 yaw=0을 유지한다.
