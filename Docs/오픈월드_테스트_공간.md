# 오픈월드 인게임 테스트 공간

`Assets/EternalSteam/Scene/Tests/OpenWorldSandbox.unity`를 열고 **Play**한다. Terrain은 씬에 저장되어 있으며 시작 시 토대·포탑은 없다. 설치 외형은 미리 만든 프리팹을 사용한다.

## 게임 안에서 사용

1. **토대 설치 · 8×8m** → 평탄한 지형 클릭. 토대 위에 2m 간격 4×4 그리드가 나타난다.
2. **포탑 종류** 선택 → 토대의 빈 칸 클릭 → 공격할 방향 클릭. 기존 포탑 4종을 사용한다.
3. **수정 · 포탑 회수** → 포탑이 있는 칸 클릭. 회수한 칸에는 다시 설치할 수 있다.
4. **편집 종료**, 우클릭 또는 Esc로 설치 모드를 종료한다. 방향 선택 중 취소하면 포탑을 만들지 않는다.
5. 수량 칸을 직접 클릭해 숫자를 입력한 뒤 **입력한 수량 소환**을 누른다.

WASD는 카메라 이동, 휠은 확대·축소다. 수량 칸을 직접 클릭했을 때만 숫자를 입력하며, WASD로 입력칸이 활성화되지 않는다. Enter·Esc·지형 클릭·다른 버튼은 수량 편집을 끝낸다. UI 위에서 휠을 돌리면 카메라 줌은 멈춘다.

설치·회수 모드는 전투를 일시정지한다. 소환 또는 전투 실행으로 재개한다. 적 초기화는 토대와 포탑을 유지한다. **Play 중 배치는 Play 종료 시 사라지며 영구 저장하지 않는다.**

## 구성과 범위

- `Scene/Tests/OpenWorldSandbox.unity`: 준비된 Terrain·카메라·게임 UI.
- `Content/Buildings/OpenWorldAuthoring`: 토대와 기존 4종 포탑 프리팹.
- `FoundationPlacement`: 토대별 공통 격자·점유·배치·회수와 프리팹 등록.
- `OpenWorldInput` / `OpenWorldHud`: 게임 클릭·미리보기·버튼 요청.
- `SpawnQuantityInput` / `FreeCameraRig`: 수량 편집과 카메라 입력 분리.
- `OpenWorldSandbox`: 기존 배열 적·공격·렌더링 조립.
- `Shared/UI/OpenWorld/OpenWorldHud.uxml`: 현재 인게임 UI.

토대는 지형 경계·경사·중복 검사를 거치며 포탑은 토대의 빈 칸에만 설치된다. 적은 최대 4,000마리이며 초과 요청은 전체 거부한다. 화면 중심 왼쪽에서 오른쪽으로 지형 높이를 따라 이동하고 토대를 통과한다. 장애물 회피·토대 공격·경제·영구 저장·토대 회수는 아직 없다.

Editor의 `씬 배치 편집` 창은 사전 배치용 보조 도구로 남아 있다. 일반 테스트는 Game 뷰의 버튼으로 진행한다. `EnableOpenWorldConstruction`은 기존 씬의 프리팹·Terrain을 보존하며 인게임 UI를 연결하는 설정 도구다.

현재 검증 도구는 `VerifyOpenWorldSandbox`(설치·회수·4종 공격·소환), `VerifyQuantityFocus`(WASD/수량 입력 분리), `VerifyOpenWorldCameraInput`(키보드·휠·UI 차단)이다. 이전 `VerifyAuthoredPlay`는 건설 UI가 없던 편집 전용 구성의 과거 검증이다. 기존 데모와 빌드 목록은 유지한다.
