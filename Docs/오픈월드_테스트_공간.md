# 오픈월드 인게임 테스트 공간

TileWorldCreator로 산과 강이 있는 96×96 셀 맵을 적용했다. 평지에 토대를 설치할 수 있으며 강·산지·외곽은 차단한다. 현재 사용 중인 부분과 활용 가능한 기능, 후속 연결 범위는 [TileWorldCreator 그리드 연동 및 사용 범위](TileWorldCreator_그리드_연동_및_사용_범위.md)를 참고한다.

`Assets/EternalSteam/Scene/Tests/OpenWorldSandbox.unity`를 열고 **Play**한다. TWC 메시·콜라이더와 설정은 씬·에셋에 저장되어 있으며 시작 시 토대·포탑은 없다. 기존 Terrain은 렌더링·충돌을 끈 높이 캐시로 유지한다. 설치 외형은 미리 만든 프리팹을 사용한다.

## 게임 안에서 사용

1. **수정 → 설치 탭 → 넥서스**를 지면에 배치하고 **확정**한다. 다시 수정 → 설치 → 토대를 선택해 넥서스 범위 안에 배치하고 확정한다.
2. **수정 → 방어 탭 → 포탑**을 누르고 넥서스 범위의 빈 지면 칸 또는 토대 칸을 한 번 클릭한 뒤 **확정**한다. 토대는 선택 사항이다.
3. **수정 → 기존 포탑 또는 토대의 빈 부분 클릭**으로 회수 예정 선택/해제한다. 토대 선택 시 위 포탑도 함께 묶인다. **확정**할 때만 실제로 회수한다.
4. **수정 버튼 다시 클릭 / Esc / 우클릭**은 임시 배치와 회수 선택을 모두 취소한다. 임시 건물을 다시 클릭하면 해당 임시 배치만 제거한다. 하단 보조 버튼은 제거했다.
5. 오른쪽 위에서 적 수량을 입력하고 소환한다. 수정 중에는 소환·전투 시작을 막는다.

수정 진입 시에는 새 배치 종류를 자동 선택하지 않는다. 포탑을 목록에서 선택한 상태에서는 토대의 빈 칸 클릭이 새 배치 요청이다. 기존 포탑 클릭은 회수 예정 선택으로 처리한다. 회수와 새 배치 작업은 섞지 않고 먼저 확정하거나 취소한다.

분류는 **방어·자원·기타·설치** 순서이며 다시 열면 방어로 초기화한다. 초기 확정 버튼은 반투명·비활성이고 수정 중에만 활성화한다. 상세한 동작과 검증은 [배치 수정 임시 UI](배치_수정_임시_UI_적용.md)를 참고한다.

**3D XZ 지면 격자를 Y축 기준 45° 회전**했다. 토대 외형·격자 선·실제 설치 위치가 일치하며 8×8m 토대 위 2m 간격 4×4 격자다. 공격 방향은 적 위치를 따라 자동 조준한다. 우클릭·Esc는 진행 중인 임시 작업 전체를 취소한다.

WASD는 카메라 이동, 휠은 확대·축소다. 수량 칸을 직접 클릭했을 때만 숫자를 입력하며, WASD로 입력칸이 활성화되지 않는다. Enter·Esc·지형 클릭·다른 버튼은 수량 편집을 끝낸다. UI 위에서 휠을 돌리면 카메라 줌은 멈춘다.

설치·회수 모드는 전투를 일시정지한다. 소환 또는 전투 실행으로 재개한다. 적 초기화는 토대와 포탑을 유지한다. **Play 중 배치는 Play 종료 시 사라지며 영구 저장하지 않는다.**

## 구성과 범위

- `Scene/Tests/OpenWorldSandbox.unity`: 준비된 Terrain·카메라·게임 UI.
- `Content/Buildings/OpenWorldAuthoring`: 토대와 기존 4종 포탑 프리팹.
- `FoundationPlacement`: 토대별 공통 격자·점유·배치·회수와 프리팹 등록.
- `OpenWorldInput` / `OpenWorldHud`: 게임 클릭·미리보기·버튼 요청.
- `SpawnQuantityInput` / `FreeCameraRig`: 수량 편집과 카메라 입력 분리.
- `OpenWorldSandbox`: 기존 배열 적·공격·렌더링 조립.
- `Shared/UI/OpenWorld/OpenWorldHud.uxml`: 현재 인게임 UI.

토대는 지형 경계·경사·중복 검사를 거치며 포탑은 넥서스 범위의 빈 지면 칸 또는 토대 칸에 설치된다. 적은 초기화 전 누적 요청 최대 100,000,000마리, 동시 활성 최대 100,000마리다. 한 번에 최대 2,048마리씩 생성하고 나머지는 대기 수량으로 보관한다. 확정된 넥서스가 없으면 소환하지 않는다. TWC 평지 중 가까운 넥서스까지 직선 경로가 강·산지를 지나지 않는 위치에 기본 0.75m XZ 중심 간격으로 생성하며, 기존 적 및 이번에 생성한 적 모두와 간격을 검사한다. 생성 위치에서 가장 가까운 넥서스 중심을 목표로 지형을 따라 이동한다. 목표 넥서스 중심 반경 20m 안에서는 생성하지 않는다. 공간이 부족하면 겹쳐 만들지 않고 대기한다. 간격은 생성 시점에만 보장하며 이동 중에는 서로 모일 수 있다. 목표에 도착한 적은 기존 테스트 흐름대로 제거되고 대기 적이 이어서 유입된다. 장애물 우회 길찾기·토대 공격·경제·영구 저장은 아직 없다. 강을 건너는 직선 소환 경로는 제외하므로 반대편 적이 자동으로 다리를 찾아오지는 않는다.

Editor의 `씬 배치 편집` 창은 사전 배치용 보조 도구로 남아 있다. 일반 테스트는 Game 뷰의 버튼으로 진행한다. `EnableOpenWorldConstruction`은 기존 씬의 프리팹·Terrain을 보존하며 인게임 UI를 연결하는 설정 도구다.

현재 건설 검증은 `VerifyDocumentConstruction`(45°·임시 배치·이동·일괄 확정·회수·방향 변경)이다. 입력 검증은 `VerifyQuantityFocus`(WASD/수량 입력 분리), `VerifyOpenWorldCameraInput`(키보드·휠·UI 차단)이다. 이전 `VerifyOpenWorldSandbox`는 즉시 설치 방식, `VerifyAuthoredPlay`는 건설 UI가 없던 편집 전용 구성의 과거 검증이다. 기존 데모와 빌드 목록은 유지한다.

문서 3종의 전체 세부 항목과 씬별 연결 범위는 [문서 대조표](문서_세부항목_적용_대조.md)를 참고한다.

## 대규모 소환 구조와 검증 (2026-09-16)

- `EnemySpawnStream`: 요청 수량·대기·분할 생성. 1억 개의 객체나 배열을 만들지 않는다.
- `EnemySpawnLayout`: 생성 간격 공간 조회. `NexusDestinationQuery`: 확정된 넥서스의 최근접 목표 선정.
- `HordeEnemyWorld`: 인스턴스별 용량·공간 검색 범위. 기존 데모 기본값 4,000과 기존 맵 범위를 유지하며 오픈월드만 10만/Terrain 범위를 사용한다. 공격과 렌더링은 실제 인스턴스 용량을 순회한다.
- Inspector의 `Enemy Spawn Spacing`은 시작 시 적용한다. 큰 간격이나 작은 지형에서는 공간 부족으로 동시 10만이 채워지지 않고 대기할 수 있다.
- [검증 기록](Validation/대규모_적_소환_검증.md).

## 휠 줌 입력 보정 (2026-09-16)

Input System의 기본 정규화된 휠 입력(한 칸 ±1)을 그대로 적용한다. 기존의 일괄 `/120`은 제거했으며, Windows에서 플랫폼 원시 입력 설정을 사용한 경우에만 120 단위를 변환한다. 휠 위쪽은 확대, 아래쪽은 축소이며 한 칸당 배율은 `exp(-0.12 × 입력)`이다. 카메라 크기 범위는 10~70을 유지한다. UI 위에서는 줌하지 않는다.

`VerifyOpenWorldCameraInput`에서 실제 카메라 크기와 ±1 입력, 역방향 복원, 무입력 유지, 0.25 미세 입력, 3칸 입력, 상하한과 상한에서 역방향 전환, UI 차단, WASD/수량 입력 분리를 검증했다. 검증용 Editor Play에서 통과했으며 빌드는 하지 않았다. 이전 검증이 120 크기의 가상 휠 입력만 사용해 실제 정규화 입력의 미약한 반응을 놓친 부분도 수정했다.

## TWC 맵 적용 (2026-09-17)

산지 최고 높이 21m, 강과 강둑, 평탄한 건설 공간으로 구성했다. 메시 생성과 높이 캐시 재작성은 `Tools/ApplyTileWorldMountainRiver.cs`에서 함께 수행한다. TWC Inspector에서 레이어만 변경하면 캐시와 허용 셀이 자동 갱신되지 않으므로 전체 생성 도구를 사용한다. [적용·검증 및 복원 안내](Validation/TileWorldCreator_산과강_적용.md).

## 자원·방어 콘텐츠 적용 (2026-09-17)

자원 탭에 지면 설치 건물 7종, 방어 탭에 새 포탑 9종을 추가했다. 기존 4종은 유지한다. 1·4·9셀 점유, 준비 중 자동 생산, 공중 적 소환, 선택 건물 무료 강화(검증)를 시험할 수 있다. 오른쪽 패널을 스크롤하면 자원과 강화 정보를 볼 수 있다. 새 콘텐츠의 수치·성장·경제는 검증 설정이며 영구 저장하지 않는다. [적용 결과·사용법·검증 한계](자원_방어_건물_적용_결과.md).

## 넥서스 건설 범위

넥서스를 먼저 확정해야 토대를 설치할 수 있다. 초기 반경은 검증용 40m이며 `DocumentContent/installation.nexus.area.asset`의 Radius로 변경한다(다음 Play부터 적용). 토대의 45° 회전된 네 모서리 모두 하나의 넥서스 XZ 원형 범위 안에 있어야 한다. 지형 높이는 범위 거리에서 제외하며 지형/경사/겹침 조건도 함께 검사한다. 수정 중에는 지형 높이에 맞춘 범위 원을 표시한다. 자원 건물은 지면에 설치하며 전체 점유 영역이 확정된 넥서스 범위 안에 있어야 한다.

임시 넥서스는 건설 범위를 제공하지 않는다. 넥서스 배치 취소는 예약도 해제한다. 토대 확정 시 범위를 다시 검사하고 실패하면 임시 배치를 유지한다. 넥서스를 회수했을 때 남는 토대가 다른 넥서스 범위로 보호되지 않으면 회수를 차단한다. 해당 토대와 범위가 필요한 자원 건물을 함께 회수 예정으로 선택하면 일괄 확정할 수 있다. 여러 넥서스 설치를 지원하며 넥서스 개수·건설 비용·제품 넥서스 성장 규칙은 확정하지 않았다. 기존 검증용 해금 레벨 설정은 그대로다.

범위 기능은 공통 `BuildAreaModuleDefinition`/`IBuildArea`로, 오픈월드 토대의 설치 조건과 연결한다. 생성 도구는 `ApplyNexusConstruction`, 검증은 `VerifyNexusConstruction`이다. 예전 토대 우선 검증 도구는 넥서스를 먼저 설치하는 준비 절차가 필요하다.

검증용 Editor Play에서 미설치/임시/확정 넥서스, 반경 경계·회전 모서리, 범위 밖 이동 실패와 예약 유지, 사용 중 넥서스 회수 차단, 토대와 동시 회수, 확정 직전 넥서스 소실을 검증했다. [실행 기록](Validation/nexus-construction.json). 게임 빌드는 하지 않았다.

## 적 목적지 변경

소환 목적지를 토대에서 확정된 넥서스로 변경했다. 넥서스만 있어도 소환할 수 있고 임시 배치 넥서스는 제외한다. XZ 거리로 가장 가까운 넥서스를 선택하며 같은 거리면 개체 ID 순이다. 넥서스 추가·회수·소실 시 살아 있는 적도 현재 위치에서 목표를 다시 선택한다. 변경이 없으면 적 전체의 목표를 매 프레임 검색하지 않는다.

넥서스가 모두 사라지면 기존 적은 제자리에서 대기하고 신규 생성도 멈추며 대기 수량은 보존한다. 새 넥서스 확정 후 전투 실행 시 다시 이동·생성을 이어간다. 도착 시 제거하는 기존 테스트 규칙은 유지한다. 넥서스 공격·피해와 재목표 경로의 장애물 우회는 아직 구현하지 않았다. 최초 지상 소환의 직선 경로 검사·간격·배치 한도는 유지했다.

`VerifyNexusDestinations`로 미설치/임시 넥서스 차단, 토대 없는 넥서스 소환, 최근접/동률, 기존 적 재선정, 전체 넥서스 소실 대기, 재설치 재개, 공중 높이와 기존 데모 이동 기본값을 Editor에서 확인했다. [검증 기록](Validation/nexus-destinations.json). 빌드는 하지 않았다.

## 넥서스 크기와 정렬

넥서스는 토대 하나와 같은 8×8m로 변경했다. 점유는 2m 셀 4×4(16셀), 배치 간격은 8m이며 토대와 같은 원점·Y축 45° 격자를 사용한다. 일반 자원 건물의 2m 배치 간격은 유지한다. 배치 프로필의 `SnapCells`로 간격을 지정하고 음수 좌표도 내림 처리한다. 넥서스 바닥판과 선택 콜라이더는 8×8m이며 평지에서 바닥판 윗면을 토대 높이에 맞췄다. 서로 다른 지형 높이를 자동 평탄화하는 기능은 아니다. 넥서스 위 포탑 설치는 이번 변경에 포함하지 않는다.

`VerifyNexusFootprint`로 양수·음수 좌표 정렬, 이웃 토대 경계 일치, 모델·콜라이더 크기, 평지 높이를 확인했다. [검증 결과](Validation/nexus-footprint.json). 기존 Play 중 배치는 종료 후 다시 배치해야 새 정의가 적용된다.

## 자원 건물의 넥서스 범위 조건

자원 7종의 배치 프로필에 `RequiresBuildArea`를 설정했다. 미리보기·임시 추가·이동·전체 확정은 같은 범위 검사를 사용하며 XZ상의 전체 점유 사각형이 확정된 넥서스 하나의 범위 안에 들어와야 한다. 넥서스 자체에는 이 조건을 적용하지 않는다. 임시 넥서스로 자원 건물을 설치할 수 없으며 넥서스를 먼저 확정해야 한다. 범위 조건과 지형·경사·점유·해금 조건은 함께 적용한다.

회수할 넥서스를 제외한 나머지 범위로 모든 잔존 토대와 자원 건물을 검사한다. 보호되지 않는 자원 건물이 있으면 회수 전체를 보류하고, 다른 넥서스가 해당 건물을 포함하거나 해당 자원 건물도 함께 회수할 때 허용한다. 범위 의존 여부는 개별 건물 실행 상태 생성 시 복사한다. 설치 후 넥서스가 파괴될 때 생산 중지·건물 파괴를 추가하는 변경은 포함하지 않았다.

Editor Play에서 자원 7종 설정, 넥서스 미설치/임시 상태, 범위 경계, 내부 설치, 회수 의존성, 다른 넥서스의 대체 범위, 동시 회수/취소, 확정 직전 넥서스 소실과 예약 유지를 검증했다. [실행 기록](Validation/resource-build-area.json). 빌드는 하지 않았다.

## 넥서스 전체 격자와 지면 방어 건물

넥서스를 확정하면 반경 전체에 지형 높이를 따라가는 2m 간격·Y축 45° 격자를 생성한다. 격자는 일반 상태에서도 표시하며 넥서스 회수/파괴 시 함께 제거한다. 하나의 정적 메시로 표현하고 격자 셀마다 오브젝트나 콜라이더를 만들지 않는다. 표시 격자는 건설 허가 자체가 아니므로 강·산지·경사·범위 경계·기존 점유·예약은 별도로 검사한다. 여러 넥서스는 같은 전역 격자를 사용한다.

신규 방어 9종과 기존 포탑 4종 모두 토대 없이 설치할 수 있다. `GroundOrFoundation` 배치 프로필이 토대 위 클릭을 토대 월드로, 지면 클릭을 공통 지면 월드로 연결한다. 지면 포탑과 자원·넥서스는 점유 및 임시 예약을 공유한다. 1·4·9칸 포탑 전체가 한 넥서스 범위 안에 있어야 하며 토대와 지면을 가로지르는 설치는 차단한다. 토대를 먼저 임시 배치했다면 확정 후 그 위에 포탑을 배치한다.

기존 포탑은 기존 공격 구현과 팩토리를 지면 월드에 연결했다. 가짜 토대를 생성하지 않는다. 지면 방어 건물도 넥서스 회수 의존성 검사에 포함한다. 준비 중 지면 무기 실행은 멈추고 자원 생산은 유지한다. 칸 클릭·회수 예정 선택·확정·취소를 사용한다. 공격 방향 지정은 아래 원형 자동 공격 변경으로 제거했다.

검증용 Editor Play에서 신규 9종/기존 4종 지면 설치·예약·취소·회수, 범위/중복 검사, 준비 중 공격 정지와 전투 피해, 토대 위 9칸 설치, 지면/토대 간 임시 충돌을 확인했다. 실제 샌드박스 입력 경로로 방향 지정과 회수 취소/확정도 검증했다. 게임 빌드는 하지 않았다.

## 원형 사거리 자동 공격

오픈월드 포탑 배치를 **수정 → 포탑 선택 → 격자 칸 한 번 클릭 → 확정**으로 변경했다. 방향 지정/변경 단계와 방향 표식을 제거하고 배치·선택 범위 표시를 원으로 변경했다. 새 방어 9종과 기존 포탑 4종 모두 XZ 원형 사거리 안에서 적을 자동 탐색한다. 새 무기의 Angle 필드는 과거 직렬화 호환용으로만 남기고 Inspector에서 숨겼으며 공격 인식에는 사용하지 않는다.

타겟은 유효한 동안 유지하고 사망·범위 이탈·필터 변경 시 다시 선택한다. 최초 선택은 가까운 순, 동률은 ID 순이며 교체로 공격 쿨다운을 초기화하지 않는다. 포신은 선택한 적을 향해 즉시 조준한다(회전 속도·조준 지연은 이번에 추가하지 않음). 논리적 방향 변경 이벤트와 시각적 조준 이벤트를 분리하여 자동 조준이 추적 시간이나 타겟을 초기화하지 않게 했다.

적이 없으면 공격하지 않는다. EMP도 범위에 유효 대상이 있을 때만 펄스를 실행한다. 범위 판정은 공격 인식이며 폭발 반경·연쇄·관통·냉기 부채꼴 같은 실제 효과 모양은 유지한다. 기존 냉기는 선택한 적 쪽으로 부채꼴 효과를 내고, 기존 관통은 목표 방향으로 발사하며 기존 최소 1.2m 사각은 오픈월드 자동 공격에서만 제거했다.

기존 3개 데모 맵은 `HordeTowerCombat`의 기본 호환 모드로 이전 무조건 연사·방향 규칙을 유지한다. 오픈월드에서만 자동 표적 모드를 명시적으로 활성화한다. 새 포탑의 조준 피벗은 상부 모델만 회전하고 바닥판·점유 격자는 유지한다.

검증: 9종 후방 타겟 인식, 조준 이벤트, 빈 범위 발사 금지, 원형 경계 포함/범위 밖 거절, 유효 타겟 유지·쿨다운 보존, 기존 4종 자동 조준과 피해/감속, 실제 한 번 클릭 배치·회수, 무기별 특수 효과, 기존 3개 맵 전투 회귀를 통과했다. Editor 검증이며 빌드는 하지 않았다.

## 포탑 사거리 선택 표시

포탑 사거리는 일반 상태에서 포탑을 클릭한 경우에만 표시한다. 빈 지면·다른 건물 클릭, 선택 취소, 수정 진입 시 숨긴다. 수정/배치 중 사거리 미리보기와 기존 포탑의 준비 중 상시 범위는 제거했다. 선택 후 UI 위로 마우스를 이동해도 범위는 유지한다. 넥서스 건설 격자·영역 표시와 실제 공격 효과는 별개로 유지한다. 신규/기존 포탑의 선택 표시와 회수 흐름을 Editor에서 검증했다. [실행 기록](Validation/selected-tower-range.json).
