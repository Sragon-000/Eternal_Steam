# 적 전투 최적화

원본 프로젝트에서 게임 빌드 없이 적용했다. 대상 선택 규칙, 피해 1, 첫 공격의 1초 대기, 방벽의 이동 구간 충돌 검사는 유지한다.

## 변경한 처리

- 목표 핸들 조회 결과와 접근 위치를 재사용한다. 목표 변경·사망·회수·정지 후 이동 재개 시 갱신한다. 건물 등록 Revision으로 제거된 표적을 즉시 무효화한다. 변경 알림 계약이 없는 조회 구현은 기존 직접 검사를 사용한다.
- 공격 루프는 매 프레임 전체 슬롯 대신, 현재 사거리 안에 있거나 최대 이동량으로 이번 프레임 진입 가능한 후보 배열만 순회한다. 이동 중 장애물에 닿은 적도 후보에 넣는다. 후보 배열은 처음 한 번 할당하고 재사용한다.
- 공격선 검사는 최초 접근·건물 구성 변경·실제 타격 직전에 수행한다. 사망/거리/기절은 별도 확인한다. 실제 공격 간격과 피해 판정을 저빈도 시뮬레이션으로 바꾸지 않았다.
- 적별 현재 건물 버킷의 경계와 차단 여부를 캐시한다. 이동 구간 전체가 변경 없는 빈 버킷 안에 있을 때만 정밀 검사를 생략한다. 빈 버킷뿐 아니라 차단된 버킷 조회 결과도 재사용해 중복 조회를 막는다. 큰 이동량·경계 통과·건물 추가/제거 시 전체 구간 검사를 유지한다.
- TWC 그리드 Transform을 시뮬레이션 프레임당 한 번 스냅샷으로 가져온다. 각 적의 지형 통행 검사는 Transform API 호출 없이 좌표·통행 배열로 처리한다. 같은 지형 셀 안의 구간은 셀 판정을 재사용한다.
- 오픈월드에서 XZ 위치가 바뀌지 않은 적은 Terrain 높이를 다시 샘플링하지 않는다. 기존 데모의 도착 제거 정책은 이전 높이 갱신 경로를 유지한다. 지형은 실행 중 변형하지 않는 현재 조건이며, 동적 지형 도입 시 높이 캐시 무효화 계약이 필요하다.

병렬 처리, DOTS/NavMesh 이전, 화면 밖 적 제거, 피해 합산, 시뮬레이션 갱신율 축소는 하지 않았다. 기존 적 공간 인덱스의 전체 재구축은 유지했다. 셀 변경분 갱신 구조는 별도의 비용 비교가 필요한 후속 범위다.

## 검증 방법

- VerifyBuildingCombat: 기존 공격/차단 회귀와 함께 목적지·정지 높이 재조회 없음, 빈 버킷에 새 방벽이 추가될 때 차단, 살아 있는 표적의 등록 해제 시 재탐색을 검사한다.
- VerifyTraversalSnapshot: 회전·스케일이 있는 지형에서 고정 시드 10,000개 이동 구간을 기존 판정과 비교한다.
- CompareBuildingCombat: 이전/현재 제어기 소스를 동일한 도구 어셈블리로 컴파일하고 같은 월드·건물·개체 수에서 순서대로 측정한다. 도구 안의 두 클래스는 비교용 소스 스냅샷이며 실제 씬은 Runtime의 EnemyBuildingCombat만 사용한다. 공통 건물 조회와 이동 엔진은 현재 버전을 사용하므로 전체 이전 버전의 A/B 실행은 아니다.
- BenchmarkBuildingCombat: 실제 Runtime 구현을 사용하는 기존 동일 배치 CPU 측정이다.
- MeasureOpenWorldFrames: 실제 스타트 지역에서 기존 소환 경로로 생성한 지상 적 4천, TWC 지형, 카메라·렌더링·UI를 포함한다. 측정용 넥서스 체력만 크게 늘린다. 종료 시 생성물·적·카메라·프레임 설정을 원복한다.

Editor 컴파일/동시 실행 부하에 따라 절대 시간이 크게 변동했다. 이전 턴의 38ms와 이번 결과를 직접 비교해 개선율로 제시하지 않는다. 비교용 호출 내부의 전후 수치를 우선한다. GC.Alloc 양성 대조군을 확인하며 전투 코어와 전체 Editor 프레임의 GC는 구분한다.

## 전후 비교 결과

10만 적, 101개 건물, 지상/공중 절반, 고정 배치. 한 호출 안에서 이전/현재 소스를 같은 컴파일 조건으로 실행했다. 10프레임 예열 + 30프레임 측정이므로 짧은 코어 비교이며 장시간 전체 플레이 성능을 대변하지 않는다. 두 실행 모두 현재 공통 이동 엔진/공간 조회를 사용한다.

| 비교 | 이전 중앙값 / p95 | 현재 중앙값 / p95 | 중앙값 감소 |
|---|---:|---:|---:|
| 1 | 94.71 / 101.85ms | 27.57 / 29.72ms | 70.9% |
| 2 | 94.17 / 103.00ms | 27.54 / 30.75ms | 70.8% |
| 3 | 93.40 / 99.58ms | 27.19 / 29.51ms | 70.9% |

각 비교의 측정 루프 GC.Alloc 이벤트와 GC0 수집은 모두 0이었다. 원시 기록은 `Measurements/building-combat-optimized-pair-100000-*.txt`에 있다. 생성/파괴의 일회성 할당과 전체 UI의 할당은 이 결과에 포함하지 않는다.

## 실제 Runtime 코어 측정

기존 BenchmarkBuildingCombat의 30프레임 예열 + 60프레임, 3회 측정도 별도로 수행했다.

| 동시 적 | 중앙값 3회(ms) | p95 3회(ms) | GC.Alloc |
|---:|---|---|---|
| 4,000 | 2.59 / 2.57 / 2.61 | 4.09 / 3.04 / 2.89 | 전부 0 |
| 10,000 | 6.57 / 6.42 / 6.36 | 9.09 / 7.03 / 6.85 | 전부 0 |
| 100,000 | 40.67 / 26.35 / 39.53 | 47.49 / 27.37 / 46.17 | 전부 0 |

환경 변동으로 10만 적의 절대 시간 편차가 크다. 가장 빠른 회차만 대표값으로 선택하지 않았다. 비교 도구와 Runtime 도구는 컴파일 위치와 측정 길이가 다르므로 수치도 동일하지 않다. **10만 적 60fps 달성은 아니다.** 실제 지형과 렌더링까지 포함하면 더 많은 비용이 필요하다.

현재 남은 코어 비용은 주로 이동/공간 인덱스다. 후속 작업은 실제 프레임에서 이 구간을 더 세분화한 뒤, 공간 인덱스 변경분 갱신과 수치 계산의 병렬화를 검토하는 순서가 적절하다.

## 실제 스타트 지역 Editor 프레임

최종 코드로 지상 적 4,000마리를 기존 소환 규칙(간격/통행 가능한 경로)으로 생성해 측정했다. 고체력 넥서스 1개, 포탑 없음, 카메라 Zoom 70, 30프레임 예열 + 120프레임 측정이다. 렌더링과 UI는 정상 실행했으며, 생성물·적·카메라와 프레임 설정은 자동 원복했다.

| 지표 | 중앙값 | p95 |
|---|---:|---:|
| Main Thread | 32.303ms | 43.261ms |
| PlayerLoop | 13.331ms | 20.503ms |
| GC Allocated In Frame | 39,537B | 39,625B |

전체 Editor 프레임에는 Editor/렌더링/UI/측정 환경 비용이 포함된다. 전투 코어의 무할당 결과와 모순되는 값이 아니며, 이 전체 할당의 발생 위치는 이번 측정만으로 특정하지 않았다. UI와 Editor 할당을 분리해 추적하는 작업이 후속으로 필요하다. 실제 씬의 전후 동일 프레임 비교는 하지 않았으므로 이 수치로 전체 게임 개선율을 주장하지 않는다. 게임 빌드는 하지 않았다.

원시 기록: `Measurements/openworld-optimized-editor-frames.txt`.

## 최종 검증

최종 Runtime 어셈블리에 새 캐시 필드가 실제 로드되고 컴파일 오류가 없음을 확인한 뒤 다음 검사를 통과했다.

- VerifyBuildingCombat: 공격 간격·피해·차단·공중 대상·기절/냉각·슬롯 재사용·동시 파괴·새 방벽/표적 제거 캐시 무효화·정지 높이 재조회 방지.
- VerifyBuildingCombatPause / VerifyBuildingCombatIntegration: 실제 일시정지, 선택 체력 표시, 예약/회수/파괴/기지 영역 연결.
- VerifyTraversalSnapshot: 기존 통행 판정과 10,000개 구간 일치.
- VerifyFrostRetargeting / VerifyTurretRotation: 냉각 대상 변경·조준·개체별 강화 유지.
- VerifyFoundationRegression: 기존 3맵의 출격·클리어·패배·재도전·보상·저장 복원 유지.

이 작업의 범위는 반복 계산과 불필요한 검사를 줄이는 최적화다. 10만 적 60fps, 전체 프레임 무할당, 병렬 시뮬레이션 완료를 의미하지 않는다.
