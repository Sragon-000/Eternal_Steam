# 미니맵 적용 결과

2026-09-24 구현, 2026-09-25 문서 정리. 기존 OpenWorldHud를 사용하는 시작 씬/오픈월드에 적용. 원본 프로젝트에서 작업했으며 게임 빌드는 하지 않았다.

## 사용

- 우측 **테스트 공간** 패널 맨 위의 미니맵을 클릭하거나 드래그하면 카메라가 해당 위치로 이동한다. 줌 크기와 건설 작업은 유지한다.
- 별도 미니맵 접기/펼치기 버튼이 있다. 기존 테스트 패널 전체 접기도 유지한다.
- 지형 개요와 이동/설치 불가 영역을 구분하고, 기지는 노랑, 활성 등록 건물은 청록, 적 밀집 구역은 빨강, 보스는 자홍으로 표시한다.
- 흰 테두리는 현재 카메라 화면을 초점 높이 평면에 투영한 범위다. 흰 십자는 카메라 초점이다. 실제 고저차 표면을 따라 계산한 가시 영역은 아니다.
- 위쪽은 월드 +Z(북쪽)다. 회전된 맵 외곽을 월드 좌표로 계산하므로 45° 맵은 다이아몬드 방향으로 나타난다.
- 미니맵에서 시작한 입력은 월드 설치/회수로 전달하지 않는다. 드래그 중 WASD와 월드 휠 줌도 차단한다.

## 구조

- `MinimapProjection`: 맵 범위와 월드↔미니맵 좌표 변환. TileWorldGround가 있으면 회전/스케일을 포함한 외곽을 사용하고, 없으면 Terrain 범위를 사용한다.
- `MinimapElement`: UXML에 저작된 표시와 포인터 처리. 게임 규칙에 의존하지 않고 표식·밀집도·카메라 범위 데이터를 그린다.
- `OpenWorldMinimap`: 기존 건물 등록/적 배열/카메라를 읽어 표시 데이터로 연결하고 이동 요청을 전달한다. 씬 종료 때 이벤트와 생성한 텍스처를 정리한다.
- `FreeCameraRig.MoveFocus`: WASD와 미니맵 이동이 같은 맵 경계 제한을 사용한다.

별도 GameObject/UI 계층/렌더링 카메라를 생성하지 않는다. UI는 기존 UXML/USS에 추가했다. 지형 배경은 시작 시 높이와 유효 지면을 128×128 텍스처로 한 번 생성하는 개요 지도다. 실제 맵 재질을 촬영한 영상은 아니다.

적은 개별 UI를 만들지 않고 32×32 밀집도에 집계한다. 표식/적 집계는 최대 5Hz, 카메라 표시는 최대 20Hz로 갱신한다. 접힌 상태에서는 갱신을 생략한다. 적 집계는 적 수가 0이면 생략하며, 적이 있으면 슬롯 배열을 한 번 순회한다. 게임 전체 성능 목표 달성을 의미하지 않는다.

## 검증

- 최종 Editor 컴파일 성공.
- `Tools/VerifyMinimap.Main`: 실제 45° 시작 맵에서 모서리 왕복·북쪽 표시, 메인 표식·카메라 범위, 줌 보존 이동, 포인터 캡처/해제, 수정 상태 유지·예약 없음, 접기/펼치기, 적 밀집도 합계 및 초기화 후 제거 통과.
- `Tools/VerifyMinimap.Input`: 가상 InputSystem 마우스로 실제 클릭/드래그 이동, 미니맵 위 입력 차단, 드래그 중 WASD/휠 차단, 토대 도구 선택 중 임시 설치가 생기지 않음 확인.
- `VerifyOpenWorldCameraInput.Main`: 기존 WASD·수량 입력 포커스·휠 단계/역방향/한계/UI 차단 회귀 통과.
- `VerifyHudFolds.Main`: 기존 상단 패널·인벤토리 접기와 임시 예약 보존 회귀 통과.
- Play 화면 캡처로 지도·표식·범위와 패널 배치를 확인했다. 저장 테스트 경로를 `/tmp/eternal-minimap-test-0924`로 분리했다.

## 범위

이번에는 전체 지도를 표시한다. 안개/탐험 해금, 적 발견 조건, 알림 핑, 미니맵 줌, 기지 영역 표시, 별도 맵 전환 UI는 포함하지 않는다. 미니맵을 위한 새 저장 포맷은 없으며 카메라 초점은 기존 안전 저장에 포함된다. 실행 중 지형을 편집한 경우 배경 개요 갱신은 씬 재시작이 필요하다.
