# 2026-10-02 main 반영 체크포인트

사용자 요청에 따라 이전 main 이후 누적된 프로젝트 코드·씬·아트·문서·검증 기록을 함께 반영한다.

- 철도 왕복/연결/선로 건설/저장 및 완성 기관차·화물칸·토대칸 연동 애니메이션 적용.
- 기존 스프라이트 기반 HUD 통합 및 해상도 앵커 적용. 마지막 전체 회귀 결과 266/266, 실제 7개 해상도 검증 기록 보존. 이번 Git 반영 작업에서 전체 회귀를 새로 실행한 것은 아니다.
- 후속 요청으로 기존 테스트 UI를 두 씬에서 다시 활성화하고 저장/재로드 상태를 확인했다. 이전 검증의 ‘테스트 UI 숨김’ 조건은 새 요구에 맞춰 후속 UI 검사에서 교체해야 한다.
- Tab 전투/건설 그룹 전환, 가장자리 이징, 기지별 자원 펼침, 플레이어 시야 중심 150×150 미니맵은 계획만 반영한 상태이며 미구현이다.
- 연구 확장 검토 문서는 보완했으며 연구 실험은 실행하지 않았다.
- GitHub의 일반 Git 파일 크기 한도를 넘는 씬·맵·기준 사본 3개는 정확한 경로로 LFS 추적한다. 기존 이미지/모델 LFS 규칙도 유지한다. Python 캐시는 제외한다.
- 변경 파일 공백 검사에는 Unity 직렬화의 빈 속성 뒤 공백 등이 보고되었다. 이번 업로드를 위해 Unity 자산을 텍스트로 재작성하지 않았다.
